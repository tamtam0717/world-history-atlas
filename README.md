# 世界歴史地図（world-history-atlas）

年代別の世界歴史地図（いまはヨーロッパとその周辺が中心）。年を1年ずつ進めたり、指定した年に飛んだりしながら、国境・君主・出来事を眺めるための静的サイト。

## しくみ

国境線を手で描く代わりに、**現代の行政区画（ピース）を年ごとの所属で塗り分け、同じ国のピースを結合して地図にする**。

- ピース：geoBoundaries（CGAZ ADM1/ADM2）を基本に、ドイツ・フランス・イタリア・ベルギー・ギリシャはより細かい区画を使用（ヨーロッパと周辺で約7,500区画）。その外の全世界は CGAZ の州・省単位で、歴史データができるまでは現代の国境で淡く表示する（範囲外は約8,900区画、全体で16,331区画）。南アジア・東南アジアは藩王国や植民地の段階的な拡大を描くため、インド・パキスタン・バングラデシュ・スリランカ・ネパール・ミャンマー・フィリピン・インドネシア（パプアを除く）を県（CGAZ ADM2）単位にし、ラオスのチャンパーサック、ベトナムのクアンチ・クアンビン、マレーシアのペナン・ペラ・サラワクも県単位にしている（pieces_config.json の world_adm2）。中国は地級（地区・市）単位の約340区画（1990年代の「中国地州界」で県を束ね、海岸の欠けは Natural Earth で補う。tools/chn_pieces.py）。租借地のために大連・青島・威海・湛江の市街、香港島・九龍を別ピースにし、サハリンは北緯50度で南北に、千島列島は北千島・南千島に分けている。南北アメリカは、ルイジアナ購入・テキサス・メキシコ割譲・宣言線・西フロリダなどを描くため、アメリカ合衆国の30州を郡単位（「郡名, 州の略号」。例 USA-Washington_PA）、カナダのケベック・オンタリオ・ノヴァスコシアを経済圏（CGAZ ADM2）、チリを県（provincia）、メキシコのチアパス、ペルーのタクナ・ロレト、パラグアイのチャコ3県、アルゼンチンのサルタ・フフイ・カタマルカ、ブラジルのロライマを ADM2 にしている。さらに経緯線・矩形などで近似の分割（split）をしている：マニトバ（1870・1881）、ケベック・オンタリオ北部（1898・1912 の拡大、ハドソン湾流域）、アルバータ・サスカチュワン（北緯55度）、ラブラドル、ヴァンクーヴァー島、北極諸島、ミシガンのアッパー半島、ネヴァダ（1861–67 の経線）、パナマ運河地帯（中心線の両側5マイル）、七つの布教村、アントファガスタ（南緯24度）など。CGAZ にない海外領土（仏領ギアナ・グアドループ・マルティニーク・サン＝マルタン／シント・マールテン・アルバ・キュラソー・バミューダ・ケイマン・英領ヴァージン諸島など）とグアンタナモ基地は Natural Earth から足している（add_ne_pieces）。アフリカは、ナイジェリア・ガーナ・カメルーン・エチオピア・エリトリア・ウガンダ・タンザニア・マリ・セネガル・ガンビア・ギニア・シエラレオネ・コートジボワール・ブルキナファソ・トーゴ・ベナン・ニジェール・チャド・アンゴラ・モザンビーク・マラウイ・マダガスカル・南アフリカを県（CGAZ ADM2）単位に、ケニアは沿岸5県、南スーダンは中央・東エクアトリアだけ ADM2。北アフリカは範囲内（州・県単位）。西サハラは北緯26度・24度で3つに、アオズー地帯・ビル・タウィール・ハラーイブを split で分け、レユニオン・マヨット・セントヘレナ・チャゴス・仏領南方地域を Natural Earth から足している。そのほか、エントレ・リオス（アルゼンチン）、サウスダコタのミズーリ川の東、北海道の和人地、奄美・トカラ・小笠原、関東州（大連の北緯39.45度以南）、ナゴルノ・カラバフ、朝鮮の北緯38度線と休戦ラインの間を分けている（split の units：CGAZ ADM2 の区画名で切る）。オセアニアは、オーストラリアを州単位に経線で近似の分割（南オーストラリアの東経132度・135度、北部準州の東経135度、クイーンズランドの東経141度以西）、トレス海峡諸島（1872・1879）、オールバニ、外部領土（クリスマス島・ココス諸島・ノーフォーク島）、ニュージーランドを地方単位にワイカト盆地・ロヘ・ポタエ（キング・カントリー）・ルアペフ・ニュープリマス・ファカタネ、パプアニューギニアの州を 1885 年の英独境界線で分け、ソロモン諸島のショートランド諸島、ハワイのカウアイ・ニイハウ、アメリカ領サモアのマヌア諸島を分けている。フィジー（州）とキリバス（環礁）は CGAZ ADM2。CGAZ にない島々（ニューカレドニア・仏領ポリネシア・ウォリス・フツナ・クック諸島・ニウエ・トケラウ・ピトケアン・合衆国の小離島・クリッパートン・ケルマデック・亜南極諸島・マッコーリー島・ハード島など）は Natural Earth から足している
- 所属・君主・出来事：`data/` の YAML（形式は [docs/data-format.md](docs/data-format.md)）

## 開発

```bash
npm install
npm run dev        # データを検証・生成して開発サーバを起動
npm run build      # dist/ に静的サイトを出力（GitHub Pages へは main への push で自動デプロイ）
```

### データの検証

```bash
npm run data                                              # 検証して public/data/atlas.json を生成
node tools/build_data.mjs --missing 1648,1815 --iso DEU   # データのないピースを一覧
node tools/snapshot.mjs 1700 --zoom 10,51,3               # 地図を PNG に書き出す
python tools/compare_hb.py 1700 --iso DEU                 # historical-basemaps と照合（要 geopandas）
```

URL の `#y=1740&p=prussia` で年と選択中の国を指定できる。`?debug=pieces` を付けるとピースの境界と ID を表示する。

### ピースの作り直し（通常は不要）

```bash
tools/fetch_sources.sh   # 元データ（約260MB）を .cache/src/ に取得
tools/build_pieces.sh    # public/data/pieces.topo.json と data/generated/pieces.tsv を再生成
```

ピース ID は所属データから参照されるので、作り直したときは ID が変わっていないか確認すること。
