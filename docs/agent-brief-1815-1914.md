# 範囲の拡大（1815→1914）：データ作成担当への共通の指示

1648–1815 の試作データ（docs/agent-brief.md の手順で作成・レビュー済み）を、**1914年まで**延ばす。担当範囲（現代の国コード）と担当ファイルは 1648–1815 と同じ（docs/polity-ids.md の表）。**既存のファイルに追記する**（地域の timeline を延ばし、必要な地域・政体・出来事を足す）。

## 最初に読むもの
1. CLAUDE.md（特に「画面づくりの原則」「進捗」）
2. docs/data-format.md、docs/agent-brief.md（手順・検証・してはいけないこと。すべてそのまま当てはまる）
3. docs/polity-ids.md（下の「1815–1914 の主な政体 ID」も）
4. data/events/europe.yaml（ヨーロッパ全体の出来事。1815–1914 の分は「全体担当」が並行して書き足している。重複しないこと）
5. 自分の担当の既存ファイル（data/polities・regions・events の担当分）

## 作るもの
- 担当範囲のすべてのピースに、1914年までの所属を与える。確認：`node tools/build_data.mjs --missing 1820,1850,1870,1880,1900,1914 --iso <担当の国コード>`（ゼロにする）。
  - 注：data/meta.yaml の表示範囲はまとめ役が全担当の完了後に 1914 へ広げる。それまで画面では 1815 までしか動かせないが、snapshot.mjs は URL で年を指定するので、`node tools/snapshot.mjs 1871 ...` のように範囲外の年も確認できるはず（できなければまとめ役に報告）。
- 主な国境の変化（条約・統一・独立・併合）を年末時点の決まりで入れる。
- 自分が定義する主な政体の、1815–1914 の**君主を全員**（在位年・Wikipedia の出典つき。日本語版の記事名に自信がなければ英語版の URL）と、情勢（periods）を2〜6件。
- 担当地域の出来事を 20〜50 件程度（europe.yaml と重複しないもの）。
- 政体の種別やラベルが時期で変わるものは names に kind / short を入れる（data-format.md）。

## overlord（上位の枠）の扱い（1815–1914）
- ドイツ連邦（german_confederation、1815–1866）：連邦に属する領域に overlord。1866 年（普墺戦争）で終わり。
- 北ドイツ連邦（north_german_confederation、1867–1870）：加盟国に overlord。
- **ドイツ帝国（german_empire、1871–）：owner を german_empire にする（1つの国として1色で塗る）。** 構成国（バイエルン王国など）の君主・情勢は各政体に残し、地域の note に「ドイツ帝国の構成国」と書く。
- オスマン帝国の宗主権下の自治国（セルビア公国 1817/1830–1878、ワラキア・モルダヴィア→ルーマニア 1878 まで、ブルガリア公国 1878–1908、東ルメリ 1878–1885 など）：overlord: ottoman。エジプト（ムハンマド・アリー朝）は overlord: ottoman（1882 以降のイギリス占領は certainty や note で表現してよい）。
- ロシア皇帝が君主を兼ねる国（ポーランド立憲王国・フィンランド大公国）：overlord: russia のまま。

## 担当ごとの主な変化（例。これに限らない）
- **A（西欧・北アフリカ）**：フランスの政体の移り変わり（復古王政・七月王政・第二共和政・第二帝政・第三共和政）、1860 ニース・サヴォワのフランス編入、1871 アルザス＝ロレーヌのドイツ編入（german_empire）、アイルランド、1830– アルジェリアのフランス征服（段階的）、1881 チュニジア保護国、1912 モロッコ保護国（フランス・スペイン）、1911–12 リビア（イタリア）、1882 エジプト（イギリスの占領）、イベリアの内戦（カルリスタ戦争）。
- **BN（北ドイツ）**：1815 プロイセンの再編、1834 関税同盟（出来事）、1864 シュレースヴィヒ・ホルシュタイン、1866 ハノーファー・ヘッセン＝カッセル・ナッサウ・フランクフルトのプロイセン併合、1867 北ドイツ連邦、1871 ドイツ帝国。
- **BS（南ドイツ）**：1815–1866 のドイツ連邦の南部、1866 普墺戦争の南ドイツ、1871 ドイツ帝国への加盟、1871 アルザス＝ロレーヌ（ドイツ側のピースがあれば）。ドイツ連邦・ドイツ帝国の皇帝・議長の扱い。
- **C（低地諸国・スイス・イタリア）**：1830 ベルギー独立（1839 ロンドン条約で確定、リンブルフ・ルクセンブルクの分割）、1848 スイス連邦国家、イタリア統一（1859 ロンバルディア、1860 中部イタリア・両シチリア、1861 イタリア王国、1866 ヴェネト、1870 ローマ）、1890 ルクセンブルクの同君連合解消。

- **E（バルカン・オスマン・中東）**：1829/1830 ギリシア独立と以後の拡大（1864 イオニア諸島、1881 テッサリア、1913 マケドニア南部・クレタ）、1817/1830 セルビア自治、1878 ベルリン会議（セルビア・ルーマニア・モンテネグロ独立、ブルガリア公国、東ルメリ、ボスニア占領、キプロス（イギリス）、カルス・バトゥミ（ロシア））、1885 東ルメリ統合、1912–13 バルカン戦争、アルバニア独立、ドデカネス（1912 イタリア）、ペルシア（ガージャール朝。1828 トルコマンチャーイ条約）、アラビア半島。
