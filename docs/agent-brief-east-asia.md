## 田村さんの決定（東アジア）
- **冊封（朝貢）関係**：朝鮮・琉球などは独自の色で塗り、`overlord: qing`（清の色の細い帯）を付ける。オスマン帝国の自治国と同じ見せ方。琉球は 1609 年以後の薩摩の支配も note に書く（帯は清だけ）。冊封が終わる年（朝鮮は 1895 下関条約）で overlord を外す。
- **清の藩部**（モンゴル・青海・チベット・新疆〈1884 年の省設置まで〉）：owner: qing、`certainty: indirect`（清の色を少し薄く塗る。画面の対応は別の担当が実装中。データ形式は docs/data-format.md）。内モンゴルも盟旗制で間接統治なので indirect でよい。

## 描き方の方針（ヨーロッパと同じ考え方）
- 「Y 年の年末の状態」。
- 王朝交代期・内戦（明清交代、三藩の乱、太平天国、国共内戦、朝鮮戦争）は、年末時点の主な勢力圏を描く。ピースが粗くて前線を正確に描けないときは、過半を占める側にし、note に書く。
- 租借地（関東州・膠州湾・威海衛・広州湾・九龍・新界）は、ピースが取れていれば租借国の色＋label。取れなければ note にとどめる。上海などの租界は描かない（note）。
- 日中戦争（1937–45）・太平洋戦争の日本の占領地は、owner: japan・certainty: occupied で描く。満洲国・汪兆銘政権・蒙疆などの傀儡政権は、独自の政体＋overlord: japan。
- 1945–52 の日本：owner: japan のまま、label「日本（連合国の占領下）」と overlord: usa。沖縄（1945–72）・奄美（–1953）・小笠原（–1968）は owner: usa＋label。
- 植民地は宗主国の色＋label（台湾 1895–1945、朝鮮 1910–45 は owner: japan、label「朝鮮（日本の植民地）」など）。
- 名目的な領有・支配が及んでいない地域（17 世紀の蝦夷地・樺太、アムール川流域など）は certainty: nominal や uncertain を使い、note に書く。
- 表記は日本の高校世界史の教科書に合わせる（康熙帝・乾隆帝・ヌルハチ・李氏朝鮮は「朝鮮」、徳川家康 など）。
- 元首：清の皇帝、中華民国の大総統・国民政府主席・総統、中華人民共和国は実権者（国家主席・共産党主席／総書記。note で）、日本は江戸時代は将軍（天皇は note）、明治以後は天皇と、必要なら首相を note、朝鮮の国王、モンゴルなど。出典の URL つき。

## 作るもの・確認
- 担当範囲のすべてのピースに 1648–2025 の所属を与える。確認：`node tools/build_data.mjs --missing 1648,1662,1683,1700,1760,1800,1842,1860,1895,1900,1912,1920,1932,1940,1945,1950,1980,2025 --iso <国コード>`（ゼロにする。G1・G2 は CHN を分け合うので、相手の分は除いて数える）。
- 情勢（periods）3〜8 件、担当地域の出来事 40〜80 件（日本の高校世界史で太字になる事件はもらさない）。
- 地図の確認：`node tools/snapshot.mjs 1648 1700 1760 1842 1860 1895 1905 1912 1920 1933 1942 1945 1950 2025 --zoom 115,38,2.6 --out .cache/snapshots/<担当名>`（`--layer religion|language` も使える）。
- `npm run data` が警告なしで通ること。

## 敏感な主題
南京事件、植民地支配、戦争・革命の犠牲、台湾・チベット・新疆などの現在の帰属をめぐる問題は、事実に基づき、高校世界史・一般的な百科事典の水準の中立的な表現で書く。現在の地図は実際の統治で塗る（台湾は roc）。
