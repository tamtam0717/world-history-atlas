# 範囲の拡大（1648→1453）：南北アメリカ・アフリカ・オセアニアのデータ作成担当への共通の指示

ヨーロッパ・中東・北アフリカ・アジアの 1453–1647 はできた（レビュー済み）。最後に **南北アメリカ・サハラ以南のアフリカ・オセアニアの 1453–1647** を作る。担当ファイルは 1648–2025 を作ったときと同じ（docs/agent-brief-americas.md・docs/agent-brief-africa.md・docs/agent-brief-oceania.md の表）。**既存のファイルに追記する**。

4. 自分の地域の指示書（americas / africa / oceania）と、自分の担当の既存ファイル

## 決まり
- 担当範囲のすべてのピースに 1453–1647 の所属を与える（意図した所属なしは note と報告に）。確認：`node tools/build_data.mjs --missing 1453,1480,1492,1500,1520,1533,1550,1570,1591,1600,1620,1640,1647 --iso <担当の国コード>`。
- **1648 年以降の所属は変えない**。基準：/tmp/claude-0/-home-user-world-history-atlas/5a7a987a-a877-559b-b3fe-1574c9cf110f/scratchpad/atlas_before_rest1453.json と比べて確かめる。1647→1648 の段差で既存の 1648 年の値が史実に明らかに合わない所は、直さずに報告に書く。
- 1648 年の形と違う区分けは `until: 1647` の小さな地域で（1648 年以降の項目を写さない）。
- 君主は **rulers** に、情勢は **periods** に書く（取り違えるとビルドが警告する）。主な政体の 1453–1647 の君主を、確かな範囲で（伝承の王名・年代があいまいな国は「歴代の王」などの1行と note でよい。誤った断定より粗いが正しい方がよい）。情勢 2〜6 件、出来事 30〜60 件（場所のはっきりしたものには `at`）。
- 描き方は 1648–2025 と同じ：**実効支配は濃く、主張だけは nominal（斜線）、在地の主な国家は独自の色、どの国家の支配も及ばない所は所属なし**。

## 主な内容（例）
- **南北アメリカ**：アステカ王国（三都市同盟。1521 年のテノチティトラン陥落まで）、マヤの諸国（ユカタンの諸都市、ペテンのイツァは 1697 年まで＝既存）、タラスコ王国、インカ帝国（–1533、ビルカバンバの残存 –1572）、チムー王国（–1470ごろ）、ムイスカ、マプーチェ、北米の先住民勢力（イロコイ連邦の成立、ポウハタン、ミシシッピ文化の衰退後）。ヨーロッパ：カリブ海のスペイン（1492– イスパニョーラ、キューバ 1511）、ヌエバ・エスパーニャ（1521–）、ペルー（1533–）、ポルトガル領ブラジル（1500 発見・1530 年代のカピタニア）、北米の初期の植民（セントオーガスティン 1565、サンタフェ 1610、ジェームズタウン 1607、ケベック 1608、プリマス 1620、ニューネーデルラント 1624、マサチューセッツ湾 1630）、オランダ領ブラジル（1630–54）。トルデシリャス条約（1494）の主張だけの範囲は斜線にしない（実効支配が及んだ所だけ）。
- **アフリカ**：ソンガイ帝国（1464 スンニ・アリ〜1591 モロッコの侵攻）、マリ帝国の縮小、カネム＝ボルヌ、ハウサ諸国、ベニン、オヨ、ジョロフ、エチオピア（ソロモン朝、1529–43 アダルのアフマド・グランの侵攻、オロモの移動）、アダル、フンジ（1504–）、スワヒリの都市国家（キルワ・モンバサ・マリンディ）とポルトガル（1505–、モンバサのフォート・ジーザス 1593）、コンゴ王国（ポルトガルとの交流）、ンドンゴ（ルアンダ 1576）、ムタパ（モノモタパ）、グレート・ジンバブエの後継、ポルトガルの拠点（エルミナ 1482、ソファラ、モザンビーク島）、オランダの進出（ゴレ 1617、エルミナ 1637）、マダガスカルの諸王国。
- **オセアニア**：1453–1647 は大半が所属なし（オーストラリア・ニューギニア・メラネシア）。トンガの海洋首長国（トゥイ・トンガ）、ハワイの島ごとの首長国（統一前なので島ごと、または所属なし）、ヨーロッパの到達（マゼラン 1521 のグアム、スペインのマリアナ 1668＝範囲外、タスマン 1642）は出来事に。
