# 南アジア・東南アジア（1648–2025）の担当間の整合

担当：S1 北西インド・パキスタン（data/*/india_north.yaml）、S2 東インド・ベンガル・ヒマラヤ（india_east.yaml）、S3 南インド・スリランカ（india_south.yaml）、S4 大陸部東南アジア（mainland_sea.yaml）、S5 島嶼部東南アジア（maritime_sea.yaml）、S6 分布（data/religion・language の south_asia.yaml・southeast_asia.yaml、data/cities.yaml の該当分、data/movements/south_asia.yaml）。
やり方は docs/integration-notes-east-asia.md と同じ。担当の境界で隣り合うピース（pieces.topo.json の共有辺）の所属（owner・overlord・certainty）を 1648–2025 の全年で比べ、「前後は同じなのに数年だけ食い違う」組と「同じ持ち主への切り替えの年が 1〜12 年ずれる」組を拾った。色は、隣り合う政体の組を全年で拾い、色差（CIE76 の ΔE）の小さい順に見た。

## 整合の結果

### 1. マラーター 1802–1817（S3）

- バセイン条約（1802 年 12 月）から宰相の領地（プネー・北コンカン・デカン西部など 11 地域）が owner: britain・indirect（「ペーシュワー領」）になっていて、1803–17 年の地図でマラーターの色が西インドから消えていた。
- → **1802–1817 年は owner: maratha・overlord: britain（イギリスの色の帯）**に直した（cause はそのまま、note に「同盟は第3次マラーター戦争まで大勢力」）。1818 年からのボンベイ管区・サーターラー藩王国はそのまま。シンディア・ホールカル・ボーンスレーなど諸侯の領地はもとから 1818 年まで maratha（帯なし）。
- data/polities/india_south.yaml の maratha の note の説明も同じ内容に書き換えた。

### 2. 隣り合う政体の色

### 3. パキスタン・カラート・チャガイ／ケチ

- data/polities/ottoman.yaml の pakistan の note を南アジア全体の前提に書き直し（東西パキスタン、藩王国の加入と 1955 年の統合、カシミールの実効支配、データの置き場所）、情勢を 1 件から 5 件に分けた（1947–58、1958–71、1972–88、1988–99、2000–）。元首はもとのまま（内容は南アジア全体でも正しい）。
- ottoman.yaml の makran_chagai（チャガイ・ケチ）を S1 の pk_kalat にそろえた：1739 ペルシアの宗主権・1747 ドゥッラーニー朝の宗主権・1758 自立（いずれも uncertain のまま）、**1876 年からは britain・indirect（「カラート藩王国」）**（もとは britain・uncertain）。
- チャガイ（chagai_m）に **1896 年からイギリス領バローチスターン**（britain・certain、label）を足した（もとの note「1896 年に直轄地」を年表にした）。
- ケチ（makran_m）は 1948 年から pakistan・certain だったが、カラートと同じく **1948–54 年は pakistan・indirect（「マクラーン藩王国」）、1955 年に西パキスタン州へ統合**にした。

### 4. 英領の直轄地の副ラベル

S1〜S3 の britain の label を全部並べて比べた。管区・州の名前と年はほぼそろっていた（ベンガル管区→北西州→北西州およびアワド→アグラ・アワド連合州→連合州、ナーグプル州→中央州、ボンベイ管区、シンド（ボンベイ管区）→シンド州、ベンガル州・東ベンガル・アッサム州・ビハール・オリッサ州など）。直したもの：

- 東ニマール（S1 mp_nimar）：1860 年から「中央州」だったが、中央州は 1861 年 11 月に置かれたので **1860 年は「サーガル・ナルマダー地方」、1861 年から「中央州」**（S1〜S3 の他の地域は 1861 年）。サンバルプル（S2）の 1862 年はベンガルからの移管の年なのでそのまま。
- 表記：**「カシュミール」（S1、65 か所）→「カシミール」**（高校世界史の表記。S6 の宗教・言語・都市はもとから「カシミール」）、「グワーリヤル」（S3 の note・都市名）→「グワーリオル」（S1 と同じ）。
- S5 のジャワ・スマトラの 1945–46 年の label が「（イギリス軍の占領）」「（オランダ軍の占領）」と地名なしだった → 「ジャワ（イギリス軍の占領）」などに。マレー北部 4 州の 1943 年の「（タイに編入）」→「マレー北部4州（タイに編入）」。
- インドに帰属した藩王国（1947–49）の label は S1 が「…（インドに帰属した藩王国）」、S2 が藩王国名だけで違うが、どちらも意味は通じるのでそのままにした。

### 6. 境目の年

- **ネパール西部タライ（S2 naya_muluk）とアワド（S1）**：S2 は 1816–59 年を britain・certain（「ナヤ・ムルク（イギリス領）」）としていたが、スガウリ条約で得た西部のタライは、会社が戦費を貸したアワド太守に与えた地で、1860 年に返されたのもアワド州（バハラーイチ・ケーリー）からだった。S1 のアワドに合わせて **1816 britain・indirect（「アワド（保護国）」）、1856 アワド州、1857 アワドの反乱軍（awadh・uncertain）、1858 アワド州、1860 ネパール**にした（1857 年に隣のバハラーイチだけ反乱軍の色で段差になっていた）。
- **ビルマのアラカン・アッサム・マニプル**：S4 のアラカン征服は 1785 年（ミャウー陥落は 1785 年 1 月。出来事は 1784 年）、S2 のアッサム（1817 宗主権、1821–23 占領）・マニプル（1819–25 占領）、ヤンダボ条約の 1826 年で S2・S4 はそろっていた。チッタゴンはビルマの占領なし（S2 の地図どおり）。
  - 第 1 次イギリス＝ビルマ戦争：S2 はアッサムの 1824–25 年をイギリス軍の占領として描くが、S4 のアラカン・テナセリムは 1826 年に直接イギリス領になっていた → **アラカン 1825 年（ミャウー陥落 4 月）、テナセリム 1824–25 年を britain・occupied** にした（どちらもヤンダボ条約で割譲された地域）。ヤンゴンなど返された下ビルマは描かない。

### 7. 潮流・宗教・言語

## 直さなかったもの・自信のない点

- **ナヤ・ムルクをアワドに与えた経緯**：アワド太守がネパール戦争の戦費を貸し、その代わりにタライを得たという記憶にもとづく（Wikipedia が使えず未確認）。note に「要確認」と書いた。間違っていれば 1816–55 年を britain・certain に戻す。
- **第 1 次イギリス＝ビルマ戦争の占領**：「戦争中の一時的な占領は描かない」原則の例外として、割譲された地域（アッサム・アラカン・テナセリム）だけ占領を描いた。下ビルマ（ヤンゴン・バゴー、1824–26 年に占領、のち返還）は描いていない。
- **マラーター 1802–1817 の帯**：帯を付けたのは S3 の宰相領だけ。シンディア・ボーンスレーなどの諸侯（S1・S2）は第 2 次マラーター戦争で領地を割譲したが、1817–18 年の条約まで maratha（帯なし）のまま。1803–04 年の講和条約で軍事保護に近い関係に入ったとみる考え方もある（未確認）。S1 の南グジャラート（gj_valsad）は帯なしで、隣の宰相領（ナーシク・パールガル）と帯の有無だけが違う。
- **色**：アワド（水色）・カーナティック（青緑）・ボーパール（水色）など青系が中部インドに増えた。互いに隣り合わないことは確かめたが、田村さんの好みで調整してよい。インドの橙は地図の中で大きな面積を占める。
- **高平の莫氏（S4 mac_cao_bang）**：1648 年から overlord: qing だが、清が莫氏を冊封したのは雲南・広西の平定以後とも考えられる（未確認・そのまま）。
- **アラカン征服の年**：地図は 1785 年、出来事は 1784 年（遠征の開始）。1784 年 12 月 31 日にミャウーが落ちたとする説もある（そのまま）。
- **マレー北部 4 州 1943–45**：S5 は siam・occupied（日本がタイに渡した占領地）として描く。タイの施政下なので occupied でなく certain とする考え方もある。
- S1 のバローチスターンの東の境（ゾーブ・ローラーライ 1887）、チャガイ（1896）・ヌシュキ（1899）の年は ottoman.yaml の既存の note と S1 の cause による（未確認）。
- 宗教・言語・潮流の中身（S6）は、年が政治とずれていないかと塗り漏れだけを見た。
