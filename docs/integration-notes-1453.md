# 担当間の整合（1453–1647、ヨーロッパ・中東・北アフリカ）

指示書は docs/agent-brief-1453-1648.md。担当は A（west）・BN（germany_north）・BS（germany_south）・C（italy_lowcountries）・D（habsburg）・E（ottoman）・F（north_east）と分布（data/religion・language・cities.yaml・movements・events/europe.yaml）。

## 整合の結果

各担当から挙がった確認点に対応したうえで、担当の境界で隣り合うピース（pieces.topo.json の共有辺）の所属（owner・overlord・certainty）を 1453–1647 の毎年で比べ、食い違いが短い期間（25〜80 年以下）だけのものを一覧にして、一覧にない食い違いも探した。
**1648 年以降の所属・分布（owner・overlord・certainty・label、宗教・言語）は、作業前の atlas.json と比べて、例外のマスカット（下の 10）以外は変わっていない**（全ピース・1648–2025 の毎年で照合）。

### 1. until への統一
- D（habsburg.yaml）の 1648 年より前だけの 34 地域（lower_austria_1485、upper_austria_1620、kufstein_1505、burgenland_pledges、koszeg_pledge、olomouc_1642、celje_county、ptuj_salzburg、tolmin_1509、slavonia_east_1526、slavonia_central_1537、knin_1522、obrovac_1527、zadar_hinterland_1537、vrana_1537、makarska_neretva、krk_1480、klis_1537、seven_counties_sk、filakovo_1554、nograd_1552、gyor_1594、veszprem_1552、nagykanizsa_1600、transdanubia_1543、esztergom_1543、somogy_1555、somogy_west_1555、szigetvar_1566、csongrad_1543、szolnok_1552、hatvan_1552、eger_1596、bekes_1566）に `until: 1647` を付け、「1648– （元の地域から写したもの）」の項目を消した。1648 年以降は外側の地域の記述が効き、所属は変わらないことを確かめた。
- ほかの担当の新しい地域（政治 331、宗教・言語）に、1648 年以降の写しは残っていない（宗教の secular.yaml は 1648 年以降だけの地域で対象外）。

### 2. ボヘミア王冠領
- ボヘミア・モラヴィア・シュレジエン（D・F）・ラウジッツ（BN・F）とも、1453 bohemia → 1469 hungary（占領）→ 1479 hungary（オロモウツの和約。ボヘミア本土は bohemia のまま）→ 1490 bohemia → 1620 でつながっている（ボヘミア・シュレジエンは habsburg、ラウジッツは saxony）。
- F のラウジッツ（ポーランド側、`lusatia`）は 1620 年の占領だけで、BN のドイツ側にある「1623 年の質入れ（uncertain）」と副ラベル（「ラウジッツ（ザクセンの占領）」「ラウジッツ（ザクセンへの質入れ）」）がなかった → BN に合わせた。

### 3. バイエルン＝ランツフート
- D のインフィアテル（`innviertel`）・クーフシュタイン（`kufstein_1505`）を、BS の `bavaria_landshut_part` と同じく 1453 bavaria_landshut → 1504 bavaria（uncertain、ランツフート継承戦争）→ 1505（インフィアテルは bavaria、クーフシュタイン・キッツビュール・ラッテンベルクは habsburg）にした。

### 4. ヘルツェゴヴィナ
- D のクロアチア側（`makarska_neretva`、`dalmatia_newest_hr` のイモツキ・ヴルゴラツ）の 1453 年を bosnia_kingdom（uncertain）から E と同じ `herzegovina` にした（オスマン領になる年は D の 1482 年のまま。E のボスニア側は 1466・1477 年で、ヘルツェゴヴィナが海岸に追い詰められていく形になる）。herzegovina の note も直した。

### 5. マラマロシュとハンガリー東部
- F のマラマロシュ（`zakarpattia_zak_maramures`）は E のマラムレシュ（`transylvania_ro` に含まれる）と同じ動きにした：1529 hungary（overlord ottoman）→ 1541 transylvania → 1551 habsburg（イザベラの譲渡）→ 1556 transylvania。
- 1648 年の段差（ウクライナ側は 1648 年から habsburg、ルーマニア側は transylvania）は既存データのもので、1648 年以降は変えない決まりのため残した（マーラマロシュ県は実際には 1733 年ごろまでパルティウムとしてトランシルヴァニア公の支配下）。**次の見直しの候補**。
- ついでに見つかった同じ種類の食い違いを D の書き方（1527 habsburg → 1529 hungary＋overlord ottoman → 1541 → 1551 habsburg → 1556 …）にそろえた：
  - E：トランシルヴァニア本土・ルゴジ（1529 の宗主、1551–55 の habsburg）、ビホル・サトゥ・マーレ（1527 habsburg、サトゥ・マーレは D のサボルチ・サトマールと同じく 1565 habsburg・1605・1607・1621・1630・1645 も）、アラド・バナト（ルーマニア側・セルビア側。1529 の宗主、1551 habsburg）、バーチカ（1527 habsburg・1529）、ボスニア北辺のポサヴィナ（1527 habsburg、クロアチア＝スラヴォニアと同じ）、ビハチ（1527 から habsburg。クロアチアのツェティン選挙）。
  - F：ベレグ・ウゴチャ（`zakarpattia`）を D のサボルチ・サトマールと同じ動きに（1541 transylvania、1565 habsburg、ボチカイ 1605–06、1630 の返還年を D の 1630 にそろえた）。ウング（`zakarpattia_zak_ung`）は 1527 habsburg を足した（ニコルスブルク・リンツの 7 県に含まれないので 1621・1645 は habsburg のまま。これは史実どおり）。

### 6. ユーリヒ・クレーヴェ、フリースラント
- ID は C・BN とも `julich_berg`（–1520）・`julich_cleves`（1521–）でそろっていた。C のシッタルト・スステレン（`julich_nl`）とヘネップ（`gennep`）に、BN と同じ 1609 年の継承争い（uncertain）と、ヘネップの 1614 brandenburg → 1618 prussia を足した。
- フリースラント 1498–1514（C）の saxony は、BN の saxony の names（1485–1546「ザクセン公国（アルベルト系）」）と合っていて、副ラベル「フリースラント（ザクセン公の総督領）」もそのままでよい。

### 7. ブルゴーニュ・ネーデルラント・ロレーヌ・三司教領
- ルクセンブルク・ティオンヴィル・ビットブルク（C・A・BS）は 1453 burgundy → 1477 habsburg_netherlands → 1556 spain でそろっている。メス（A）は 1552 france（hre の枠）→ 1648 france。
- BS のザールルイ（ロレーヌ公領）に、A の lorraine_duchy と同じ 1475 burgundy（占領）・1476 lorraine を足した。
- A のダンケルクに、C のフランドルと同じ 1577 netherlands（uncertain）を足した（1583 年 7 月にパルマ公が奪回して spain。ブルッヘ・ヘントは C の 1584 年のまま）。
- 残した段差：1469–73 年の上アルザス（A、ブルゴーニュへの質入れ）とブライスガウ（BS、habsburg）。質入れはブライザッハと森林都市だけでフライブルクは含まれず、ピースが粗いため BS の note のとおり。1634–47 年のアルザス（フランスの占領）とオルテナウ、1639–47 年の上アルザスとブライスガウ（ブライザッハのフランス占領はピースが粗くて描けない）は史実どおり。
- 1520 年代以前のトゥルネー（C、フランス王領の飛び地）とリール（A）の段差、1536–1600 年のクーネオ（C、フランスの占領とサルッツォ）とニース（A、サヴォイア）の段差も史実どおり。

### 8. ドナウ二公国・黒海北岸
- F のモルダヴィア北部（ブコヴィナ・ホティン・ヘルツァ）とブジャクは overlord ottoman が 1538 年からで、E のモルダヴィア（1456 貢納 → 1473 シュテファン大公が止める → 1489 再開）と段差があった → F 側に E と同じ 1456・1473・1489 を足した（1538 年の項目はスレイマン1世の遠征の cause として残した）。キリア・アッケルマン（1484 ottoman）とブジャク・ベンデル（1538 ottoman）は E・F で一致。
- ドニエストル左岸（E の `transnistria`）は 1538 年まで lithuania、1538 年から ottoman で F と同じ年。確からしさを F のイェディサンと同じ uncertain にした。イェディサン沿岸の 1492 crimea（オチャキウ）は F のまま。
- ノガイ・カザフ・カルムイク（E・F の草原）は uncertain でそろっている。

### 9. ラグーザ・ロードス島
- ラグーザ（D）は 1453 overlord hungary → 1526 overlord ottoman になっていて、ほかの担当に別の記述はない。
- C の `malta` に names（–1529「聖ヨハネ騎士団（ロードス騎士団）」、略称「ロードス騎士団」）、1453–1521 年の総長 8 人、1453–1522 年の情勢を足し、E の `pre_rhodes` の副ラベルを消した（地図の名前で時期が分かる）。

### 10. マスカット（例外：1648 年以降のデータの修正）
- 既存データ（E の oman_north）はマスカットを 1648 年からオマーン領としていたが、ポルトガル人がマスカットを追われたのは 1650 年 1 月。E の `pre_muscat_pt` を `until: 1650` にして 1648–1649 年を portugal、1650 年に oman（cause：ヤアーリバ朝のスルターン・ブン・サイフがマスカットを攻略）とした。**1648 年以降の所属を変えたのはこの 1 ピース（OMN-Muscat）の 2 年だけ**（まとめ役の判断、例外として記録）。

### 11. 出来事の重複（7 件をまとめた）
- europe.yaml と担当側の重なりは、挙がった候補（グーテンベルク、95 か条、ヴォルムス、シュパイアー、アウクスブルク信仰告白、ミュールベルク、ネルトリンゲン、ブライテンフェルト、リュッツェン、マクデブルク、プラハの和約、パヴィア、マリニャーノ、オランダ独立宣言、東インド会社、マルタ包囲、ガリレオ、カルヴァン、カール5世の退位、モハーチ、ウィーン包囲、ブダ陥落、白山、窓外投擲、ナントの王令、カトー＝カンブレジ、アルマダ、ローマの劫掠、グラナダ、トルデシリャス、首長法、コンスタンティノープル、プレヴェザ、チャルディラーン、カスレ・シーリーン、カイロ）とも、すでにどちらか一方にしかなかった（イギリス東インド会社＝europe とオランダ東インド会社＝C は別の出来事）。
- 担当どうしの重複をまとめた：
  - ベオグラード包囲 1456（D と E）→ D に 1 件（本文を合わせた）。
  - ベオグラードの陥落 1521（D と E）→ E に 1 件。
  - カッファの征服とクリミア＝ハン国の服属 1475（F と E）→ F に 1 件（題名「オスマン帝国がカッファを征服（クリミア＝ハン国の服属）」）。
  - プロイセン公国の成立 1525（BN と F）→ F に 1 件（重要度 1、本文に「最初のプロテスタントの国家」）。
  - 伯爵戦争 1534（BN と F）→ F に 1 件（題名「伯爵戦争（デンマークの王位争い）」、oldenburg を関係国に足し、リューベックの話を本文へ）。
  - グルムバッハ事件 1567（BN と BS）→ BN の「ゴータの陥落（グルムバッハ事件）」に 1 件（wurzburg を足した）。
  - カール5世の退位 1555/56（C と D の「ハプスブルク家の二系統への分裂」）→ C に 1 件（hre を足し、D の本文を合わせた）。
  - E の「ロードス包囲とオトラント占領」1480 は C の「オスマン軍がオトラントを占領」と重なるので、E 側を「ロードス包囲」（ottoman・malta）にした。
- 関係国を足した：白山の戦い（palatinate）、ブダの陥落とハンガリーの三分割（hungary）、ルターがヴァルトブルク城にかくまわれる（hre・habsburg。ヴォルムス帝国議会）。
- 題名を変えた出来事を参照する潮流はなかった（`npm run data` で未定義の参照の警告なし）。

### 12. 首都
- 都市の座標がどのピースにあるかを調べ、1453–1647 年の首都の期間にそのピースがその政体の持ち物かを全都市で確かめ、cities.yaml を直した（1648 年以降の首都の期間は変えていない）：
  - ベルリン：brandenburg 1453–1617、prussia 1618–（1618 年から地図の所属が prussia のため）。ケーニヒスベルク：ducal_prussia は 1617 年まで。
  - ウィーン：habsburg を 1491–1917 に続け、プラハの habsburg（1583–1611、ルドルフ2世の宮廷）を消した（D はボヘミアを 1619 年まで bohemia で塗るため。宮廷のことはプラハの note にある）。プラハの bohemia は 1619 年まで。
  - 滅亡・併合の年の年末に首都が残っていたもの：ディジョン（–1476）、ノヴゴロド（–1477）、トヴェリ（–1484）、プスコフ（–1509）、カザン（–1551）、アストラハン（–1555）、パンプローナ（–1511）、ミストラ（–1459）、スメデレヴォ（–1458）、トレムセン（–1553）、フェス（ワッタース朝 –1548）。
  - シュトゥットガルト：1520–33 年（ハプスブルク家の支配）を抜いた。ギュラフェヘールヴァール：1551–55 年を抜いた。
  - ツェティニェ：zeta 1482–1495、montenegro 1516–。ティフリス：georgian_kingdoms –1489、kartli_kakheti 1490–1647（E の地図に合わせた）。
  - 首都のなかった政体に足した：ストックホルム（sweden 1453–）、ナンシー（lorraine 1453–）、ロドス（malta 1453–1521）、ヴァレッタ（malta 1571–。もとは 1648–）、トレド（castile 1453–1515、spain 1516–1560。宮廷は移動した）、ブリュッセル（habsburg_netherlands 1477–1555）。
- 王領ハンガリーの首都プレスブルクは**入れない**ことにした。D は王領ハンガリーを habsburg（オーストリアと同じ色）で塗っていて、1 つの政体に首都は 1 つなので、ウィーンと重なる。
- 残したずれ：占領下の首都（ハイデルベルク 1622–47、ナンシー 1633–47、シャンベリ 1536–58、モスクワ 1610–11、マントヴァ 1630 など。これまでの方針どおり）、ナポリ・ミラノ（ナポリ王国・ミラノ公国の首都の期間に、地図ではスペイン・フランスの色。政体の首都として残す）、ジェノヴァ（ミラノ・フランスの宗主下で indirect）、チュニス（1534・1569–72 年のオスマンの一時支配）。

### 13. 色
- 1453–1647 年に隣り合う政体の組の ΔE（CIE76）を毎年調べ、新しい政体（1648 年より前だけの 102 政体）が入る組で 20 未満のものを、新しい政体の色を変えて解消した（明るさ・彩度はこれまでの色の範囲。68 政体）。主なもの：ボヘミア（ハンガリー・プファルツと近かった → 薄紫）、ブランデンブルク（青を明るく）、ミラノ（青緑）、アラゴン（緑）、ブルゴーニュとハプスブルク家のネーデルラント（同じピンク）、マムルーク朝、黒羊朝・白羊朝の周辺、ドイツの小領邦（ハルバーシュタット、フェルデン、ユーリヒ＝ベルク、テューリンゲン、ヘッセン＝マールブルクなど）、ヘルツェゴヴィナ、ボスニア王国、ポンメルン、ノヴゴロド・プスコフ・リャザン・カザン・アストラハン・大オルダ。
- 既存の政体の色を 3 つ変えた（1648 年以降の地図の色も変わる）：**hungary**（#b9d39a → #c4bd82。1453–1540 年にオスマン帝国と ΔE 5 で、ハンガリーとオスマン領の区別がつかなかった）、**crimea**（#d9d08a → #f6b9c5。リトアニアと ΔE 6.5）、**nogai**（#dcd7ab → #e4d0f3。カザフと ΔE 2.2）。
- 解消しきれなかった組（20 未満）：マムルーク朝とサファヴィー朝（1510 年だけ、16）、ミンデンとオスナブリュック（17）、ロマーニャ公国とサンマリノ（1500 年だけ）、ブルゴーニュ／ネーデルラントとリエージュ（19.7）。既存どうしの組（マインツとヴュルツブルク、アンスバッハとバイロイトなど、1648 年以降も隣り合うもの）はこれまでどおり。

### 14. 塗り方のぶれ（1453・1500・1550・1600・1640）
- 担当ごとに certainty の使い方を数えて見比べた。草原・砂漠の遊牧地は E・F とも uncertain、北アフリカの内陸とアイルランドのゲール人地域は A が nominal、ハンガリーのオスマン領との境は D・E とも certain、長い占領（三十年戦争・イタリア戦争・ロレーヌ）は occupied、ジェノヴァやロマーニャの教皇代理領などは C が indirect、で担当の範囲の中ではそろっている。A の nominal（北アフリカ）と E の uncertain（アラビアの部族地域）は意味の違い（名目上の支配がある／帰属がはっきりしない）として残した。

### 1647 年と 1648 年のつなぎ目
- 1648 年に所属が変わるのに cause のなかった地域に、cause だけを足した（所属は変えていない）：ウェストファリア条約（三司教領・ヒンターポンメルン・ライン左岸のプファルツ・オスナブリュック・マインツ・エアフルト・バーデン＝ドゥルラッハ）、ラーコーツィ・ジェルジ1世の死による 7 県の返還、クリスの陥落（1648 年 3 月）、フメリニツキーの乱（ザポロージャ）、ベルゴロド防衛線（スロボダ）。
- シベリア東部・アルタイ（qing・khalkha・dzungar、1648 年から）は 1647 年まで所属なしで、東アジアの段階で扱う。

### 直さなかったもの・課題
- **担当範囲の外のピース**：`--missing` で A〜F の全 iso を見ると、データのないピースは MRT（13）・MLI（49）・PAK（123）の計 185 ピースだけ。どれも 1648 年以降はアフリカ・南アジアの担当のデータで、次の段階（アジア・アフリカの 1453–1647）で扱う。
- マラマロシュのウクライナ側の 1648 年の段差（上の 5）。
- ダンケルクの 1646–47 年のフランス占領は、1648 年以降のデータ（spain）とつながらないので描いていない。
