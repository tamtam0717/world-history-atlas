# 担当間の整合（1453–1647、アジア）

指示書は docs/agent-brief-1453-asia.md。担当は Z1（china）・Z2（inner_asia）・Z3（japan_korea）・Z4（india_north・india_east）・Z5（india_south）・Z6（mainland_sea）・Z7（maritime_sea）と Z8（宗教・言語の east_asia・south_asia・southeast_asia、cities.yaml、movements）。境を接するヨーロッパ側（ottoman・north_east）の 1453–1647 も合わせて見た。

## 整合の結果

担当の境界で隣り合うピース（pieces.topo.json の共有辺）の所属（owner・overlord・certainty）を 1453–1647 の毎年で比べ、食い違いを一覧にして確かめた（作業用のスクリプトは scratchpad の int_asia1453/：border.py・step.py・ov.py・caps.py・colors.py・recolor.py・cmp1648.py）。
**1648 年以降の所属・分布は、作業前の atlas.json（atlas_before_asia1453.json）と比べて、下の 1 の例外 2 ピース（CHN-Ali・VNM-Cao_B_ng）以外は変わっていない**（全ピース・1648–2025 の毎年で照合。宗教・言語は差なし）。

### 1. 1647→1648 の段差
- **南インド（Z5）**：`pre_rayalaseema`（アナンタプル・カダパ）を分け、カダパを新しい `pre_gandikota`（until 1647）にした。ヴィジャヤナガル王国の滅亡（1646、シュリーランガ3世がヴェールールを追われる）から、アナンタプル（ペヌコンダ）は bijapur[uncertain]、カダパ（ガンディコータ）は golconda[uncertain] とし、1648 年の既存データにつなげた（ガンディコータの陥落は 1650 年なので不確実のまま）。
- **ジンジー周辺・プドゥッチェーリ**：1646–47 gingee、1648 bijapur[uncertain] のまま。ジンジーの城は 1648 年末〜1649 年に落ちたが、周辺はすでにビジャープル軍に押さえられていて、1648 年の「不確実」は年末の状態として妥当と判断した。ヴェールール（1647 bijapur → 1648 不確実）も変えていない。
- **ガリ（Z2、例外）**：`pre1648_ngari` を `until: 1683` に延ばし、**1648–1678 年を ladakh、1679–1683 年を tibet/khoshut[uncertain]**（チベット・ラダック・ムガル戦争）にした。1684 年からは既存の `tibet_central`（チベット）。ラダックがガリを治めたのは 1630 年ごろから 1684 年のティンモスガン条約までで、既存の 1648 年のデータ（チベット）は史実に明らかに合わなかった。出来事「ティンモスガン条約（ガリがチベット領に）」（1684、inner_asia）を足した。
- **高平の莫氏（Z6、例外）**：`vnm_caobang` の 1648 年の項目から清の帯を外し、**1661 年から overlord: qing**（清が雲南・広西を平定。年は要確認）にした。清軍が広西に来たのは 1650 年ごろで、1648 年の清の帯は早すぎた。1644–47 年の「帯なし」はそのまま。
- **ペラ（Z7）**：1620–1647 年はアチェの帯、1648 年から帯なし。アチェの宗主権がいつ終わったかの年に確信が持てないため、1648 年以降は変えていない（**次の見直しの候補**。1650 年代まで続いたという見方がある）。
- **ガヨ高地（Z7）**：1530–1647 年は aceh[nominal]、1648 年から aceh（確か）。所有者は同じで、斜線の有無だけの違いなので残した（1648 年以降は既存データの単純化）。
- **ブータン南部のドゥアール（Z4）**：西ドゥアール（ジャルパイグリ・アリプルドゥアール）は 1647 年まで koch_bihar、コクラジャール・チランは mughal、バクサ・ウダルグリは ahom で、1648 年から既存データがブータン。ブータンの進出は 17 世紀後半だが、代わりの年を決められないため 1648 年以降は変えていない（**次の見直しの候補**）。ブータン東部（1647 年まで所属なし[不確実] → 1648 年 bhutan[不確実] → 1655 年に確か）は、どちらも不確実なのでそのまま。
- **中国南部**（李成棟・金声桓の寝返りによる 1648 年の南明の回復）、黒竜江の確からしさ（1647 年の nominal・uncertain → 1648 年 certain）は史実・既存の単純化どおりでそのまま。
- そのほかの段差（宗主の帯や確からしさだけの違い）で、1648 年以降の既存データの単純化によるもの：チョーター・ナーグプル（1616–1647 ムガルの帯 → 1648 帯なし）、バルティスターン（1637–1647 ムガルの帯 → 帯なし）、ブンデールカンド・メーワート・ラリトプル（certain → indirect）、キャンディ東部・ネパール南部（uncertain → certain）。どれも所有者は同じで、1647 年側は 1648 年以降より細かい描き方として残した。

### 2. 明の終わりと冊封の帯
- `overlord: ming` はすべて 1643 年で終わる（朝鮮は 1636 年まで、琉球は 1643 年まで（奄美は 1608 年まで）、黎朝（鄭氏）・莫氏・高平は 1643 年まで）。明の直轄・indirect・nominal の地も 1643 年までで、1644 年からは南明・順・大西・清。明が 1644 年 4 月に滅び、年末は南明という扱いで全担当そろっている。
- 朝鮮の清の帯は 1637 年から（丙子胡乱の降伏は西暦 1637 年 1 月）。Z3 の出来事「丙子胡乱（朝鮮の清への降伏）」（1637、joseon・qing）と一致し、Z1 に重複する出来事はない。後金→清の国号は 1636 年（Z1「国号を清と改める」）。

### 3. 境目
- **Z4–Z5**：南カリンガ（`pre_kalinga_south`）にガンジャームと同じ 1568 年の garhjat[uncertain]（ガジャパティ朝の滅亡）を足し、ガンジャーム（`pre_ganjam`）の 1571 年を golconda[uncertain]、1600 年から確か（南カリンガと同じ）にした。デーオガル（Z4 は 1595 年から mughal[indirect]、Z5 のナーグプルは gondwana）は 1648 年以降の既存データ（mp_deogarh と nagpur_land）と同じ分け方なので残した。ハーンデーシュ・ベラール・ナーシクの境は一致。
- **Z6–Z7**：サトゥーン（`tha_satun`）に、クダ本土と同じ 1619 年の aceh の帯、1637 年の siam の帯を足した。
- **Z1–Z2**：内モンゴル（トゥメト・オルドス・チャハル）、兀良哈三衛（朶顔衛・泰寧衛・福余衛、1454–1546 年 ming[nominal]）、ハミ（1473・1513 年にトゥルファン）、青海・チベット東部、沿海州は、確からしさの濃淡の違いだけでつながっている。
- **Z1–Z6**：雲南西南の土司（徳宏・シプソンパンナー）は ming[indirect]、ビルマ側のシャン諸国は 1557 年から burma[indirect]、コーカンは ming[nominal]。シプソンパンナーはバインナウン以後ビルマにも貢納したが、明の土司として描く方針のまま。
- **Z4–Z6**：チッタゴン・アラカンは一致（1459 arakan、1512 ベンガル、1538 arakan）。北東インドの山地は Z4 が「所属なし」、ミャンマー側のチン丘陵は Z6 が「所属なし（不確実）」で、どちらも 1648 年以降の既存データと同じ書き方なので残した。
- **Z4–E**：シンド（サンマー朝→1520 アルグン朝→1555 タルハーン朝→1591 ムガル）、クエッタ・ピシーン（カンダハールと同じ動き、不確実）は E の `afg_kandahar` と一致。
- **Z2–F**：シベリア東部は F のヤクーツク（1632 russia[uncertain]）、Z2 のザバイカル・アムールは所属なし（アムール中流は 1635 年から後金・清の nominal）で、段差は史実どおり。
- 1453–1494 年のジャウンプル（ビハール南部は不確実）、1526–1538 年のビハール（スール家）とジャウンプル（ムガル）、1557–1573 年のビハール（ベンガル）と東部ウッタル・プラデーシュ（スール朝の残り、1559 年からムガル）は史実どおり。

### 4. 出来事の重複
- 「ラダックがグゲ王国を併合」（1630、india_north）と「ラダックがグゲ王国を滅ぼす」（1630、inner_asia）→ inner_asia に 1 件（本文にイエズス会の伝道所とガリの支配の期間を足した）。
- 表記をそろえた：「トゥルファンがハミを攻め取る」（1473、inner_asia。もとは「トルファン」）。1513 年の「トゥルファンがハミを奪う」（china）は別の出来事で、moghulistan を関係国に足した。
- 関係国を足した：「エセンがハンを名のる」（1453、china）に dzungar・northern_yuan、「ヴァスコ・ダ・ガマのインド到達」（1498、europe）に calicut。
- そのほかの候補（壬辰・丁酉倭乱と明の援軍、万暦の三大征の寧夏の役・播州の役、ポルトガルのマラッカ占領、マゼラン（マクタン島の戦い〈maritime_sea〉と世界周航〈europe〉は別）、ザビエル（ゴア〈india_south〉と鹿児島〈japan_korea〉は別）、朱印船、VOC の設立〈italy_lowcountries〉とバンテン商館〈maritime_sea〉、アクバルのデカン遠征（アフマドナガル 1600）、ターリコータ）は、どれも一方にしかなかった。
- 題名を変えた出来事を参照する潮流はなかった（`npm run data` で未定義の参照の警告なし）。

### 5. 首都・都市（data/cities.yaml）
- 都市の座標のあるピースが、首都の期間にその政体の持ち物かを全都市で確かめて直した（年末の状態）：マドゥライ・タンジャーヴール（ナーヤカの都は 1565 年から。地図はそれまでヴィジャヤナガル）、キャンディ（1582–90 年のシーターワカ占領を抜いた）、ジャフナ（1467–1618。1450–66 年はコーッテの支配）、アヴァ（–1554）、バゴー（ハンターワディー –1537、タウングー朝 1538–1598）、ハノイ（莫朝 –1591、鄭氏 1592–）、ガウル（1538–53 年のスール朝の支配を抜いた）、ジャウンプル（–1478）、マーンドゥ（1453–1530・1537–41・1555–60）、ビーダル（バフマニー朝 –1526、ビーダル王国 1527–1618）、タッター（–1590）、ブルハーンプル（–1599）、スラバヤ（1547–1624）、シュリーナガル（–1585）、アフマダーバード（1536–1571）、ジョードプル（1564–82 年のムガルの直轄を抜いた）。
- 首都を足した・延ばした：ジンジー（gingee 1565–1647）、ヘトゥアラ（後金 1603–）、シヴァサーガル（アホームのガルガーオン、1540–）、アンベール（1648–1726 を埋めた）、フエ（広南阮氏 1648–1686 のキムロンを埋めて 1636–1774）。新しい都市：プレレド（マタラム 1647–77）、カルタスラ（マタラム 1680–1744）、肇慶（南明 1646・1648–49）、桂林（南明 1647）。
- 1648 年より後に作られた都市に founded を足した：イルクーツク 1661、ウラン・ウデ 1666、チタ 1653、ナーグプル 1702、台北 1709、ハイデラバード（シンド）1768、ハガニア 1668、ダーウィン 1869、コロニア 1887、ツラギ 1897、ラバウル 1910、ホニアラ 1952、パリキール 1989、マルルムド 2006（これらの都市は founded の年より前は地図に出なくなる。1648 年以降の所属には影響しない）。シヴァサーガルはガルガーオンの代わりの点なので founded は付けていない。
- 残したずれ：占領下の首都（ソウル 1592）、ムガルの間接統治下のラージプートの都（ウダイプル・ジョードプル・アンベール。1648 年以降と同じ扱い）。

### 6. 色
- 1453–1647 年に隣り合う政体の組の ΔE（CIE76）を毎年調べ、新しい政体（62）が入る組で 20 未満のものを、新しい政体の色を変えて解消した（35 政体。どれも 1648 年以降の地図には出ないので、1648 年以降の色は変わらない）。主なもの：パクモドゥ（アホームと 3.9）、ランガー（ラージプート諸国と 4.1）、シャン諸国（マニプルと 4.4）、グゲ（ヤルカンドと 6.0）、ティルフト、マールワー、コーチ・ハジョ、ジャウンプル、チルボン、ツァンパ、ラムリ、明（ツァンパと近かった。サーモンを少し明るく）、北元（ハルハと 15.6）、ビーダル、ハーンデーシュ、ジンジー、ガジャパティ、バフマニー朝、ベラールなど。
- 解消しきれなかった組（16.7–19.9、密集したラージプート・北インドの周り）：ベンガルとセーン家（ネパール）・ガルジャート、グジャラートとマールワール・ラージプート諸国、デリー・スルタン朝とメーワール・ラージプート諸国、スール朝とブンデーラ・クマーウーン、ブンデーラとグワーリオル、ガジャパティとチョーター・ナーグプル、バーティとムガル、明とツァンパ・ヤルカンド。

### 7. 塗り方のぶれ（1500・1550・1600・1640）
- 担当ごとに certainty の使い方を数えて見比べた。明の辺境は Z1 が indirect（西南の土司）・nominal（女真・兀良哈・遼東の外）、Z2 が nominal（青海・ハミ）、Z6 が nominal（コーカン）でそろっている。戦国日本は 1467–1589 年が japan[uncertain]、1590 年から確か（蝦夷地は 1593 年から nominal）。草原・山地は Z2・E・F とも所属なし（不確実）か uncertain、北東インドの山地（Z4）は所属なし。島嶼部の内陸（ボルネオ・スマトラ）は Z7 が nominal。ムガル帝国の周辺は Z4 が indirect（ラージプート）・uncertain（新しい征服地）・nominal（辺境）を使い分けている。どれも 1648 年以降の既存データの書き方に合っている。

### そのほか
