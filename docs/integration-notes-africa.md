# アフリカ（1648–2025）の担当間の整合

担当：F1 西アフリカ（data/*/west_africa.yaml）、F2 ギニア湾・ナイジェリア・チャド（guinea_coast.yaml）、F3 東アフリカ・アフリカの角・スーダン（east_africa.yaml）、F4 中部・南部アフリカ（southern_africa.yaml）、F5 分布（data/religion・language の africa.yaml、data/cities.yaml のアフリカ分、data/movements/africa.yaml）。北アフリカはヨーロッパの担当の data/regions/west.yaml・ottoman.yaml。指示書は docs/agent-brief-africa.md。
やり方は docs/integration-notes-americas.md と同じ。担当の境界（北アフリカのファイルを含む）で隣り合うピースの所属（owner・overlord・certainty）を 1648–2025 の全年で比べ、「前後は同じなのに数年だけ食い違う」組と「同じ持ち主への切り替えの年が 1〜12 年ずれる」組を拾った。色は、隣り合う政体の組を全世界のピースで全年拾い、CIE76 の ΔE を見た。首都は、都市の座標を含むピースの所属を首都の期間の全年で確かめた。

## 整合の結果

### 1. F1–F2（ハウサ・ボルヌ・サモリ・ボルグ）

- **ハウサ諸国の ID**：ジハードの前（〜1803/08）は両担当とも `hausa_states`＋label（カノ・カツィナ・ゴビル・ケッビなど）で、もとからそろっていた。ジハードの後の亡命王朝は F1 が独自の政体（`gobir` ティビリ・`maradi`）、F2 が `hausa_states`＋label（アルグング・アブジャ）で食い違っていた → **亡命王朝はそれぞれ独自の政体にそろえ、F2 に `kebbi`（ケッビ王国〈アルグング〉、1849–1901）・`abuja`（アブジャ首長国、1828–1901）を足した**（ng_argungu・ng_suleja）。hausa_states の情勢（periods）は 1808 年までにし、note に亡命王朝の扱いを書いた。
- F1 のゴビル・カツィナ（ner_gobir・ner_maradi）のジハード前の hausa_states は uncertain（斜線）、F2 の隣（ゴビル・カツィナの本拠）は確か、で段差 → **F1 の 2 地域の uncertain を外した**（コンニ〈ner_konni〉は辺境なので uncertain のまま）。
- **ボルヌ西部（NER-Diffa ほか、ner_bornu）**：1893–99 年が bornu・uncertain で、F2 のクカワ（ラービフ 1893–99）と食い違っていた → **1893 年から rabih・uncertain**、1900 年は france・nominal（ラービフの子ファドルッラーの抵抗が 1901 年まで続く）、**1903 年から確か**（F2 のチャド湖東岸 td_lake と同じ年）。
- **サモリのガーナ北西部**：F2 のガーナ北部（gc_upper）は 1898 年まで所属なしで、サモリ（wassoulou）がなかった → **ワ周辺（Wa 3 郡・ナドウリ・ダフィアマ）を地域 gc_wa_samori に分け、1896–97 年を wassoulou・uncertain**（F1 のブナ〈civ_bouna 1896–97〉と同じ時期）。1898 年からは gc_upper と同じ。
- **ボルグ**：F2 だけが持つ（ベナン北東部 bj_borgu 1894 nominal・1897 フランス、ナイジェリア側 ng_borgu 1898 英・indirect）。F1 の隣（ブルキナファソ東部・ニジェール南西部 1897–98 フランス）と矛盾はない。そのまま。
- **ヴィシー政府（1940–42）**：F1 のフランス領西アフリカは vichy_france、F2 のダホメ・トーゴは france のままで段差 → **F2 のベナン・トーゴの 17 地域に 1940–41 年 vichy_france を入れた**（トーチ作戦後の 1942 年から france）。カメルーン・チャド（自由フランス、1940 年 8 月）は france のまま（正しい）。

### 2. F2–F3（チャド東端・ダルフール・ワダイ）

- ダル・タマは F2 のワダイ本体（td_wadai）に入っていて、1909 年まで wadai、1909–11 occupied、1912 年からフランス。F3 のダール・マサリート（sdn_west_darfur：1898–1921 masalit、1922 年からイギリスの indirect）とは時期・扱いとも矛盾がない。
- **ダル・シラ（td_sila）**：1909 年に同じ内容の項目が重なり、ワダイの都の陥落（1909）の後も 1915 年まで wadai になっていた → **1909–15 年は所属なし**（スルタン国は自立。塗る政体は作らない。note に説明）、1916 年からフランス。
- **ワダイとダルフール**：互いに争った隣国で、宗主権の関係はない（どちらも独自色）。ダル・シラは両方に貢納した（note）。ダルフールの 1874–98 年（エジプト・マフディー国家）、1898–1916（アリー・ディーナール、イギリスの帯）とチャド側の年は矛盾がない。

### 3. F2–F4（中央アフリカ北部・新カメルーン）

- **ラービフのダール・アル＝クーティ**：F4 は 1830–96 年を dar_al_kuti だけで塗っていた → **1886–90 年を rabih・uncertain**（ラービフの拠点。1890 年にサヌーシーを立てて西へ移る）にし、**dar_al_kuti の 1830–85・1891–96 年に overlord: wadai**（ワダイの宗主権の帯）を付けた。政体 rabih に 1879–92 年の情勢を足し、dar_al_kuti の note（「帯にしない」）を直した。バギルミの中央アフリカ北部への宗主権（奴隷狩りの範囲）はピースが大きく範囲もあいまいなので描いていない。
- **新カメルーン（1911–14）**：F4 の 4 ピース（ウォレウ＝ンテム・サンガ・サンガ＝ムバエレ・マンベレ＝カデイ）と F2 のマヨ・ケビ（td_mayo_kebbi、ロゴヌ川の西）がドイツ領、1914 年からフランスの占領、1916 年からフランス（F4）。リクアラ・ロバイエは新カメルーンが川岸に細く達しただけなので入れない判断は妥当。フランスが取り戻した旧仏領は 1916 年から確か、旧ドイツ領カメルーン（F2）は 1916–18 occupied・1919 委任統治で、意図どおりの段差。そのまま。

### 4. F3–F4（ラド・ザンデ・ンゴニ・ティップ・ティプ・ルバ）

- **ラド飛び地**：F3（ssd_lado・uga_west_nile）は 1894 nominal、1897/1900 確か、1908 belgium、1910 イギリス。F4 のイトゥリ・ウエレは 1885 nominal・1896 確か・1908 belgium。年はそろっていた（1896 年の 1 年だけ濃さが違うのは、レジャフの陥落〈1897〉まで飛び地に支配が及ばなかったため）。そのまま。
- **ザンデ**：F3 の西エクアトリア（ssd_western_equatoria）は 1898 年まで所属なしだった → **1800–98 年を F4 の zande・uncertain**（グブドゥエの王国など。1899 nominal・1905 確かはそのまま）。zande の情勢を 1905 年まで延ばし、note を直した。
- **ンゴニ**：F4 の ngoni（マラウイ・ザンビア東部・テテ）の情勢にタンザニア南部が書いてあるが、F3 のソンゲアは所属なしだった → **地域 tza_songea（ソンゲア・ナムトゥンボ・ムビンガ）を分け、1850–96 年を ngoni・uncertain、1897 年からドイツ**（駐屯地の設置）。ngoni の情勢を 1850 年から、note を直した。
- **ティップ・ティプ**：F4 の tippu_tip（マニエマ 1870–86・チョポ 1883–86）に **overlord: zanzibar（ザンジバルの宗主権の帯）**を付けた（ティップ・ティプはザンジバルのスルタンの臣下として動いた）。note を直した。タンガニーカ湖東岸のウジジ・タボラ（F3）は所属なしのまま（アラブ商人の拠点だけで、領域の支配はない）。
- **ルバとタンガニーカ湖西岸**：F4 の cd_tanganyika は 1648 年から luba だったが、ルバ王国が湖岸に達したのは 18 世紀末〜19 世紀初め → **1648–1799 所属なし、1800 年から luba・uncertain**。ザンビア北部のベンバ（zm_bemba 1750–98）とは国境（現代のピース）で分かれていて、重なりはない。
- **ルアラバ（F4 内）**：ルンダの都ムスンバのあるピース（COD-Lualaba）が 1856–90 年イェケ（ムシリ）の色で、首都がイェケの中にあった → **1856 年の項目を消し、1890 年までルンダ（uncertain）**、イェケは上カタンガ（cd_haut_katanga）だけにした（note に理由）。
- ザンジバルは F3 が 1890–1963 年にイギリスの indirect＋label で塗っていて、ケニア沿岸の帯（1895–1963）も indirect でそろっていた。

### 5. 北アフリカ（ヨーロッパの担当）との境

- **mali_north（MLI-Tombouctou、west.yaml）**：1894–1939 年が nominal → **1894–98 nominal（label「フランス領スーダン」）、1899 年から確か**（ニジェール川湾曲部のトゥアレグの服属。F1 のガオ〈1899 確か〉と同じ年）。label を F1 にそろえ、1904「上セネガル・ニジェール植民地」、1920「フランス領スーダン」を足した。F1 の mli_timbuktu・mrt_tiris の note から「ヨーロッパの担当の …」を消した。
- 政体 **mali・mauritania の note「地図の範囲には北部だけが入る」を消した**（west.yaml の polities）。
- **ビル・タウィール**：west.yaml に地域 **bir_tawil（EGY-Aswan_Governorate_Bir_Tawil）を足し、1956 年から owner なし**（1955 年まではエジプト本体と同じ）。F3 のハライブ（1882 occupied・1902 英エジプト領スーダン・1956 スーダン・1995 エジプト〈uncertain〉）・ワディ・ハルファの突出部（1902 スーダン）は、エジプト本体の年（1882 occupied・1914 保護国・1922 独立）と食い違いがなかった。F3 の note の「data/regions/west.yaml」を消した。
- **サハラ**：ホガール（alg_hoggar、west.yaml）は 1900–19 年 nominal で、隣の F1（アイル 1906・キダル 1910・メナカ 1917・アザワグ 1917 に確か）より遅かった → **1905 年から確か**（ムーサ・アグ・アマスタンの服属とタマンラセットの拠点）。トゥアト（1901）・ティンドゥフ（1934）・ティリス・ゼムール（1934）・フェザーン（1930・1943 自由フランス）・ティベスティ（F2：1914 確か・1916–28 nominal）・カワール（F1：1906–22 nominal）は、それぞれ占領の年の違いで、段差はそのまま。

### 8. 隣り合う政体の色

### 9. 1880・1900 年の塗り方

担当ごとに、1880・1890・1900・1914 年の面積の内訳（ヨーロッパの国の確か／nominal／indirect、在地の国家の確か／uncertain、所属なし）と国ごとの内訳を出し、地図の画像で見た。

- どの担当も「海岸・征服地は濃く、勢力圏だけの内陸は斜線、在地の国家は独自色、国家のない所は所属なし」で、ある担当だけ内陸を濃く塗っている所はなかった。1900 年の nominal の割合は、アンゴラ 73%・ケニア 84%（北部辺境地区は 1926 年まで）・南スーダン 94%・カメルーン 41%・中央アフリカ 42%・ニジェール・モーリタニアの砂漠など。
- 早めに濃いのは F4 のコンゴ自由国（1891–98 年の公安軍の遠征・駐屯地の設置から確か。1900 年に 100%）と F3 のドイツ領東アフリカ（1893・1898 年から確か）。どちらも note に遠征・駐屯地の年があり、決まり（実効支配が及んだ年から濃く）に沿っているので、そのままにした。
- indirect は、北ナイジェリアの首長国・ブガンダなどウガンダの王国・ザンジバル・ベチュアナランド・バストランド・スワジランド・バロツェランド・ルワンダ・ブルンジ・フータ・ジャロン・バギルミ・中央アフリカのスルタン国などで、間接統治のはっきりした所に限られていて、担当でそろっていた。フランスの保護条約の多く（モシ・ダホメ南部など）は直轄と同じ扱い（指示書どおり）。
- ヴィシー政府（1940–42）：F1・F3（ジブチ）だけにあり、F2（ダホメ・トーゴ）・F4（マダガスカル・コモロ・マヨット・レユニオン）になかった → **ダホメ・トーゴ 1940–41、マダガスカル 1940–41（1942 年はイギリスの占領のまま）、コモロ・マヨット・レユニオン 1940–41 を vichy_france に**した。フランス領赤道アフリカ・カメルーンは自由フランス（france）のまま。

## 直さなかったもの・自信のない点

- **ホガールの 1905 年**：トゥアレグの服属を目安に確かにしたが、隣の F1 のキダル（1910）・メナカ・アザワグ（1917）は nominal が長く、1905–16 年に今度は F1 側が斜線になる段差がある。トゥアレグの反乱（1916–17）の範囲と合わせて、どちらに寄せるかは判断が分かれる。
- **トンブクトゥ州（mali_north）の 1899 年**：州の大部分は北のタウデニの砂漠で、そこにフランスが達したのは 1906 年ごろ（west.yaml の note）。トンブクトゥの町とニジェール川沿いを含むので、F1 のガオに合わせて 1899 年から濃くした（1906 年からにする考え方もある）。
- **ボルヌ西部 1903 年**・**ダル・シラ 1909–15 年の所属なし**・**ソンゲアのンゴニ 1850 年**・**ルバのタンガニーカ湖岸 1800 年**・**ラービフのダール・アル＝クーティ 1886–90 年**・**ガーナ北西部のサモリ 1896–97 年の範囲**：いずれも年・範囲は目安（出典は英語版 Wikipedia の概説）。
- **コンゴ自由国の早い「確か」**：ゴムの取り立ての駐屯地網を実効支配とみなした。1900 年に全域が濃いのは、ケニア・アンゴラ（同じ時期に大半が斜線）と比べると目立つ。
- **ルアラバ（COD-Lualaba）**：ピースの東半分はイェケ王国だったが、ルンダの都に合わせてルンダの色にした。ピースを分ければ両方を描ける。
- **色**：101 政体の色を変えた（上の表）。互いに隣り合わないことは確かめたが、色合いが大きく変わったもの（ダルフール・ワダイ・オヨ・シェワ・スーダン・オレンジ自由国・ダール・アル＝クーティ など）は田村さんの好みで調整してよい。ダルフール（淡い藤色）とイギリス（ピンク）は ΔE 20 ぎりぎりで、uncertain の斜線で区別している。
- 保護国の都（カンパラ・ザンジバル・チュニスなど）を首都のまま宗主国の色の中に置いた点は、前回までと同じ扱い。
- 宗教・言語・潮流の中身（F5）は、年が政治とずれていないかと首都・座標だけを見た。
