# 言語（民族）の分布データの形式

田村さんと決めた方針（2026-11-20〜21）：
- 民族は言語とほぼ重なるので「言語（民族）」として1つの表示にする。
- 描き方は宗教と同じ：多数派（民衆の話す言語）の色で塗り、無視できない少数派がいる所は2色目の斜線。
- **色は語族ごとの色相にそろえる**（ゲルマン系＝青系、ロマンス系＝赤〜橙系、スラヴ系＝緑系、ウラル系＝紫系、テュルク系＝茶系、セム系＝黄系 など）。文字を読まなくても、どの語族の地域かが一目でわかるようにするため。

## 言語の種類（data/language/_kinds.yaml）
`id`、`name`、`family`（語族）、`color`。種類を増やすときはここに足す。

## 地域ごとの変遷（data/language/*.yaml）
宗教（docs/religion-format.md）と同じ書き方。`main` と `minor` に言語の ID を書く。

```yaml
- id: lang_bohemia
  name: ボヘミア
  select:
    regions: [bohemia]
  timeline:
    - from: 1648
      main: czech
      minor: german          # 都市部・国境地帯のドイツ語話者
      note: 北部・西部の国境地帯（のちのズデーテン）はドイツ語が多数
```

- 判断の基準は「その地域の住民（特に農村の民衆）の多数派の言語」。支配層・都市の言語だけが違う場合は minor にするか note に書く（例：バルト地方のドイツ系領主、ハンガリーの都市のドイツ語話者）。
- **「民族」でそろえる**（田村さんの決定、2026-11-21）：日常で使う言語と民族が食い違う地域では、民族（住民の帰属意識・国勢調査の民族）の言語を main にし、実際に広く使われている別の言語は minor（斜線）で示す。
  - 例：ウクライナ人・ベラルーシ人の地域（ミンスク・ドンバス・ハルキウ・オデーサなど）は、ロシア語を多く使っていても `ukrainian` / `belarusian` を main にし、`russian` を minor にする。
  - 逆に、ロシア人が民族として多数の地域（ナルヴァ・ダウガフピルス・クリミア・ベンデルなど）は `russian` を main にする。
  - ユダヤ人は、イディッシュ語・ラディーノ語の時代は `yiddish` / `ladino`、イスラエルでは `hebrew` で示す（ハンガリーなど、ユダヤ人の多くがその国の言葉を話した地域は例外として note で説明する）。
  - 宗教の地図（docs/religion-format.md）と同じピースでは、切り替えの年と多数派をできるだけそろえる（例：言語で lang_riga が 1970 年にロシア語になるなら、宗教の rel_riga も 1970 年に正教会にする）。
- 年は大きな変化（移住・植民・追放・同化の進行）の年で切り替える。ゆっくり進む同化は、変化が地図上で意味を持つ時点で1回切り替える程度でよい。ゆっくり進む変化の年（1950・1960 など区切りのよい年）は目安。
- 範囲は 1648〜2025 年。

## 東アジア（2026-11-21、G4 担当。data/language/east_asia.yaml）
- 語族の色：シナ・チベット系＝紅（ばら色）、日本語族＝水色、朝鮮語＝黄土、モンゴル系＝カーキ（カルムイク語と同じ系統）、ツングース系＝青緑、タイ・カダイ系＝琥珀、ミャオ・ヤオ系＝オリーブ、オーストロネシア系＝淡い青緑、アイヌ語・古アジア諸語＝灰（孤立言語）。ウイグル語・シベリアのテュルク系は既存の茶系。
- 「民族」でそろえる例：回族は中国語を話すので `chinese`（宗教の地図でイスラーム）。満洲人・土家族は多くが中国語に移ったが、民族として多い地域・時期は `manchu_tungusic`／`tibeto_burman` を main か minor にする。琉球（沖縄）は 1945 年まで `ryukyuan`、以後は `japanese` に `ryukyuan` の斜線。
- 大きな変化の年（目安）：台湾の漢人化（台南 1662、西部 1720、北部 1760、宜蘭 1810、南投 1880、東部 1950）、北海道の和人化（1869）、満洲の漢人化（吉林 1880、黒龍江 1900、北部 1930）、延辺の朝鮮人（1900–70）、内モンゴルの漢人化（南部 1800、河套 1900、オルドス・ホルチン 1930、東部 1950、シリンゴル・アラシャン 1970）、新疆北部（ジュンガル滅亡の 1760、兵団の 1958–70）、シベリアのロシア人化（西部 1700–60、極東 1890、北東部 1935–75）。宗教（docs/religion-format.md の「東アジア」）と同じ年で切り替える。

## atlas.json への出力
`language: { kinds, regions, pieceTimelines }`（宗教と同じ形）。
