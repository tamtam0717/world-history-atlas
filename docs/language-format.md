# 言語（民族）の分布データの形式

田村さんと決めた方針（2026-11-20〜21）：
- 民族は言語とほぼ重なるので「言語（民族）」として1つの表示にする。
- 描き方は宗教と同じ：多数派（民衆の話す言語）の色で塗り、無視できない少数派がいる所は2色目の斜線。
- **色は語族ごとの色相にそろえる**（ゲルマン系＝青系、ロマンス系＝赤〜橙系、スラヴ系＝緑系、ウラル系＝紫系、テュルク系＝茶系、セム系＝黄系 など）。文字を読まなくても、どの語族の地域かが一目でわかるようにするため。

## 言語の種類（data/language/_kinds.yaml）
`id`、`name`、`family`（語族）、`color`。種類を増やすときはここに足す。

## 地域ごとの変遷（data/language/*.yaml）
宗教（docs/religion-format.md）と同じ書き方。`main` と `minor` に言語の ID を書く。

```yaml
- id: lang_bohemia
  name: ボヘミア
  select:
    regions: [bohemia]
  timeline:
    - from: 1648
      main: czech
      minor: german          # 都市部・国境地帯のドイツ語話者
      note: 北部・西部の国境地帯（のちのズデーテン）はドイツ語が多数
```

- 判断の基準は「その地域の住民（特に農村の民衆）の多数派の言語」。支配層・都市の言語だけが違う場合は minor にするか note に書く（例：バルト地方のドイツ系領主、ハンガリーの都市のドイツ語話者）。
- **「民族」でそろえる**（田村さんの決定、2026-11-21）：日常で使う言語と民族が食い違う地域では、民族（住民の帰属意識・国勢調査の民族）の言語を main にし、実際に広く使われている別の言語は minor（斜線）で示す。
  - 例：ウクライナ人・ベラルーシ人の地域（ミンスク・ドンバス・ハルキウ・オデーサなど）は、ロシア語を多く使っていても `ukrainian` / `belarusian` を main にし、`russian` を minor にする。
  - 逆に、ロシア人が民族として多数の地域（ナルヴァ・ダウガフピルス・クリミア・ベンデルなど）は `russian` を main にする。
  - ユダヤ人は、イディッシュ語・ラディーノ語の時代は `yiddish` / `ladino`、イスラエルでは `hebrew` で示す（ハンガリーなど、ユダヤ人の多くがその国の言葉を話した地域は例外として note で説明する）。
  - 宗教の地図（docs/religion-format.md）と同じピースでは、切り替えの年と多数派をできるだけそろえる（例：言語で lang_riga が 1970 年にロシア語になるなら、宗教の rel_riga も 1970 年に正教会にする）。
- 年は大きな変化（移住・植民・追放・同化の進行）の年で切り替える。ゆっくり進む同化は、変化が地図上で意味を持つ時点で1回切り替える程度でよい。ゆっくり進む変化の年（1950・1960 など区切りのよい年）は目安。
- 範囲は 1648〜2025 年。

## 東アジア（2026-11-21、G4 担当。data/language/east_asia.yaml）
- 語族の色：シナ・チベット系＝紅（ばら色）、日本語族＝水色、朝鮮語＝黄土、モンゴル系＝カーキ（カルムイク語と同じ系統）、ツングース系＝青緑、タイ・カダイ系＝琥珀、ミャオ・ヤオ系＝オリーブ、オーストロネシア系＝淡い青緑、アイヌ語・古アジア諸語＝灰（孤立言語）。ウイグル語・シベリアのテュルク系は既存の茶系。
- 「民族」でそろえる例：回族は中国語を話すので `chinese`（宗教の地図でイスラーム）。満洲人・土家族は多くが中国語に移ったが、民族として多い地域・時期は `manchu_tungusic`／`tibeto_burman` を main か minor にする。琉球（沖縄）は 1945 年まで `ryukyuan`、以後は `japanese` に `ryukyuan` の斜線。
- 大きな変化の年（目安）：台湾の漢人化（台南 1662、西部 1720、北部 1760、宜蘭 1810、南投 1880、東部 1950）、北海道の和人化（1869）、満洲の漢人化（吉林 1880、黒龍江 1900、北部 1930）、延辺の朝鮮人（1900–70）、内モンゴルの漢人化（南部 1800、河套 1900、オルドス・ホルチン 1930、東部 1950、シリンゴル・アラシャン 1970）、新疆北部（ジュンガル滅亡の 1760、兵団の 1958–70）、シベリアのロシア人化（西部 1700–60、極東 1890、北東部 1935–75）。宗教（docs/religion-format.md の「東アジア」）と同じ年で切り替える。

## 南北アメリカ（2026-11-21、A6 担当。data/language/americas.yaml）
- 語族の色：北米の先住民の諸語＝緑の系統（アルゴンキン・イロコイ・スー・マスコギ・カドー・ナ・デネ・エスキモー・アレウト・ユト・アステカ・
  北西海岸とカリフォルニアの諸語・プエブロの諸語）、メソアメリカの諸語＝青緑〜水色（ナワトル・マヤ・オト・マンゲ・その他）、
  アンデスの諸語＝茶（ケチュア・アイマラ）、南米低地の諸語＝黄土〜からし色（チブチャ・トゥピ・グアラニー・アラワク・カリブ・その他）、
  マプーチェ語とチャコ・パタゴニアの諸語＝藤色。クレオール語は、もとになったヨーロッパの言語の色を濃く・くすませた色
  （英語系＝濃い青、フランス語系＝ローズ、パピアメント語＝橙）。ハワイ語・ラパヌイ語は polynesian（オセアニアでも使えるように）。
  データ未整備の色（#e2e0dc）と見分けられるよう、広い面積を塗るエスキモー・アレウト語族（#7fb8c4）・メソアメリカのその他（#7cbfa8）・
  南米のその他（sa_other、#b5a67e）は彩度・濃さを上げている（色差 ΔE 25 以上）。チブチャ語族の語族名は凡例で切れないよう「チブチャ系など」。
- 先住民の語族は細かく分けず、地域の主な語族で塗る（17 世紀の分布は、集団の移動の後の 18 世紀の知見による推定を含む目安）。
  語族のはっきりしない孤立した言語（ティムクア・カルーサ・コアウイルテカ・アタカパ・ベオスックなど）は other、南米の小さな語族は sa_other。
- 「民族」でそろえる方針の当てはめ：
  - **メスティーソ化**：メスティーソ（混血）・ムラート・パルドは、スペイン語・ポルトガル語を話し国民として自らをとらえる人々として、
    spanish / portuguese で塗る。先住民の言葉を話す人、または先住民として自らをとらえる人が多数の所だけを先住民の色にする
    （オアハカ・チアパス高地・ユカタン・グアテマラ西部高地・ペルー南部の高地・ボリビアのアルティプラノ・パラグアイなど）。
    メキシコ中央高原は 1850 年ごろ（メスティーソが多数になり、レルド法で村の共有地が解体された時期）にスペイン語に切り替え、
    先住民の言葉が 1〜2 割残る山地は minor（斜線）で示す。
  - **パラグアイ**：住民の大多数はメスティーソだが、グアラニー語を日常語とするので tupi_guarani（スペイン語を minor）で塗る。
  - **入植者が多数になる変化**：アメリカ合衆国・カナダの西部は「入植者が住民の多数になった年」の目安で切り替える
    （例：オハイオ 1800〈北西部 1820〉、ジョージア西部・アラバマ 1830〜40、カリフォルニア 1850、カンザス東部 1860・中部 1870・西部 1880、大平原 1880〜90、オクラホマ 1890〜1920）。
    強制移住の前後（チェロキー 1838、五部族のインディアン準州 1840–90）は地域を分けて示す。
    州（adm1）単位では内陸の未入植の郡まで早く切り替わってしまう所は、割譲・入植の年に合わせて郡（ピース）単位の地域を作る
    （ヴァージニア・カロライナのピードモント、ジョージアのオコーニー線の西、テネシー東部の割譲地、オハイオ北西部、コロラドの西斜面など）。宗教も同じ分け方・同じ年にそろえる。
  - **アフリカ系の住民**：クレオール語を話す所（ジャマイカ・小アンティル・ハイチ・スリナム・ガラ〈サウスカロライナ・ジョージアの海岸 1730–1910〉・
    ベリーズ・ミスキート海岸）はクレオール語の色。ヨーロッパの言語を話す所（アメリカ合衆国南部・ブラジル・キューバ）は、その言語の色にして note に書く。
  - **移民の国**：移民の言葉が日常に使われた 1〜2 世代の間だけ minor（斜線）で示す（ペンシルヴェニア・ダッチ、ニューヨークのイディッシュ語 1900–50、
    中西部のドイツ語・スウェーデン語、ブエノスアイレス・モンテビデオ・サンパウロのイタリア語 1880–1940、ブラジル南部のドイツ語 1860–1950、
    カナダの平原のウクライナ語 1910–50、チリ南部のドイツ語 1860–1930、チュブのウェールズ語 1880–1930）。
    近年のヒスパニックの増加（カリフォルニア・テキサス・フロリダなど）は、多数になった郡は spanish、州全体で 2〜4 割の所は minor。
- 宗教（docs/religion-format.md の「南北アメリカ」）と、地域の分け方と切り替えの年をできるだけそろえている。

## アフリカ（2026-11-23、F5 担当。data/language/africa.yaml）
- 北アフリカは west.yaml のまま（アラビア語・ベルベル語）。エジプトのヌビア（アスワン）の minor を other → nubian、リビアのフェザーン南部の minor を other → teda に直した。
- **語族のまとめ方**：凡例の語族（family）は次の7つ。
  - **セム系**（既存のアラビア語の黄に、エチオピアのアムハラ語・ティグリニャ語〈ティグレ語を含む〉・グラゲ語〈ハラリ語を含む〉を金〜黄土で加えた）
  - **アフロ・アジア系**（既存のベルベル語・コプト語に、クシ系〈オロモ・ソマリ・アファール・ベジャ・その他〉＝橙〜茶、オモ系＝カーキ、チャド系〈ハウサ語・その他〉＝珊瑚色を加えた）
  - **ナイル・サハラ系**＝れんが色〜赤茶（カヌリ・テダ・ソンガイ・フール・ヌビア・ディンカ＝ヌエル・西ナイル〈ルオ〉・東ナイル〈マサイなど〉・南ナイル〈カレンジン〉・中央スーダン・その他）
  - **ニジェール・コンゴ系**＝紫〜赤紫（西アフリカの諸語：ウォロフ・フラニ・その他の大西洋系・マンデ・南マンデ・クル・グル・ドゴン・アカン・エウェ＝フォン・ヨルバ・イボ・エド＝イジョ・ナイジェリア中部・ウバンギ＝アダマワ）
  - **バントゥー系**＝緑〜青緑（ニジェール・コンゴ系の一部だが、大陸の南半分を占めるので別の語族として凡例に出す。グラスフィールド諸語もここ。地域ごとにまとめた：カメルーン・ガボン、コンゴ、キンブンドゥ、ウンブンドゥ、チョクウェ＝ルンダ、ルバ、コンゴ盆地、ルワンダ＝ルンディ、ルガンダ、大湖地方、キクユ、タンザニア内陸、スワヒリ、マクア、チェワ、ザンビア、ショナ、ズールー〈ングニ〉、コサ、ソト、ツワナ、ツォンガ＝ヴェンダ、オヴァンボ＝ヘレロ）
  - **コイサン諸語**＝くすんだ薔薇色、マダガスカル語はオーストロネシア系の青緑。アフリカーンス語はゲルマン系の青、ポルトガル語系クレオール（カーボベルデ・ギニアビサウ・サントメ・アンノボン）はクレオール語。
- 隣り合う言語どうし（ヨルバ語とイボ語・ハウサ語、ルガンダ語と大湖地方、ズールー語とコサ語・ソト語・ツワナ語、アムハラ語とティグリニャ語・オロモ語など）は明るさで差をつけた。
- 「民族」でそろえる方針の当てはめ：
  - 都市の共通語（スワヒリ語・リンガラ語・ハウサ語・サンゴ語・バンバラ語・英語・フランス語・ポルトガル語）ではなく、住民の多数の民族の言語を main にする（キンシャサ＝コンゴ語、ナイロビ＝キクユ語、ルアンダ＝キンブンドゥ語・ポルトガル語の minor）。
  - 南アフリカのカラード（混血の住民）はアフリカーンス語。ケープ植民地は 1720 年からオランダ語、1875 年（第1次アフリカーンス語運動）からアフリカーンス語。白人が人口の2〜3割を占めた所（オレンジ自由国、ソールズベリー・ブラワヨ 1920–80、ロレンソ・マルケス 1950–75、ナミビア中部）は minor。
  - ナミビアのダマラ人はコイコイ語を話すので khoisan。タンザニアのハ人はルワンダ＝ルンディ、ンゴニ人の移住先はその土地の言語のまま（note）。
  - モーリシャスは 1860 年からインド系（bihari）を main、モーリシャス・クレオール語を minor。
- 大きな変化の年（目安）：フラニ人の首長国（アダマワ 1810、北カメルーン 1830）、ムフェカネ（ンデベレ王国 1840）、ソマリ人の南西への拡大（1850–80）、オロモ人のウォロ（1648 時点でオロモ語、1900 からアムハラ語化）、ボーア人の内陸入植（1780〜1850）、ヨハネスブルク（1890 英語、1950 ズールー語）、フリータウン（1800 クリオ語、1970 テムネ語）。大きな変化はなるべく宗教と同じ年で切り替えた（改宗と民族の移動で意味のある違いがある所はずれている）。
  - 移民の minor：ダーバンのインド系（1880–1979 タミル語、1980 から英語）、ナイロビのアジア系（1910–69 グジャラート語）。ハラルは 1887 年の征服後に移住が進み、1950 年からオロモ語が main。
