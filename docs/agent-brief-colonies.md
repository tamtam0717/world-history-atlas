# 植民地・保護国のデータを作る担当への共通の指示

田村さんの要望：植民地を選んだときは本国と区別し、カードに「植民地と本国の背景・状況を踏まえた情勢解説」を出したい。画面のしくみと試しの 10 件（data/colonies/americas.yaml・asia_africa.yaml）はできている。これを**世界の主な植民地・保護国・委任統治領・租借地・占領地**に広げる（合わせて 50〜100 件程度）。

## 最初に読むもの
1. CLAUDE.md（「進捗」の「植民地の選択」）
2. docs/data-format.md の「植民地」（match の書き方：labels・contains・regions・iso・exclude_labels・exclude_certainty）
3. 試しのデータ data/colonies/americas.yaml・asia_africa.yaml（**書き方の見本。この2ファイルは編集しない**）

## 作るもの（1件ごと）
- id・name（時期の名前は names）・parent（本国の政体）・match・from・to
- periods：情勢 3〜6 件。本国の事情（戦争・政変・政策）と植民地の状況（統治のしかた・経済・住民・抵抗・独立運動）を踏まえて書く。高校世界史の教科書の表記。
- governors：主な総督・副王・高等弁務官など（確かな範囲で。出典つき。自信がなければ書かない）。
- polities：独立後の国など、この植民地の出来事として扱う政体 ID（data/polities を grep）。
- source・note。images は任意（Commons で存在を確かめたものだけ）。
- 本国が替わる土地（ケープの蘭→英など）は別の植民地に分ける。
- **match は必ず実際のデータで確かめる**：atlas.json のピースの timeline から owner と副ラベルの組を一覧にして、意図したピースだけが入ること、取りこぼしがないことを確かめる（build_data は存在しない副ラベルを警告する）。

## 守ること
- 自分の担当ファイルだけを作る・編集する（下の表）。data/regions・polities・events は変えない（直すべき所は報告に）。
- `npm run data` が警告なし。Playwright（tools/snapshot.mjs の起動方法、URL `#y=<年>&p=<本国>&c=<id>`）で数件を選んだ画面を撮って見る。
- 作業用スクリプトはリポジトリの外：/tmp/claude-0/-home-user-world-history-atlas/5a7a987a-a877-559b-b3fe-1574c9cf110f/scratchpad/col_<担当名>/
- git commit はしない。報告は日本語で簡潔に（作った件数と一覧、迷ったもの、データの不具合）。
