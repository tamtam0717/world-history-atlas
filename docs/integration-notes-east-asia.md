# 東アジア（1648–2025）の担当間の整合

担当：G1 中国（data/*/china.yaml）、G2 内陸アジア（data/*/inner_asia.yaml）、G3 日本・朝鮮（data/*/japan_korea.yaml）、G4 分布（data/religion/east_asia.yaml・data/language/east_asia.yaml・data/cities.yaml の東アジア分・data/movements/east_asia.yaml）。
やり方は docs/integration-notes-2025.md と同じ。担当の境界で隣り合うピース（pieces.topo.json の共有辺）の所属（owner・overlord・certainty）を 1648–2025 の全年で比べ、一覧にない食い違いも探した。色は、隣り合う政体の組を全年で拾い、色差（CIE76 の ΔE）の小さい順に見た。

## 整合の結果

### 1. 中国共産党の政権（chinese_soviet）と内モンゴル自治政府（inner_mongolia_ag）

- **色**：chinese_soviet の `#f2a596` は japan（`#eba6a0`）と ΔE 6 しかなく、1938 年の陝甘寧辺区と日本の占領地が見分けにくかった → **`#e0604f`（はっきりした赤）**にした。ソ連（`#d49c87`）とも区別できる。
- **関係**：内モンゴル自治政府（1946–48、G2）は中国共産党の指導下にあったので、`overlord: chinese_soviet`（共産党の赤い帯）を付けた。自治政府自体は uncertain（斜線）のまま。色はソ連（ΔE 9）と近かったので **`#e6c88a`（黄土色）**に変えた。
- chinese_soviet の名前（names）：1945 年末の状態は「解放区」なので、「陝甘寧辺区」を 1937–1944、「中国共産党の解放区」を 1945– にした（1945 年の地図に「陝甘寧辺区」が華北一帯に出ていた）。

### 2. 熱河・満洲の段差

- **赤峰（G2 `juu_uda`）1945–48**：G1 の承徳・朝陽は 1945 chinese_soviet、1946–47 roc、1948 chinese_soviet。G2 の赤峰は 1945 ソ連軍の占領、1946–48 内モンゴル自治政府だった。G2 自身の note のとおり赤峰一帯は共産党の熱河省の機関が治め、ジョーウダ盟が自治政府に入ったのは 1947 年以後なので、**1945–48 を chinese_soviet（certain）**にした（1946 年に国民政府軍が承徳を奪っても、北の赤峰は共産党が保った）。
- **満洲 1931**：G1 は遼寧・吉林・チチハル・洮南（白城）を 1931 年に japan・occupied（「満洲（関東軍の占領）」）、G2 の興安・ジリム（`hinggan_jirim`）は 1932 年の満洲国からだった。興安・ジリムは洮南・チチハル・長春・奉天に囲まれ、嫩江の戦い（1931 年 11 月）の舞台でもあるので、**1931 年に同じ副ラベルの japan・occupied を足した**。ホロンバイル（蘇炳文が 1932 年末まで抵抗）、ハルビン（1932 年 2 月）、錦州・阜新・朝陽（1932 年 1 月以後）は 1931 年は中華民国のまま（史実どおりの段差）。
- **1945 年末のソ連軍の占領の副ラベル**を「（ソ連軍の占領）」の形にそろえた：満洲（G1、そのまま）、G2 のホロンバイル・興安・ジリム「内モンゴル東部（ソ連軍の占領）」→「満洲（ソ連軍の占領）」（旧満洲国の興安省なので G1 と 1 つのラベルにまとまる）、G3「朝鮮北部（ソ連の占領）」「南樺太（ソ連の占領）」「千島列島（ソ連の占領）」「北方領土（ソ連の占領）」→「…（ソ連軍の占領）」。対になる「朝鮮南部（アメリカの軍政）」も「朝鮮南部（アメリカ軍の占領）」にした。旅順・大連（「ソ連軍の管理」「ソ連軍の駐留」）は占領ではないのでそのまま。

### 3. サハリン

- data/regions/north_east.yaml（F 担当）の地域 `sakhalin`（adm1 Sakhalin Oblast 全体）を**削除した**。G3 の `north_sakhalin`・`south_sakhalin`・`north_kurils`・`south_kurils` が全ピースを上書きしていて、地図には効いていないのに、1855 年の「国境の変化」に「日露両国民の雑居地」の名前・理由で出ていた。ほかのファイル・tools・src からの参照はない（宗教・言語は G4 の `rel_sakhalin_*`・`lang_sakhalin_*`、都市 `yuzhno_sakhalinsk` は別物）。削除後もピースのデータの数は変わらない（8050）。

### 4. 出来事

- **重複**：G1・G2・G3 と europe.yaml・west.yaml・north_east.yaml の間に、同じ事件の重複はなかった（アヘン戦争・義和団戦争・日英同盟・日露戦争・三国同盟・太平洋戦争・日本の降伏は europe.yaml だけ、香港の返還は west.yaml だけにある）。担当どうしでは「英仏軍の北京占領と北京条約」（G1）と「北京条約で沿海州がロシア領に」（G2）、「ロシア内戦と対ソ干渉戦争」（north_east）と「シベリア出兵と米騒動」（G3）は主題が違うので両方残した。
- **関係国の追加**：europe.yaml のアヘン戦争に qing、義和団戦争に qing・japan・usa、日英同盟・日露戦争・日独伊三国同盟・太平洋戦争とアメリカの参戦・日本の降伏と第二次世界大戦の終結に japan、west.yaml の香港の返還に prc、north_east.yaml のロシア内戦と対ソ干渉戦争に japan を足した（Edit で polities の行だけ）。
- **同じ題名**：G2 に「清軍のラサ進駐」が 1720 年と 1910 年の 2 件あった（潮流の参照は題名で引くので紛らわしい）→ 1910 年を「清の四川軍のラサ進駐とダライ・ラマ13世の亡命」に改題。
- **潮流の関連づけ**（movements の events）：
  - east_asia.yaml：洋務運動（総理衙門の設置と洋務運動・清仏戦争・甲午農民戦争と日清戦争）、変法運動（戊戌の変法と戊戌の政変・科挙の廃止と中国同盟会・憲法大綱の発表と光緒帝・西太后の死）、三民主義（中国同盟会・辛亥革命・中華民国の成立・中国国民党の結成・第1次国共合作・北伐の開始・北伐の完了）、新文化運動（新文化運動の始まり・五・四運動・中国共産党の結成）、毛沢東思想（中国共産党の結成・長征・中華人民共和国の成立・大躍進・文化大革命・毛沢東の死と四人組の逮捕）、改革開放（改革・開放政策・天安門事件・南巡講話・WTO 加盟・一帯一路）。
  - system.yaml：共産主義に中国共産党の結成・中華人民共和国の成立・朝鮮戦争・中ソ国境紛争、帝国主義に列強の租借地（中国分割）、冷戦に朝鮮戦争・ニクソン訪中。
  - 考証学・国学は対応する出来事がないので空のまま。

### 6. 共産主義の潮流の曲線

data/movements/system.yaml の communism の curve は 2000 年に 0 だったが、中国・北朝鮮（spread）では 2025 年まで続くので、パネルの「この時代の潮流」から消えてしまっていた。**1991 年 0.25、2000 年 0.2、2025 年 0.15** と、ソ連解体後は低いが 0 にしない形にした。text にも「中国・北朝鮮・ベトナム・キューバなどではその後も共産党の一党支配が続く」を足した。

### 7. 冊封の帯・藩部の表示（スナップショットで確認）

### 一覧になかった食い違い（境界の調査）

- **1927 年の国民政府**：G1 は 1927 年末の甘粛・寧夏・山西などを canton_government（国民政府）にしたが、G2 の隣（綏遠・オルドス〈`inner_mongolia`〉、西寧、青海〈`kokonor`〉、アラシャン）は roc（北京政府）で、1 年だけ段差があった。綏遠は山西の閻錫山の勢力下、西寧・青海・アラシャンは馮玉祥の国民軍の勢力下で、どちらも 1927 年に国民政府についたので、G2 の 4 地域に 1927 canton_government・1928 roc を足した。新疆（楊増新が 1928 年に国民政府に従う）とチャハル・熱河（奉天派）は roc のまま。
- **カム 1718–19**：G2 のチャムドは 1718 年から清、G1 のカンゼ（より東）は 1720 年からで、逆向きの段差だった。清の第 1 次の出兵（1718）はジュンガルに敗れ、岳鍾琪の軍が理塘・巴塘を従えたのは 1719 年なので、両方 1719 年にした。
- そのほかの段差は史実どおり（清の直轄と藩部〈indirect〉の境、1912–14 のホロンバイル独立、1918–48 のチベットと西康、1945–48 の国共内戦の前線、シベリアのロシアとの境、1864–77 の新疆の反乱期など）で、変えていない。

## 直さなかったもの・自信のない点

- **シリンゴル 1945–47**（G2、roc・uncertain → 1948 内モンゴル自治政府）：G2 も「要確認」としている。1945 年のスニトの「内モンゴル人民共和国」、1946–47 年の共産党・国民党の勢力の及び方は確かめられていない。
- **赤峰 1946–47**：国民政府軍が赤峰まで進んだ時期があったか確かめられていない（G2 の note の「赤峰には及ばない」に従った）。
- **興安・ジリム 1931**：満洲事変の年末に通遼（ジリム）まで関東軍が押さえていたかは確かめていない（周りの洮南・チチハル・長春・奉天に合わせた）。
- **琉球 1872–78**：G3 は琉球藩の時期を日本の不確実な支配として描く。王国は続いていたので琉球（overlord: japan）とする考え方もあるが、G3 の判断を残した（首都の年だけ合わせた）。
- **カムの年**：1719 年にそろえたが、G1 の note のとおり、打箭炉の掌握（1701）・境界画定（1725–27）など幅がある。
- **色の変更**：日本・中華民国・中国共産党は地図の中で大きな面積を占める色なので、田村さんの好みで変えてもよい（今回は、イギリス・フランスとの区別を優先した）。
- 宗教・言語・都市の人口などの G4 の内容は、この作業では見ていない（スナップショットで塗り漏れがないことだけ確認した）。
