# 独立レビュー：1453–1647 南アジア・東南アジア

対象：data/polities・regions・events の india_north.yaml・india_east.yaml・india_south.yaml・mainland_sea.yaml・maritime_sea.yaml（1453–1647）。共通の指示は docs/agent-brief-1453-asia.md、整合の結果は docs/integration-notes-1453-asia.md。
合意済みの方針（ヨーロッパの拠点は実際に治めた所だけ、ベトナムの明の帯、ビルマ・シャムの宗主権の帯、1648 年以降は原則変えない）は指摘していない。

方法：`npm run data` の後、`node tools/snapshot.mjs` でインド（80,22,2.6）・大陸部東南アジア（102,15,3）・島嶼部（115,0,2.6）を 1453–1647 の主な年で書き出して見た（.cache/snapshots/review1453_sa/）。`--polity rajput_mewar` で右パネルも見た。YAML の 1648 年より前の地域の推移・君主・情勢・出来事（南アジア 109 件、東南アジア 102 件）を通読した。

## 重要度 A

- **[A] 君主がパネルに出ない・1648 年以降の君主も消えた**（data/polities/india_north.yaml の `rajput_mewar` `rajput_marwar` `rajput_amber` `rajput_bikaner` `garhwal` `kumaon` `gondwana`）：君主の項目（`{name, title, from, to, ...}`）が `rulers:` ではなく `periods:` の下に入っていて、`rulers:` は空になっている。その結果、右パネルは「君主　データ未登録」になり、情勢の欄に本文のない「1597–1620」などの行が並ぶ（1600 年のメーワールで確認：.cache/snapshots/review1453_sa/polity/map_1600_zoom_rajput_mewar.png）。**1648 年以降にもともとあった君主**（メーワール 1652–1828 のラージ・シング1世〜ビーム・シング、マールワール 1707–1803、アンベール 1699–1803、ビーカーネール 1700–1787、ガルワール 1717–1785 のプラディープ・シャーなど）も同じく `periods` の下に移っていて、作業前（fa27d0f の前）は `rulers` にあった。整合の照合は所属・分布だけだったので見落とされた。→ 7 政体の `name` を持つ項目を `rulers:` へ戻す（`periods` には `text` のある項目だけ残す）。検証ツールに「periods の項目に text がない／name がある」を警告として足すとよい。確信度：高。

## 重要度 B

- **[B] カリカット王国（ザモリン）に 1453–1647 の情勢・君主がない**（india_south.yaml の `calicut`、ほかに `cochin`）：1453–1647 年の地図に出るが、パネルは空。ヴァスコ・ダ・ガマの来航（1498）・ポルトガルとの戦い（コーチンを保護下に置いたポルトガルとの対立、クンジャリ・マラッカルの水軍）で教科書にも出る国なので、情勢 1〜2 件とザモリンの代表的な君主を足したい。コーチンもポルトガルの保護下に入った経緯（1500–1503）を情勢に。確信度：高（データがないことは確実）。
- **[B] パタニ王国の君主がない**（mainland_sea.yaml の `patani`）：情勢の本文に女王たちの名が出るのに `rulers` がない。ラジャ・ヒジャウ（1584–1616）、ラジャ・ビル（1616–24）、ラジャ・ウング（1624–35）、ラジャ・クニン（1635–49 ごろ）を足せる。確信度：中（在位年は諸説）。
- **[B] アフマドナガル王国の君主の抜け**（india_south.yaml の `ahmadnagar_sultanate`）：ブルハーン2世（–1595）とバハードゥル（1596–）の間に、イブラーヒーム・ニザーム・シャー（1595、ビジャープルとの戦いで戦死）とアフマド・シャー2世（1595–96、擁立をめぐる争い）が抜けている。確信度：中。
- **[B] カシミール・スルタン朝の君主の空白**（india_north.yaml の `kashmir_sultanate`）：1537–1540 年と 1551–1561 年に君主がいない。シャー・ミール朝のナーズク・シャー（1540 年前後と 1551–52）、イブラーヒーム・シャー2世、イスマーイール・シャー、ハビーブ・シャー（–1561、チャク家に廃される）がいる。確信度：中（在位年は史料で揺れる）。
- **[B] チャンパーの明の帯が 1471 年で切れる**（mainland_sea.yaml の `vnm_khanhhoa` `vnm_panduranga` ほか）：政体の情勢には「明への朝貢は 16 世紀半ばまで続いた」とあり、地図と本文が食い違う。本文に合わせて `overlord: ming` を 16 世紀半ば（例：1543 年ごろの最後の朝貢）まで延ばすか、本文の言い方を「名目的」に変える。確信度：中。

## 重要度 C

- **[C] 1559–1647 年のゴルカ王国の地図の名前が「ネパール」**（india_east.yaml の `nepal`、地域 `pre_gorkha`）：この時期はチャウビセ諸国の 1 つの小国で、カトマンズ盆地は「マッラ朝」なので、小さなゴルカに「ネパール」と出るのは少し誤解を招く。1768 年までの既存データも同じ扱いなので、直すなら `short` を時期で変える仕組みか label で「ゴルカ」と出す程度。確信度：中。
- **[C] 表記ゆれ「グワーリヤル」と「グワーリオル」**：政体 `gwalior_tomar` は「グワーリヤルのトーマル朝」、出来事「ローディー朝がグワーリヤル城を取る」、一方で都市・地域名（mp_gwalior など）は「グワーリオル」。地図上で両方が並んで見える（1453・1518 年）。どちらかにそろえる。確信度：高（好みの範囲）。
- **[C] 君主の小さな空白**：ラダック 1485–1555、ランガー朝 1498–1502、チャンパー 1478–1579（南部の王統は史料が乏しいので note で一言）、黎朝 1527–1533（莫登庸の簒奪から荘宗の擁立まで。阮淦を「実権者」として足せる）、トリプラ・マニプルの途中。確信度：中。
- **[C] シャムの君主**：マハー・チャクラパット（1548–1564）は 1564 年に退位し、1568–69 年に復位している。note で一言あるとよい。確信度：中。
- **[C] スペインのホロ占領（1638–46）・テルナテとティドレの砦（1606–）**：地図ではスールー・テルナテのまま。方針（実際に治めた所だけ、砦は描かない）どおりなら問題ないが、ホロは 8 年間スペインの守備隊が置かれたので `certainty: occupied` にしてもよい。確信度：低。
- **[C] 情勢の本文が古い/空の行**：上の A を直せば、ガルワール・クマーオーン・ゴンドワナの空の行も消える。

## 要確認（確信度 低）

- **ティモール全体を 1641 年からポルトガル（nominal）**（maritime_sea.yaml の `kupang` `timor_*` `oecusse`）：ドミニコ会の布教とトパス（黒いポルトガル人）の進出は 1640 年代に始まるが、リファウを拠点にした実効的な影響力は 1650 年代以降という見方が多い。1648 年以降の既存データと同じなので段差はないが、始まりの年は 1641 より少し遅くてもよい。
- **セイロンの 1638 年のキャンディへの切り替え**（india_south.yaml の `pre_lk_seven_korales` `pre_lk_sabaragamuwa` `pre_lk_hambantota`）：ガンノルワの戦い（1638）の後もポルトガルは内陸の一部（サバラガムワ・七コーラレの砦）を 1650 年代まで保ったという記述がある。1648 年の既存データ（lk_coast_1766 ＝ kandy）につながる書き方なので、1638 年の時点で「不確実」にとどめるかどうか。
- **タトン・マルタバンの 1600–1612 年の siam[uncertain]**（mainland_sea.yaml の `mmr_thaton` `mmr_martaban`）：ナレースワンのモン地方への進出は確かだが、マルタバンはトングー側の諸侯・モンの首長が入れ替わった時期で、「所属なし（不確実）」でもよいかもしれない。
- **1453 年のロンヴェーク**：都市が 1453 年から地図に出ている（首都の印はない）。ロンヴェークが王都になるのは 16 世紀半ばで、都市としての成立年（founded）もそのころ。
