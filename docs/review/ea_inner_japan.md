## 指摘

### 重要度 A

- **[A] 琉球の色（polities/japan_korea.yaml `ryukyu`、1648–1871）**：琉球 `#f0cf86` と清 `#ecc978` の色差が ΔE 4.8 しかない。冊封の見せ方（独自色＋清の色の帯）は、本体と帯の色がほぼ同じなので帯が見えず、琉球が清の一部（あるいは台湾〈1683– 清〉と同じ国）に見える。1700 年の地図（.cache/snapshots/review_ea_ij/ok/map_1700_zoom.png）で、沖縄島は清と同じ黄色に見え、帯は見分けられない。田村さんの決定「冊封は独自色＋清の帯」が琉球では実際には伝わっていない → 琉球を清・日本（`#d97a9a`）・朝鮮（`#b3d3a2`）・オランダ東インド会社など、近くの色から離れた色（例：青緑や薄紫の系統）に変える。確信度：高。

### 重要度 B

- **[B] チベットの元首の空白（polities/inner_asia.yaml `tibet`、1934–1949）**：ダライ・ラマ13世は 1933 年 12 月に死去し、14世の欄は 1950 年から。チベットが事実上独立した国として地図に出ている 1934–1949 年に、パネルの元首が空になる → 摂政レティン・リンポチェ（1934–1941）、タクタ・リンポチェ（1941–1950）を rulers に加える（14世は 1940 年に即位）。同じく、1912–1932 は 13世で埋まっているが、1648–1716 の期間の 1682–1696（5世の死の秘匿期間、摂政サンギェ・ギャツォ）も空なので、摂政を ruler として入れるとよい（C 相当）。確信度：高。
- **[B] 北海道と北方領土の確かさの食い違い（regions/japan_korea.yaml `hokkaido`・`south_kurils`、1855–1868）**：日露和親条約（1855）で択捉島以南は `japan`（確実）になるが、同じ年に幕府が全域を直轄にした北海道本島は `nominal`（白い斜線）のまま 1868 年まで続く。地図（sk/map_1860_zoom.png）では、国後・択捉が濃い実線で、その手前の北海道が斜線になり、北方の島のほうが「確かな日本」に見える → どちらかにそろえる。案：1855 年の幕府直轄を境に北海道も確実（あるいは北方領土を 1868 年まで nominal のまま、1869 年の開拓使で両方確実）。確信度：中（どちらにそろえるかは方針の問題だが、今の段差は不自然）。
- **[B] 琉球 1872–1878（regions/japan_korea.yaml `okinawa`）**：整合でも「自信のない点」に残っている。琉球藩の時期も王国は存続し、1874 年まで清への進貢も続けた（禁止は 1875 年）。高校世界史では「1879 年の琉球処分で王国が滅んだ」と教えるので、1872–1878 は `ryukyu`（overlord: qing のまま、または 1875 年から overlord: japan）とし、琉球藩の設置は note で示すほうが教科書に近い。今は 1872 年から日本の色（斜線）になり、1879 年の出来事「琉球処分」の地図上の変化が見えない。確信度：中。
- **[B] モンゴルの首相の名前（polities/inner_asia.yaml `mongolia`、1923–1928）**：「バルダンドルジ・ツェレンドルジ」は父称が違う。Balingiin Tserendorj ＝「バリンギーン・ツェレンドルジ」（日本語版 Wikipedia の表記もこれ）。確信度：中。
- **[B] シリンゴル 1945–1947（regions/inner_asia.yaml `xilingol`）**：roc・uncertain としているが、1945 年 8 月以後シリンゴル・チャハルの両盟は、ソ連・モンゴル軍の占領の後、ウランフーの内モンゴル自治運動連合会（1945 年 11 月、張家口。中国共産党の指導下）の勢力圏に入り、国民政府の支配はほとんど及ばなかったとされる → 1945 年をソ連軍の占領（隣の興安・ホロンバイルと同じ）、1946–47 を inner_mongolia_ag（overlord: chinese_soviet、uncertain）とするほうが実態に近い。G2・整合とも要確認としている点。確信度：低〜中（要確認）。

### 重要度 C

- **[C] 年の小さな食い違い**：
  - events/inner_asia.yaml 1682「死を15年近く隠して」と、polities `tibet` のダライ・ラマ5世の note「1696年まで隠された」。公表は 1697 年（6世の即位と同じ年）なので、note を「1697年まで」にそろえる。
  - events/japan_korea.yaml 1894「日英通商航海条約で領事裁判権が撤廃された」→ 調印は 1894 年、撤廃の発効は 1899 年。「撤廃が決まった（1899年に施行）」とするとより正確。
  - events/inner_asia.yaml 2006「青海省の西寧（ゴルムド）とラサを結ぶ」：西寧–ゴルムドは 1984 年開通で、2006 年に開通したのはゴルムド–ラサ。「西寧からゴルムドを経てラサに至る青蔵鉄道が全線開通した」のように直す。
  - polities `mongolia_west`（regions/inner_asia.yaml）は 1755 年から qing・indirect だが、同じ年のイリ・タルバガタイ・ウルムチは「アムルサナの反乱（1755–57）」で uncertain。ホブド一帯も反乱の範囲なので 1755–1756 は uncertain にそろえてもよい。
- **[C] 白頭山定界碑（events/japan_korea.yaml 1712）**：碑文は「西は鴨緑、東は土門」で、「土門江」が豆満江かどうかがのちの間島問題の争点になった。「鴨緑江と土門江（豆満江とされる）を境とした。土門江の解釈はのちに間島問題の原因となった」とするとよい。
- **[C] 情勢（periods）のすき間・重なり**：`mongolia` は 1940–1944 が空（1921–1939 の次が 1945–）。`japan` は 1894・1945・1952 が前後の 2 つの期間に重なる（1868–1894 と 1894–1918 など）。パネルで 2 件出るか、どちらかだけ出るかを確かめ、境の年をずらす。
- **[C] 隣り合う色**：北朝鮮 `#e2b08a` とソ連 `#d49c87` は ΔE 10.8（豆満江の短い国境だけなので軽微）。
- **[C] アルバジン（regions/inner_asia.yaml `amur_primorye_pre1858`）**：1665–1689 年はロシアのアルバジン砦がアムール州のピースにあった（1685・1686 年に清が攻める）。ピースの過半ではないので qing・nominal のままでよいが、1665–1688 年は uncertain（ロシアと係争）にすると、1689 年のネルチンスク条約の地図上の意味が出る。
- **[C] ハバロフスク地方（regions/north_east.yaml `khabarovsk` 相当、担当外）**：1648–1857 年がロシア・uncertain で、隣の G2 のアムール州・沿海州（清・nominal）と食い違う。ネルチンスク条約ではアムール川下流（ハバロフスク・ニコラエフスク）も清の側で、ロシア領はオホーツク海岸。1 ピースなのでどちらかに決めるしかないが、note で「アムール川下流は清の側」と書いている以上、境の不連続は note で十分か確認したい。
- **[C] ピースの粒度で描けないもの（既知）**：奄美（1946–53）・小笠原（1946–68）のアメリカの施政、北緯 38 度線と休戦ラインの違い（開城・甕津・束草・鉄原）。どれも note で説明されている。地図で見せたい場合は、ピースの分割（鹿児島県の奄美群島、東京都の小笠原村、開城特別市など）が必要。
- **[C] ヤルカンド・ハン国のアブドゥッラー・ハン（polities `yarkent`、1638–1669）**：1667 年ごろに退位してインドへ去り、その後ユルバルス・ハン（1667–1669）が立ったとする説明が多い。要確認（確信度：低）。
- **[C] 日本の名前（polities `japan` の names）**：「大日本帝国」を 1868 年から使っているが、国号として定着するのは 1889 年の大日本帝国憲法から。1868–1888 を「日本（明治政府）」などにしてもよい（好みの範囲）。
