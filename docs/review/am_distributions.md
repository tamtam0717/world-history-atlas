# 独立レビュー：南北アメリカの宗教・言語（民族）の分布、都市、潮流（1648–2025）

対象：data/religion/americas.yaml・secular.yaml（南北アメリカの項目）・_kinds.yaml、data/language/americas.yaml・_kinds.yaml、
data/cities.yaml（「南北アメリカ」の節、95 都市）、data/movements/americas.yaml と、art・religion・system・thought の各 movements ファイルのアメリカの spread。

方法：
- YAML を通読した。`npm run data` を実行し、エラー・警告がないことを確かめた（宗教 12,990／言語 12,985 ピースにデータあり）。
- 地図：`.cache/snapshots/review_am_dist/`
  - `religion/`・`language/`：`--zoom -80,10,1.3`（1650, 1750, 1850, 1900, 1950, 2025）
  - `na_religion/`・`na_language/`：北アメリカ中部 `--zoom -98,45,1.6`（1750, 1850, 1900, 2025）
  - `sa_religion/`・`sa_language/`：南アメリカ南部 `--zoom -60,-25,1.4`（1750, 1900, 2025）
- atlas.json から、アメリカの全ピースについて 1648–2025 年の宗教・言語を1年ごとに取り出し、次を機械的に照合した。
  1. 宗教が「その他（先住民の信仰）」なのに、言語がヨーロッパの言語・クレオール語になっている年（入植者が多数なのに信仰が先住民のまま、という食い違い）
  2. 宗教がキリスト教になる年と、言語がヨーロッパの言語になる年の差（30 年以上）
  3. 宗教・言語が入植者の色になる年と、政治のデータでその土地が入植国の確実な支配（certainty: certain）になる年の差（15 年以上早いもの）
  4. 既定値の地域（lang_us_base など）がそのまま残っているピース
- 色の見分けやすさは、_kinds.yaml の色と src/map.ts の「データ未整備」（REL_NODATA #e2e0dc）の CIELAB の色差（ΔE）で確かめた。

重要度：A＝地図や事実が明らかに誤り、B＝不正確・改善すべき、C＝好みや細部。

### 宗派の塗り分け

### 色の見分けやすさ

- **[B] 「データ未整備」（#e2e0dc）と近い色**：ΔE はエスキモー・アレウト語族 8.2、メソアメリカのその他 15.0、南米のその他（sa_other）15.2、チャコ・パタゴニア 18.8（参考：ほかの語族はたいてい 25 以上）。

## C（好みや細部）

- **[C] evangelical の名前「プロテスタント（…福音派）」**：ルター派・改革派・国教会もプロテスタントなので、凡例で「プロテスタント」が1つだけあると紛らわしい。高校世界史では「メソジスト」「バプテスト」と個別に出てくることが多い。「福音派（バプテスト・メソジストなど）」の方が誤解が少ない。
- **[C] アイダホ全体（1ピース）を 1880 年から lds**：docs では「アイダホ南東部」とあるが、ピースは州全体なので州全体が lds になる。州全体でも LDS が最大の宗派なのでおおむねよいが、docs の書き方を「アイダホ（南東部が中心）」に。
- **[C] ユーコン（宗教 1910、言語 1900）、サグネ（宗教 1870、言語 1860）、チリのパタゴニア（宗教 1900、言語 1890）、ベリーズ市（宗教 1800、言語 1790）**：10 年のずれ。ゴールドラッシュのユーコンは 1898 年なので両方 1900 年でよい。
- **[C] ハイチの言語が 1648 年から french**（`lang_haiti`）：1648 年のイスパニョーラ島西部はほぼ無人で、フランス人はトルトゥーガ島のバッカニアだけ。政治の地図と合わせるなら 1660〜70 年（ジャン・ド・ポワントの総督 1665）から french でもよい。
- **[C] パナマ市の座標**（9.01, -79.49）はパナマ・ビエホ（1671 年に焼かれた旧市街）の位置。1673 年からの現在の旧市街（カスコ・ビエホ）は約 7 km 西（8.95, -79.53）。
- **[C] シウダー・トルヒーヨの名前が 1936–1961**：1961 年 11 月にサント・ドミンゴに戻ったので、年末の状態では 1936–1960。
- **[C] アスンシオンの capital（1811–1868）**：1868 年 2 月に首都はルケへ移り、1869 年 1 月にアスンシオンは連合軍に占領された。年末で数えると 1868 年は首都でない（to: 1867）。
- **[C] 首都の空白**：チリ 1810–1817（サンティアゴ、パトリア・ビエハ）、エクアドル 1811–1812（キトの自治政府）、テキサス 1836・1842–1844（コロンビア／ワシントン＝オン＝ザ＝ブラゾス）、ハワイ 1795–1844（ラハイナ・カイルア）など。政体があるのに capital のない年がある（都市を足すか note で）。
- **[C] ラテンアメリカの独立運動の全体の curve が 1898 年 0.2 で終わる**（範囲外は 0）のに、キューバ・ドミニカの spread は 1902 年 0.4 まで続く。全体の curve に [1902, 0.2] を足すと帯と地図がそろう。
- **[C] カウディーリョの people にサルミエント**：サルミエントは『ファクンド』でカウディーリョを批判した側。text で「批判者」と書いているならよいが、people の並びだけ見ると代表的なカウディーリョに見える。
- **[C] インディヘニスモに 2006 年（エボ・モラレス）を最大（1.0）**：20 世紀前半の国家主導のインディヘニスモと、1990 年代以後の先住民自身の運動（インディアニスモ・多民族国家）は区別されることが多い。text では触れているので、名前を「インディヘニスモと先住民運動」にすると誤解がない。
- **[C] 宗教と言語の潮流に、20 世紀後半のラテンアメリカのペンテコステ派の広がり**（宗教の分布では 1990 年から minor で出している）がない。religion の潮流として足すと、分布の変化と結びつく。

## 問題がなかった観点

- **ケベックのフランス語**：セントローレンス川流域・領主制の農村・サグネ・アビティビの開拓の年、モントリオールの英語系の時期（1831〜65 年ごろ）とフランス語系への復帰、イースタン・タウンシップスのフランス系化（1880）は通説どおり。ケベックの宗教もカトリックで一貫し、「静かな革命」の世俗化（1965–）も妥当。
- **ルイジアナのフランス語**：ニューオーリンズ（1730 french／creole_french → 1840 english）、アカディアナ（1780 ケイジャン、1810 クレオール語の minor）の扱いは妥当（上記のアカディアナの宗教の年を除く）。
- **アフリカ系の住民の言語**：クレオール語（ジャマイカ・小アンティル・ハイチ・スリナム・ガラ・ベリーズ・ミスキート海岸・リモン・ボカス）と、ヨーロッパの言語を話す地域（アメリカ南部・ブラジル・キューバ）の分け方は、方針（docs/language-format.md）どおりで一貫している。キュラソーのパピアメント語、スリナムのマルーン（ンジュカ・サラマカ）の creole_english と宗教 other（ウィンティ）も妥当。
- **メスティーソ化の年**：メキシコ中央高原 1850・山地 1880、ユカタン・オアハカ・チアパス高地・グアテマラ西部高地・ペルー南部の高地・アルティプラノを先住民の色のまま残す扱い、パラグアイのグアラニー語は方針どおりで通説とも合う。
