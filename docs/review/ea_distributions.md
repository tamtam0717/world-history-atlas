## 重要度 A

- **[A] ボルタラ（religion: rel_dzungaria_han ／ language: lang_bortala、CHN-Boertala、1760–1969）**：宗教と言語の層が食い違っている。言語では 1760 年から main が `mongolian`（清が駐屯させたチャハル部のモンゴル人、minor はカザフ語）なのに、宗教では同じピースが 1760 年から `sunni` になっている（rel_dzungaria_han の 1760 の項目。小さい地域が優先なので rel_dzungaria の値は効かない）。モンゴル人が多数なら宗教は `tibetan_buddhism`（minor sunni）のはず。docs/language-format.md の「宗教と同じピースでは切り替えの年と多数派をそろえる」にも反する → ボルタラだけ別の宗教の地域にして、1760 年は tibetan_buddhism ＋ minor sunni、1970 年は chinese_folk ＋ minor（sunni か tibetan_buddhism）にする。確信度：高（層間の矛盾であることは確実。どちらに合わせるかは、ボルタラ・モンゴル自治州の成り立ちを考えると言語の側が正しい）。
- **[A] 江戸・東京の人口（cities.yaml の tokyo、1700–1850）**：pop は 1700: 690,000・1750: 700,000・1800: 690,000・1850: 780,000 なのに、同じ項目の note には「18 世紀には人口 100 万人前後（武家を含む推計）で世界最大級の都市」とある。高校の日本史・世界史の教科書の通説も「18 世紀前半に 100 万人を超え、世界最大級」。今の値だと、地図の点の大きさで江戸が北京（1750: 900,000、1800: 1,100,000）より小さく見え、note・教科書と矛盾する。Chandler の値は武家人口を含まない推計なので、武家を含む値に上げる → 1700: 1,000,000 前後、1750: 1,100,000、1800: 1,100,000、1850: 1,100,000 程度（または note を値に合わせて直す。ただし教科書に寄せる方針なら値を上げるべき）。確信度：高（通説としての「100 万人」）。

## 重要度 B

### 宗教・言語の地域と年
- **[B] タルバガタイ・アルタイ（rel_dzungaria の CHN-Tacheng・CHN-Aletai ／ lang_tacheng・lang_altay_han）**：
  1. 宗教は 1760 年から `sunni`、言語は 1770 年から `turkmen_kazakh` で、10 年ずれている（1760–69 年は宗教がイスラームなのに言語はモンゴル語）。
  2. そもそもカザフ人がこの地域で多数になるのは、もっと遅いと思われる。清はジュンガル平定の後、カザフ人には季節の放牧しか認めず、1771 年にはヴォルガから帰還したトルグート部・ホシュート部をタルバガタイ（ホボクサル・ウス）に住まわせた。アルタイは 1919 年までホブド（モンゴル）の管轄で、アルタイ・ウリャンハイ（モンゴル系の仏教徒）の地。カザフ人の大量の移住はロシア領からの移住が増えた 1860〜80 年代以後。
  → 宗教・言語とも 1771 年はモンゴル系（tibetan_buddhism／mongolian）＋ minor カザフ、1870〜1880 年ごろに sunni／turkmen_kazakh へ切り替える。両方の層で同じ年にする。確信度：中。
- **[B] 南千島（rel_kurils_south・lang_kurils_south、1800）**：1800 年から main が和人（shinbutsu／japanese）、minor がアイヌ。高田屋嘉兵衛による択捉の漁場開設（1799–1800）は事実だが、和人の多くは季節の出稼ぎで、定住人口でアイヌを上回ったとは考えにくい（クナシリ・メナシの戦いの後もアイヌは漁場の労働力として住み続けた）。→ 1800 年は main アイヌ（other／ainu）＋ minor 和人とし、和人が多数になるのは明治の開拓（1870 年ごろ）からにする。確信度：中。
- **[B] チュクチ（rel_sib_northeast・lang_sib_chukotka）**：宗教はマガダンとまとめて 1935 年に orthodox（minor other）、言語ではチュクチは 1950 年まで paleosiberian。チュクチの切り替え年が層の間でずれている → 宗教の地域をマガダン（1935）とチュクチ（1950）に分ける。確信度：高（ずれ自体は確実）。
- **[B] 北海道（JPN-Hokkaido が1ピース）**：北海道全体が1つのピースなので、1648–1868 年は全島がアイヌ（灰色）、1869 年に一斉に和人の色に変わる。松前藩の和人地（渡島半島南部）は江戸時代から和人の土地で、19 世紀半ばには和人の人口がアイヌを上回っていた。→ tools/pieces_config.json で渡島・檜山（和人地）を分け、和人地は 1648 年から shinbutsu／japanese にする。ピースの分割はデータ担当の範囲外かもしれないので、次のピース改良の候補として。確信度：高（地理の事実）、優先度は中。
- **[B] 韓国の中部（rel_skorea_east の忠清道・大田・世宗・江原道、2015 年以後）**：2015 年の国勢調査では、仏教が最大なのは慶尚道（釜山・大邱・蔚山を含む）と済州で、大田・忠清南道・世宗などはプロテスタントが仏教を上回る（2005→2015 年で仏教徒が大きく減った）。→ 2015 年の項目を足し、忠清・大田・世宗（と江原道）を reformed（minor mahayana）にする。確信度：中（道ごとの順位は要確認）。
- **[B] 新疆の世俗化を漢人の地域にも適用している（secular.yaml の sec_xinjiang）**：sec_xinjiang は新疆全体（adm1）を選ぶので、漢人が多数のウルムチ・昌吉・石河子・カラマイ・ハミなど（chinese_folk）も 1980 年以後 0.25 になり、隣の甘粛（sec_china 0.5）より宗教色が濃く見える。2017 年の 0.4（ウイグル人への規制）も漢人の地域に及ぶ。→ sec_xinjiang をムスリムが多数の地域（rel_tarim・rel_akesu・rel_dzungaria の残りなど）に絞り、漢人の地域は中国本土と同じ値にする。確信度：高（データの仕組みとして）。

### 都市

### 潮流
- **[B] 日本の潮流が植民地（朝鮮・台湾・樺太）でも光る（movements/east_asia.yaml の taisho_democracy、three_principles の japan、bunmei_kaika）**：spread が `polities: [japan]` なので、1910 年以後の朝鮮、1895 年以後の台湾も日本本土と同じ強さで光る。大正デモクラシー（1925 年の普通選挙など）は朝鮮・台湾には及ばず、むしろ三・一独立運動の弾圧や治安維持法の適用の時代だった。中国同盟会（三民主義）の日本での活動（東京）も、朝鮮・台湾まで光らせる理由はない。→ 日本本土の政治の地域（regions）で書くか、植民地を除く指定にする。帝国主義（system.yaml の imperialism）は植民地が光ってよい。確信度：高。
- **[B] 清の学問・改革がモンゴル・チベット・新疆まで光る（kaozheng・self_strengthening・reform_movement_1898 など）**：ファイル冒頭に「目安」と断っているが、考証学や洋務運動がチベット・外モンゴルで同じ強さで光るのは見た目の誤解を生む。→ 中国本土（と満洲）の地域 ID を regions で書く。確信度：中（表示の仕組みでできるなら）。
- **[B] 東アジアの抜け**：
  - 東学（1860 年、崔済愚。甲午農民戦争 1894 につながる宗教運動。kind: religion）：教科書の必須項目。
  - 日本の軍国主義（超国家主義）：system.yaml の fascism の spread に日本が無い。高校世界史ではファシズム諸国（枢軸国）の一つとして扱われる。1930 年代〜1945 年の japan を足す（帝国主義には入っている）。
  - ナショナリズム（thought.yaml）に東アジア（三・一運動、五・四運動、中国の民族運動）の spread が無い。
  - 東アジアの高度成長（east_asian_growth）の本文に香港・シンガポールが出てくるのに、香港の spread が無い。
  確信度：高（抜けであることは確実。どこまで入れるかは方針次第）。

### 色
- **[B] 言語の色：カザフ語など（turkmen_kazakh #dcbe98）とシベリアのテュルク系（siberian_turkic #e3cba8）の差が小さい（ΔE≈5）**：バヤン・ウルギー（1870〜）・新疆のアルタイ（カザフ）と、隣のアルタイ共和国・トゥヴァ（シベリアのテュルク系）が隣り合い、見分けにくい。ブリヤート語（#e2dbb0）とシベリアのテュルク系も ΔE≈9 で、ブリヤートとトゥヴァ・ヤクーチアが隣り合う 1648–1900 年は見分けにくい。→ siberian_turkic をもう少し明るく黄みに寄せるか、茶系の中で彩度を変える。確信度：中（色差の計算と 1650・1930 年の画像による）。

## 重要度 C

- [C] 宗教の色：朝鮮の `confucian`（儒教）は、北朝鮮の世俗化 0.8 ではほぼ白に見え、2025 年の地図では「無色の国」に見える。意図どおりだが、凡例の「薄い色＝世俗化」が目に入らないと「データなし」と区別しにくい。
- [C] 宗教の名前：`chinese_folk` の名前に「儒教」が入っているので、朝鮮だけ「儒教（朝鮮）」として別の色になっている理由が凡例から分かりにくい。docs の説明（朝鮮王朝の国教としての朱子学、崇儒抑仏）を、凡例のツールチップか note に短く出すとよい。
- [C] 琉球（rel_okinawa）は 2025 年まで `other`（灰色）。シベリアのシャーマニズムと同じ色になる。祖先崇拝・御嶽の信仰が中心という判断は妥当だが、「その他」の灰色ではなく、日本の神仏習合とアニミズムの間の色を作る手もある（好み）。
- [C] 攀枝花（CHN-Panzhihua）：言語は 1965 年までイ族（tibeto_burman）が main なのに、宗教には rel_yi_lisu の対象に入っておらず chinese_folk。麗江（ナシ族、言語は tibeto_burman）も同じ。言語と宗教の食い違いは小さい地域なので C。そもそも攀枝花の谷（米易・塩辺）は清代から漢人も多く、言語の main が tibeto_burman かどうかも要確認。
- [C] チチハル（lang_qiqihar、1648）：ダウール人・ソロンが嫩江流域に移されたのは 1650 年代なので、1648 年はまだ人口がわずかな地。影響は小さい。
- [C] 承徳（CHN-Chengde）はずっと中国語・chinese_folk。17 世紀にはハラチン部などのモンゴルの牧地で、漢人の入植は 18 世紀（熱河の開発）から。遼西（朝陽・阜新）と同じ扱い（1800 年まで mongolian）でもよい。
- [C] 吉林（中部・南部）の漢人化を 1880 年としているが、長春庁（1800）の設置が示すように、中部では 19 世紀前半から漢人の農民が多く、1850 年ごろの切り替えでもよい。1880 年でも「目安」の範囲。
- [C] 世俗化：sec_tibet_qinghai が regions: [rel_tibet] で選ぶため、1960 年に漢人が多数になった海北（rel_haibei）にもチベットの値（1966 年 0.6、1980 年 0.25）が入る。中国本土の値でよい。
- [C] 樺太・千島の世俗化（sec_karafuto_kurils）は 1947 年 0.6 で、同じ年のシベリア（sec_siberia、1943–58 年 0.45）より高い。根拠がなければシベリアにそろえる。
- [C] 潮流：変法運動（reform_movement_1898）の japan の spread（康有為・梁啓超の亡命）は、日本全体を光らせるほどのものではない。考証学の japan（1700 年 0.2）は、日本の考証学派（大田錦城ら）は 18 世紀末〜19 世紀前半なので、1700 年の値は荻生徂徠の古文辞学と混ざっているように見える（1780 年ごろから始めてよい）。
- [C] 都市：武漢の capital に 1927 年の武漢国民政府（国民党左派）が無い（note には書いてある）。ユジノサハリンスクの「豊原」は 1908 年の命名なので names は 1908 年からが正確（1906–07 年はウラジーミロフカのまま）。
- [C] 鹿児島県の奄美群島は琉球語圏だが、鹿児島県が1ピースなので表せない（ピースの限界として note に書いておく程度）。

## 要確認（確信度が低いもの）

- 西シベリア（rel_sib_tyumen・lang_sib_tyumen）を 1648 年に sunni／tatar の main としているが、トボリスク・チュメニ・トゥリンスクの周辺には 1640 年代までにロシア人の農民がかなり入植しており、1648 年の時点ですでにロシア人が多数だった可能性がある（切り替え 1700 年は遅いかもしれない）。
- オルドス（CHN-Eerduosi）の漢人化 1930 年：南部（ジュンガル旗・ダラト旗）の漢人化は早いが、オルドス全体で漢人が多数になったのは 1950 年代以後かもしれない。通遼（ホルチン）は 1930 年でよいと思う。
- 黔南（CHN-Qiannan）を 1800 年以後もプイ族（zhuang_tai）main としているが、現在の黔南州は漢族が4割余りで最大の民族。少数民族の合計では過半なので、main をどうするかは方針次第。
- ユダヤ自治州のユダヤ人の割合「最も多い時期でも2割に届かなかった」：国勢調査（1939 年 16％）ではそのとおりだが、1948 年ごろの推計では4分の1前後とするものもある。

## 問題がなかった観点

- **多数派の宗教の決め方**：中国の漢人を儒・仏・道の民間信仰（chinese_folk）、日本を神仏習合（shinbutsu）、朝鮮王朝を儒教（confucian）でまとめる方針は、高校世界史の説明（宋学・朱子学、日本の寺請制度と神仏習合、朝鮮王朝の崇儒抑仏）と合っており、妥当。韓国を 1985 年以後にプロテスタント（西部）と仏教（嶺南）に分けるのも国勢調査と合う（2015 年の中部の扱いだけ B）。仏教圏を赤〜桃色でそろえる色の考え方も分かりやすい。
- **宗教と言語の年の整合**：上の A・B（ボルタラ、タルバガタイ・アルタイ、チュクチ）以外は、内モンゴル（1800・1900・1930・1950・1970）、満洲（遼西 1800、吉林 1880、吉林西部 1910、黒龍江 1900、北部 1930）、延辺（1900・1970）、台湾（1662・1720・1760・1810・1880・1950）、北海道（1869・1890）、樺太（1907・1947）、シベリア各地の切り替え年が両方の層でそろっている。
- **漢人移住の年**：台湾（台南 1662＝鄭成功、西部 1720、北部 1760、宜蘭 1810＝噶瑪蘭庁、南投 1880＝開山撫番、東部 1950）、内モンゴル（走西口、移民実辺 1902–）、満洲（封禁と闖関東）、新疆（ウルムチ 1760、兵団・石油の 1958–70）は通説と合う。延辺の朝鮮族が半数を割る時期（1960 年代）も 1970 の切り替えで表せている。
- **アイヌ・琉球**：アイヌ（言語 ainu・宗教 other）、樺太アイヌ・千島アイヌ（北千島の正教化、1884 年の色丹島への移住）、琉球語を 1945 年まで main、以後 japanese＋斜線とする扱いは方針どおりで妥当。
- **世俗化の値**：中国（1949・1958・1966–76・1978）、北朝鮮（1958 年 0.8）、モンゴル（1937–39 の粛清、1990 の民主化）、トゥヴァ、日本（戦後に上昇）、韓国（2015 年の 56％）、台湾（低い）の流れは docs の目安どおりで、1970 年の地図では中国・モンゴル・北朝鮮が薄く、台湾・南の地域との差が見た目で分かる。
- **都市の首都の期間**：北京（清・北京政府、1928–48 北平）、南京（太平天国の天京 1853–63、国民政府 1928–36・1946–48、汪兆銘政権 1940–44）、重慶（1937–45）、台北（1949–）、広州（1917–26）、瑞金（1931–33）、延安（1937–46）、長春＝新京（1932–44）、首里（–1871）、台南（東寧 1662–82）、昆明（南明 1656–58、呉三桂の周 1679–80）、ソウル（漢城–1909、京城 1910–45、釜山の臨時首都 1951–52）、平壌（1948–）、フレー→ウランバートル（1924 改称）、チタ（極東共和国 1920–21）、クズル（1921–43）、ラサ、ヤルカンド、カシュガル（ヤークーブ・ベク）は年末の状態の決まりで正しい。名前の切り替え（江戸→東京、奉天、帰化城→帰綏→厚和、迪化→ウルムチ、打狗→高雄、ダーリニー→大連、ハバロフカ→ハバロフスク）も正しい。人口の多く（北京・広州・杭州の Chandler 値、1950 年以後の国連の都市圏の値）も通説の範囲。
