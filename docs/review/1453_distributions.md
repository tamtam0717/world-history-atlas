# 独立レビュー：1453–1647 の分布・都市・潮流・出来事（ヨーロッパ・中東・北アフリカ）

レビュー担当（作成に関わっていないエージェント）、2026-11-24。データは読むだけで、変更していない。

## 対象と方法
- 対象：data/religion（_kinds.yaml の hussite を含む）・data/language・data/cities.yaml・data/movements・data/events/europe.yaml の 1453–1647。
  形式は docs/religion-format.md・docs/language-format.md・docs/movements-format.md、整合の結果は docs/integration-notes-1453.md を参照した。
- 地図：`node tools/snapshot.mjs 1453 1500 1520 1530 1545 1560 1580 1600 1620 1640 --zoom 15,47,2 --layer religion`、
  言語は 1453・1500・1560・1600・1640（.cache/snapshots/review1453_dist/）。
- `npm run data` で作った atlas.json から、ピースごとに 1453–1647 の main・minor と効いている地域を書き出して読んだ
  （宗教 315 地域・言語の変化のある地域を全部）。あわせて次の機械的な照合をした：
  - 宗教と言語の食い違い（テュルク・アラビア語なのにキリスト教、正教の民族なのにカトリック・プロテスタントなど）を 1453・1500・1530・1560・1600・1640 年で。
  - 1647 年と 1648 年のつなぎ目の段差（宗教 443 ピース・言語 161 ピースで値が変わる。下の「問題のなかった観点」）。

重要度：A＝地図や事実が明らかに誤り、B＝不正確・改善すべき、C＝好みや細部。確信度は（高・中・低）。

## 重要度 A

- **[A] ハンガリーの宗教改革の多数派が描かれていない**（data/religion/central.yaml：`rel_hungary`〈セーケシュフェヘールヴァール・ザラなど 15 ピース〉、
  `rel_hungary_transdanubia_mixed`〈ヴェスプレーム・ショモジ・トルナ・バラニャ・エステルゴムなど 40〉、`rel_hungary_between_rivers`〈ドナウ・ティサ川間、65〉、
  `rel_heves`〈7〉。1560–1647）：
  4 地域・約 127 ピースが 1560–1647 年を通じて **catholic が main**（minor reformed、ヘヴェシュは minor なし）のまま。
  ところが `rel_hungary` 自身の note に「16世紀末には住民の大多数がプロテスタント」とあり、塗りと説明が矛盾している。
  16 世紀後半〜17 世紀前半のハンガリーは住民の 8〜9 割がプロテスタントとされ、とくにオスマン領のドナウ・ティサ川間
  （ケチケメート・ナジケーレシュ・ツェグレードなど「カルヴァン派の町」）は改革派が圧倒的だった。いまの地図では
  1600 年にハンガリーの中央部がカトリックに見え、宗教改革の広がりで最も目立つ地域の一つが抜けている。
  → 目安として：`rel_hungary_between_rivers` は 1560（または 1570）から main reformed（minor catholic）、
  `rel_hungary_transdanubia_mixed` は 1570 から reformed（minor catholic。西部はルター派も多い）、`rel_hungary` は 1570–1630 を reformed または lutheran（minor catholic）にして
  パーズマーニの再カトリック化（1630 前後、王領ハンガリーの西部）から catholic/reformed に戻す、`rel_heves` は 1560 から少なくとも minor reformed。
  `rel_hungary_east_reformed` の 1550–1564（catholic/lutheran）も、1550 年代にはティサ川以東の大半がプロテスタント（はじめルター派、ついでカルヴァン派）なので
  1550 を lutheran/catholic にするとよい。1648 年以後の値（catholic/reformed）は対象外だが、同じ理由でドナウ・ティサ川間は 1648 年以後も改革派の main が自然（1690 年代の再植民の前まで）。
  （根拠：Wikipedia「ハンガリーの宗教改革」、デブレツェン・ケチケメートの改革派、パーズマーニ・ペーテルの対抗宗教改革。確信度：事実は高、切り替えの年は中）

- **[A] メリリャの 1453–1496 年がカトリック・スペイン語**（`ESP-Melilla`：宗教 `rel_iberia`、言語 `lang_spain_base`）：
  メリリャがスペイン（メディナ・シドニア公）に占領されたのは 1497 年で、それまではモロッコ（ワッタース朝の支配圏）のムスリムの町。
  → 1453–1496 年は sunni・arabic（または berber）、1497 年から catholic・spanish。（根拠：メリリャの征服 1497。確信度：高）
- **[A] セウタの 1453–1640 年の言語がスペイン語**（`ESP-Ceuta`：`lang_spain_base`）：
  セウタは 1415 年からポルトガル領で、住民はポルトガル人（1640 年のポルトガル再独立のときにスペイン王側にとどまり、1668 年のリスボン条約でスペイン領）。
  → 1453–1640 年ごろは portuguese（政治の地図は 1640 年にポルトガル→スペインの変化を描いている）。（確信度：高）

## 重要度 B

### 宗教
- **[B] イランのシーア派化が早すぎる**（ottoman.yaml `rel_iran`、`rel_iran_west_azerbaijan`）：1510 年から main shia（minor sunni）、1600 年から shia のみ。
  サファヴィー朝が十二イマーム派を国教にしたのは 1501 年だが、住民の改宗は 16 世紀を通じてゆっくり進み、多数派になったのは 16 世紀末〜17 世紀前半
  （アッバース1世の時代）、ほぼ完了するのは 17 世紀後半とするのが通説。
  → 1501（または 1510）は sunni/shia のまま note に国教化を書き、1580〜1600 に shia/sunni、1648 年以後の shia につなぐ。
  （根拠：Encyclopaedia Iranica「Conversion of Iran to Shiism」など。確信度：中）
- **[B] アルバニア中部のイスラーム化（1600 年に main sunni）がやや早い**（`rel_albania`）：アルバニアの大規模な改宗は 17 世紀（とくに中葉以後）で、
  ムスリムが多数になるのは 17 世紀後半とされることが多い。→ 1600 は catholic/sunni・orthodox のまま、1630〜1648 で sunni に。
  同じく `rel_macedonia_muslim`（1600 sunni）・`rel_polog`（1620 sunni）も、西マケドニア・テトヴォの改宗は 17〜18 世紀なので早めかもしれない（要確認、確信度：低〜中）。
- **[B] ブダとペスト（ブダペストの 23 区のピース）が、言語はトルコ語なのに宗教はカトリック**（言語 `lang_budapest` 1541 turkish/hungarian、
  宗教 `rel_hungary_between_rivers` catholic/reformed）：オスマン領のブダ（1541–1686）は守備兵・役人・商人のムスリムが多数の町。
  → 1541 年からブダペストのピースだけ sunni（minor reformed／catholic）にする地域を分けるのがよい。（確信度：中）
- **[B] バーチ南部・スボティツァ**（`lang_bacs_south_hu` 1540 serbocroatian、`lang_subotica` 1550 serbocroatian）が宗教では catholic main
  （`rel_hungary_between_rivers`・`rel_subotica`）。16 世紀にここへ入ったのはおもに正教のセルビア人（カトリックのブニェヴァツ人の移住は 17 世紀後半が中心）。
  → 1540–1647 は orthodox/catholic か、言語の note で説明。（確信度：中）
- **[B] クリミア山地の宗教から正教の minor が消える**（`rel_crimea`、1550 から sunni のみ）：言語の同じ地域（`lang_crimea_mountains`）は 1453–1647 を通じて
  tatar/greek。山地・南岸のギリシア人（正教徒）は 1778 年の移住まで相当数いた。→ 1550 年以後も minor orthodox を残す。（確信度：中）
- **[B] 草原の宗教と言語の地域の分け方の食い違い**：
  - `rel_right_bank`（ドニエプル右岸）に入るキロヴォフラード西部のピース（Haivoron・Holovanivsk・Kamianka・Novoarkhanhelsk・Vilshanka・Blahovishchenske）が
    1453–1599 年も orthodox だが、言語では `lang_wild_fields_ua_pre` の tatar（荒野）。同じ年の他の荒野のピースは宗教も sunni。→ 宗教も `rel_wild_fields_ua_pre` にそろえる。
  - アゾフ海北岸（Manhush・Nikolske、`lang_mariupol_greeks`）は言語では 1647 まで tatar なのに、宗教は `rel_wild_fields_ua_pre` で 1600 から orthodox/sunni。
  - サリスク草原（Remontnensky・Zavetinsky、`lang_sal_steppe` tatar）が宗教では `rel_don_pre` で 1600 から orthodox。
  - テレク川下流（`rel_kizlyar`）：宗教は 1600 から orthodox/sunni、言語（`lang_kizlyar`）は tatar/russian。テレク・コサック（1580 年代〜）は少数で、
    住民の多数はノガイ人・クムク人。→ 宗教を sunni/orthodox に。
  - ヴォルガ中流の草原（`rel_middle_volga_pre`）は 1600 から orthodox/other、言語（`lang_middle_volga`）は volga_finnic/russian。モルドヴィン人の多くは
    18 世紀半ばの集団洗礼まで伝統信仰が強かった。→ 宗教も other/orthodox か、1600 の切り替えを遅らせる。（確信度：中）
- **[B] スロボダ・ウクライナとドンバスが 1600 年にウクライナ人・正教の地になる**（`lang_sloboda_ua`・`lang_donbas` 1600 ukrainian、`rel_wild_fields_ua_pre` 1600 orthodox/sunni）：
  スロボダ・ウクライナへの入植はチュフイウ（1638）、ハルキウ（1650 年代）など 1630〜50 年代、ドネツ川流域（ドンバス）は 17 世紀末〜18 世紀（イジューム 1681、バフムート 1701）。
  1600 年のウクライナ人の多数は 40〜100 年早い。→ スロボダは 1640 前後、ドネツ川流域は 1647 まで tatar/sunni のままにする（1648 年以後の既存の値が早いことは対象外として note に）。
  同じく `lang_south_russia_steppe_pre` の南部（ヴォロネジ南部のボグチャル・ロッソシなど、町の建設は 18 世紀）が 1600 から russian なのも早い。（確信度：中〜高）
- **[B] テッサロニキの宗教**（`GRC-Thessaloniki`：`rel_greece_north` orthodox/sunni）：言語は 1500 年から ladino（セファルディム）が main なのに、宗教には
  ユダヤ教が出ない（note では「住民の過半数がユダヤ教徒」）。jewish の種類はあるので、1500 年から（1648 年以後も 1912 年まで）jewish を main か minor にするのが整合的。（確信度：中）
- **[B] セヴェンヌ（`rel_france_huguenot_core`）が 1555 年以後も catholic main**：セヴェンヌ・ヴィヴァレの山地はユグノーが住民の多数だった地域
  （名前も「ユグノーの中心地」）。→ 1560 から reformed/catholic（1648 年以後の値も同じ理由で要検討）。（確信度：中）

### 出来事（data/events/europe.yaml。担当ファイルも検索して確認）
- **[B] ユグノー戦争（1562 年のヴァシーの虐殺）とサンバルテルミの虐殺（1572）の出来事がどこにもない**（europe.yaml・west.yaml などすべての events を検索）。

### 潮流
- **[B] イギリスの宗教改革（首長法・国教会）の潮流がない**：宗教改革の潮流は「ルター派」と「カルヴァン派」の 2 つで、イングランドは calvinism の GBR（1560 0.2 → 1640 0.8、ピューリタン）
  でしか光らない。教科書では宗教改革をルター・カルヴァン・イギリス国教会の三つで扱うので、1534–1559 のイングランドが光らないのは不自然。
  → `lutheran_reformation` か新しい潮流で `polities: [britain]`（1534 0.5、1553 0.2、1559 0.8、1600 0.6）など。（確信度：中）

## 重要度 C
- 宗教：
  - `rel_bohemia_pre` の 1624 年の catholic main は少し早い（1624 年の非カトリック聖職者の追放、1627 年の改訂領邦条例のあと住民の改宗は 1630〜50 年代）。1627 か 1630 でもよい。
  - `rel_mulhouse`（ミュールーズ）1529 catholic/reformed：ミュールーズ市はスイスと結んだ改革派の町。ピースが周辺の農村を含むならこのままでよい。
  - トランシルヴァニアのユニテリアン（トルダの勅令 1568。クルジュ・ウドヴァルヘイ）は種類がなく note だけ。reformed にまとめているのは妥当。
  - ポーランド・リトアニアのカルヴァン派（小ポーランド・リトアニアの貴族、1550–1600）は住民の多数ではないので塗らなくてよいが、`rel_poland` の note に一言あるとよい（潮流の calvinism では POL・LTU が光る）。
  - ドゥカジン（コソヴォ西部）は言語が albanian main なのに宗教は 1453 年 orthodox のみ。1453 年のアルバニア人はおもにカトリック。
  - アゼルバイジャン北部（シルヴァン・シェキ・クバ）の 1540 年からの shia main は、北部（シェキ・クバ）でスンナ派が長く多数だったことを考えると早いかもしれない（要確認・低）。
  - チェルケス・カバルダの 1600 年からの sunni main：民衆のイスラーム化は 17〜18 世紀とする説もある（要確認・低）。
  - ラズィスタン（`lang_lazistan` 1600 turkish/georgian）：ラズ人はイスラーム化してもラズ語を話し続けた（民族で塗るならカルトヴェリ系）。1648 年以後の値と同じなので既存の方針どおりでもよい。
- 言語：`lang_vilnius_city`（1453 lithuanian/belarusian、1580 polish）は 15〜16 世紀のヴィルノではルーシ人（ベラルーシ語）が最大だった可能性（要確認・低）。`lang_kaunas_city` の 1600 polish main も要確認。
- 都市（cities.yaml）：
  - バフチサライ（crimea 1453–）：町の建設は 1532 年ごろ。それまでの都は隣のサラチク・クルク・エル（チュフト・カレ）なので、場所はほぼ同じで実害はない。
  - ブリュッセル（habsburg_netherlands 1477–1555）：1507–1530 年はマルグリット・ドートリッシュの宮廷がメヘレンにあった。
  - マルタ騎士団の 1530–1570 年の都ビルグ（イル・ビルグ）がない（ロドス –1521、ヴァレッタ 1571–）。
  - フェス（wattasid 1472–）：1453–1465 はマリーン朝の都（政体の扱い次第）。
- 潮流：
  - `baroque` の people にルーベンス・ベラスケス・レンブラントが 2 回ずつ入っている。
  - `baroque_catholicism` の spread `{polities: [castile, aragon]}`（1540–1560）は、castile・aragon が 1516 年以後に領域を持たないので効いていない（spain の行で足りている）。
  - `baroque_catholicism` の `iso: [ITA]` は 1647 年で終わるので、1648 年にイタリア（教皇領・ナポリ以外）の光が急に消える。1648 年以後も続けるか、少しずつ下げる。
  - `lutheran_reformation`・`calvinism` にトランシルヴァニア（ザクセン人のルター派、ハンガリー人の改革派）が入っていない。`second_serfdom` にハンガリー（1514 年のドージャの乱後の「永久の農奴制」）がない。
  - 人文主義の people「マキァヴェリ」と出来事の題名「マキァヴェッリが『君主論』を書く」で表記がそろっていない（教科書はマキァヴェリ）。
- 出来事（europe.yaml）：
  - 1522「マゼラン一行の世界周航」の「地球が丸いことが実証された」は教科書的な言い方だが、当時すでに球体は知られていたので「地球が球体であることが航海で確かめられた」くらいがよい。
  - 1609「ケプラーの『新天文学』」の関係国が habsburg（地図ではボヘミアは 1619 年まで bohemia の色。整合のメモどおりプラハの宮廷のこと）。bohemia も足すとパネルで分かりやすい。
  - 1536「フランスとオスマン帝国の同盟」：1536 年のカピチュレーションは批准されず、正式な付与は 1569 年、と本文に書いてあり正確。

## 問題のなかった観点（確認したこと）
- **ドイツ諸邦の宗教改革**：早い領邦（エルネスト系ザクセン・ニュルンベルク・リューネブルク・ハンブルク 1521–28）、1530 年代（アルベルト系ザクセン・ブランデンブルク 1539・ポンメルン 1534・ヴュルテンベルク 1534）、
  遅い領邦（メクレンブルク 1549・ブラウンシュヴァイク＝ヴォルフェンビュッテル 1568）、ヘッセン（1526、カッセルの改革派 1605）、プファルツ（1546/1556 ルター派 → 1563 改革派 → 1576 ルター派 → 1583 改革派）、
  ブレーメン（1581）・アンハルト（1596）・ナッサウ＝ディレンブルク（1578）・リッペ（1605）の改革派、オーバープファルツ（1628）・ノイブルク（1615）の再カトリック化、
  アウクスブルク（1534、復旧令 1629）、ウルム（1530/31）、シュトラスブール（1529）、ケルン戦争とヴェストファーレンの再カトリック化（1610）、エヒター司教の対抗宗教改革（1600）は、いずれも年と向きが正しい。
- **北欧・バルト**：北欧 1527–40（ヴェステロース 1527、デンマーク 1536）、アイスランド 1550（ヨーン・アラソンの処刑）、プロイセン公国 1525、リヴォニア 1525–60、ダンツィヒ 1557 は妥当。
- **スイス**：チューリヒ 1523、ベルン 1528、バーゼル 1529、ヴォー・ジュネーヴ 1536、第二次カッペル平和（1531）の共同支配地、中央スイスのカトリックは正しい。
- **イングランド・スコットランド・アイルランド**：首長法 1534 → メアリ1世 1553 → 統一法 1559、スコットランド 1560、アイルランドはカトリック（ダブリン 1600 minor anglican、アルスター植民 1610）は正しい。
- **ネーデルラント**：聖像破壊運動 1566、北部の改革派化（1594 フローニンゲン）、アントウェルペン陥落 1585 の南部の再カトリック化は正しい。
- **フランス**：ユグノーの地域（1555/1560 から minor reformed）、アルザス・モンベリアールは妥当（セヴェンヌだけ上の B）。
- **オーストリア・ボヘミア**：上・下オーストリア（1570 lutheran → 1625）、内オーストリア（1565 → 1600 → 1630）、ボヘミアのフス派（1453–1623 の main、1530 から minor lutheran、1624 カトリック）、
  ドイツ人の国境地帯（1530 lutheran）、モラヴィア（1550 hussite main）は史実の流れに合う。hussite の色（くすんだ紺）はルター派・カルヴァン派と区別でき、凡例も「フス派（ウトラキスト・兄弟団）」で分かりやすい。
