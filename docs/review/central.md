# 中欧データのレビュー（ドイツ・ハプスブルク領）

- レビュー日：2026-11-20
- 対象：data/polities・regions・events の germany_north.yaml、germany_south.yaml、habsburg.yaml（必要に応じて north_east.yaml・italy_lowcountries.yaml・europe.yaml も参照）
- 方法：
  - YAML の全地域の timeline と、政体の君主・情勢を通読した。
  - `public/data/atlas.json` を使い、年ごとの overlord（hre / rhine_confederation / german_confederation）に入るピースを国コード別に集計した。
  - 地図を書き出して目視で確認した（`.cache/snapshots/review_central/`）。年は 1648, 1683, 1690, 1700, 1740, 1745, 1789, 1800, 1803, 1806, 1807, 1808, 1810, 1812, 1815。バイエルン・オーストリア・プロイセンは国を選んだ状態でも見た。
  - historical-basemaps との照合（compare_hb.py 1783 DEU）も試したが、照合先の 1783 年のデータは実質的に 1815 年の国境で、参考にならなかった。

全体として、国境の変化の年・理由はおおむね正確で、出典もよく付いている。特に 1803・1806・1807・1810・1815 の再編はかなり細かく正しく描かれている。
地図そのものに明白な誤りはほとんど見つからなかった。重要度 A は、右パネルに出る「種別（kind）」の表示誤り1件だけ。

## 重要度 A

- **[A] 政体の種別（kind）が時期で変わらず、誤った種別が表示される**（polities/germany_south.yaml・germany_north.yaml：bavaria, wurttemberg, baden, hesse_darmstadt, nassau, wurzburg, prussia ほか。1648–1815）
  - 右パネルの名前の下に kind がそのまま出る。このため、たとえば 1810 年のバイエルンは「バイエルン王国 ／ 選帝侯領」と表示される（スナップショットで確認）。同じ問題がほかにもある。
    - ヴュルテンベルク王国が「公国」
    - バーデン大公国が「辺境伯領」
    - ヘッセン大公国が「方伯領」
    - ナッサウ公国が「侯国」
    - ヴュルツブルク大公国（1806–）が「司教領」
    - 逆にブランデンブルク＝プロイセンは、1648–1700 年も「王国」
  - 正しくは：kind にも names と同じように時期別の値を持たせる。またはザクセンのように「選帝侯国（1806年から王国）」の形の文字列にする。
    - バイエルン：選帝侯領→王国（1806）
    - ヴュルテンベルク：公国→選帝侯国（1803）→王国（1806）
    - バーデン：辺境伯領→選帝侯国（1803）→大公国（1806）
    - ヘッセン＝ダルムシュタット：方伯領→大公国（1806）
    - ナッサウ：諸侯領→公国（1806）
    - プロイセン：選帝侯国（ブランデンブルク）→王国（1701）
  - 確信度：高（表示を確認済み）。

## 重要度 B

### 地図・所属

- **[B] ライン左岸プファルツ・ラインヘッセンの 1814–1815 年がオーストリア（uncertain）で塗られる**（regions/germany_south.yaml：kurpfalz_left, zweibrucken, pirmasens, alzey, mainz_left, worms_city, speyer_city, landau。1814–1815）
  - 1815 年の地図で、プファルツ一帯がオーストリアの黄色に斜線で表示される。
  - 実際は、オーストリアとバイエルンの共同管理委員会による暫定統治（1814–1816）である。ウィーン議定書でも、最終的な帰属は後の交渉に委ねられていた。オーストリアの領土として描くと、「1815 年のオーストリアがライン川沿いに飛び地を持っていた」ように読めてしまう。
  - 改善案（いずれか）：
    - owner を other_hre（または専用の「連合国の管理地」政体）+ uncertain にする。
    - 教科書地図の慣例（1815 年の地図ではすでにバイエルン領ラインプファルツ／ヘッセン領ラインヘッセンとして描くことが多い）に合わせる。
  - 確信度：中。

- **[B] シャウムブルク全体がヘッセン＝カッセル→ヴェストファーレン王国になっている**（regions/germany_north.yaml：schaumburg（DEU-Schaumburg）。1648–1815）
  - 1647/48 年のシャウムブルク分割で、北半分（ビュッケブルク・シュタットハーゲン）はシャウムブルク＝リッペ伯領（1807 年から侯国）となった。リッペ家の独立した領邦で、1807 年にライン同盟に加盟し、ヴェストファーレン王国には入っていない。1815 年にはドイツ連邦の加盟国になった。
  - DEU-Schaumburg はおよそ半分がシャウムブルク＝リッペにあたる。このため、1807–1813 年にこのピースをヴェストファーレン王国とするのは不正確。
  - 改善案：シャウムブルク＝リッペを lippe か other_hre の扱いにする（ピースの面積の大きい方に合わせる）。少なくとも note に書く。
  - 確信度：中〜高。

- **[B] オスマン領ハンガリーが、皇帝軍の奪回後も 1698 年までオスマン領のまま塗られる**（regions/habsburg.yaml：ottoman_hungary_hu, bihar_hajdu。1686–1698）
  - ブダ（1686）、セーケシュフェヘールヴァール（1688）、エゲル（1687）、カニジャ（1690）、ヴァーラド（1692）などは、カルロヴィッツ条約より前にハプスブルク家の支配下に入っている。1686–1698 年の地図では、ハンガリー中部がオスマン領の緑のまま表示される。
  - 「ブダ奪回」（1686）の出来事と地図が合わず、地図を眺めて全体像をつかむという目的からすると違和感が大きい。
  - 改善案：data-format.md の例外規定（何年も続き、地図の理解に必要な占領）に当てはまるので、`from: 1686`（ブダ州）などで `owner: habsburg, certainty: occupied` を挟み、1699 年に certain にする。テメシュヴァル（バナート）は 1716 年まで、パッサロヴィッツ条約は 1718 年。
  - 確信度：中（方針の問題）。

- **[B] ヴェストファーレン王国の色がフランスとほとんど同じ**（polities/germany_north.yaml：westphalia_kingdom `#b6c7f0`、フランス `#9db7e0`。1810–1813）
  - 1810 年末に北西ドイツがフランスに併合されると、両者は長い境界で接する。広域の表示では、外枠の破線がなければ区別しにくい（1810 年のスナップショットで確認）。
  - イリリア（`#a9bce6`）も同系色だが、こちらはフランスの州なので意図どおりと考えられる。
  - 改善案：衛星国であることを示すにしても、ヴェストファーレンは色相をずらす（例：薄い青緑や薄い紫）。確信度：高（見た目）。

- **[B] フランクフルト大公国とヴュルツブルク大公国の色がほぼ同じ**（frankfurt_gd `#c7a9d4`、wurzburg `#c3aedb`。1806–1813）
  - アシャッフェンブルク・フルダ（ダールベルク領）とヴュルツブルクは隣り合っている。1810 年の地図では、紫の二つの国の境目がほとんど見えない。確信度：高（見た目）。

- **[B] 地図ラベル（short）が時期で変わらない**（prussia の short「プロイセン」、frankfurt_gd の short「ダールベルク領」）
  - 1648–1700 年もラベルは「プロイセン」と出る（パネルの名前は正しく「ブランデンブルク＝プロイセン」）。
    - 改善案：1700 年まではラベルを「ブランデンブルク」にする。高校教科書では「ブランデンブルク＝プロイセン」の地図ラベルはふつう「ブランデンブルク」。
  - 1810–1813 年のフランクフルト大公国も、ラベルは「ダールベルク領」のまま。
    - 改善案：names のように short にも時期の指定を持たせる。
  - 確信度：高。

### 事実・文章

- **[B] フュッセンの和約の説明「皇帝位の要求を放棄」**（events/germany_south.yaml 1745、polities/germany_south.yaml bavaria の periods 1740–1745）
  - カール7世は 1745 年1月に死去している。子のマクシミリアン3世ヨーゼフが放棄したのは、オーストリア継承（ハプスブルク家の遺領）への要求である。さらに、フランツ・シュテファンの皇帝選出に票を投じることを約束した。マクシミリアン3世ヨーゼフは皇帝位を要求していない。
  - 正しくは「オーストリア継承の要求（ハプスブルク家の遺領への請求）を放棄し、フランツ・シュテファンの皇帝選出を支持する代わりにバイエルンを回復した」。確信度：高。

- **[B] 1742年のシュレジエン割譲（ブレスラウ条約・ベルリン条約）と、1745年のドレスデン条約の出来事がない**（events/*）
  - 高校世界史で太字級の出来事だが、「出来事」の一覧にない。地域の国境変化の理由としてだけ表示される（north_east.yaml silesia_pl）。
  - 1748 年アーヘンの和約、1763 年フベルトゥスブルク条約はある。
  - 改善案：1742 年「プロイセンがシュレジエンを獲得（ブレスラウ条約・ベルリン条約）」（importance 1）と、1745 年「ドレスデン条約（第二次シュレジエン戦争の講和。プロイセンのシュレジエン領有を再確認）」を追加する。確信度：高。

- **[B] オーストリアの情勢 1700–1739 に、パッサロヴィッツ条約と 1730 年代の損失が書かれていない**（polities/habsburg.yaml habsburg periods 1700–1739）
  - 書かれていないのは次の3つ。
    - パッサロヴィッツ条約（1718）による最大版図（バナート・北セルビア・小ワラキア）
    - ポーランド継承戦争によるナポリ・シチリアの喪失（1735/38）
    - ベオグラード条約（1739）による北セルビアの返還
  - 地図上の大きな変化なので、情勢の文にも一言あるとよい。確信度：高。
