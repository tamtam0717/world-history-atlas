# 独立レビュー：アジアの宗教・言語の分布、都市、潮流（1453–1647）

対象：data/religion・data/language の east_asia・south_asia・southeast_asia.yaml（1453–1647 の項目と until の地域）、data/cities.yaml のアジアの都市（首都の期間・人口・founded）、data/movements の 1453–1647 の潮流（陽明学・明の文化・朝鮮の朱子学・ゲルク派・アジアへの布教・東山／桃山文化・インド＝イスラーム文化・東南アジアのイスラーム化・アジアの海の交易・バクティ・シク教）。
整合の結果（docs/integration-notes-1453-asia.md）も見た。

方法：
- atlas.json（`npm run data`。警告なし）から、ピースごとの宗教・言語・所属を年ごとに引き出すスクリプトで照合した（scratchpad の rev/：lib.py・chk.py・jumps.py・caps.py・caps2.py・de.py）。
- 地図：`node tools/snapshot.mjs 1453 1500 1550 1600 1640 --zoom 100,25,1.3 --layer religion|language`（.cache/snapshots/review1453_asia_dist/religion・language）。島嶼部（115,2,2.2）・インド（80,22,2.4）・東アジア（112,40,1.8）も書き出した（sea_rel・sea_lang・ind_rel・ind_lang・ea_rel・ea_lang）。
- 1647→1648 の段差：アジアの全ピースで宗教・言語の main／minor を比べた。違うのはコーカン（MMR-Laukkaing）の宗教だけ（下の A-1）。

重要度：A＝地図や事実が明らかに誤り、B＝不正確・改善すべき、C＝好みや細部。

## A（明らかな誤り）

- **[A] ミンダナオのマギンダナオ・ラナオ・コタバト（religion/southeast_asia.yaml の rel_moro・rel_lanao_norte・rel_cotabato、1453–1519 年）**
  1453 年から `main: sunni` になっている（rel_moro は 1453 sunni／minor other、1520 sunni。rel_lanao_norte は 1453 から sunni だけ。rel_cotabato は 1453 sunni／minor other）。
  rel_moro の note にも「マギンダナオ（16 世紀初めにシャリーフ・カブンスワンがイスラームを伝える）。ラナオのマラナオ人のイスラーム化は 16〜17 世紀」とあり、note と塗りが合っていない。政治の地図でも、マギンダナオ王国は 1520 年から（1453 年のマギンダナオ・ラナオは所属なし）。
  → 1453 年の値を rel_moro から分ける。スールー・タウィタウィ（・バシラン）は 1453 年から sunni のままでよい（スールー王国は 15 世紀半ばにスルタン国）。マギンダナオ・コタバトは 1453 other／minor sunni → 1520 sunni、ラナオ（南北）は 1453 other → 1520 other／minor sunni → 1600〜1620 sunni くらい（`until: 1647` の地域で）。確信度：高。
  1453 年の島嶼部の地図（sea_rel/map_1453）では、ミンダナオ西部がブルネイ・スールーと同じ濃い緑になって目立つ。

- **[A] コーカン（MMR-Laukkaing）の言語と宗教の食い違い（language/southeast_asia.yaml の lang_kokang、religion の rel_kokang、1453–1647 年）**
  宗教は 1453–1647 年が other／minor theravada（note：「パラウン人・ワ人などの山地の民の地。明末清初に、明の遺臣とされる楊氏などの漢人が移ってきた」）で、1648 年に chinese_folk になる。ところが言語は 1453 年から `chinese` だけ。漢人（コーカン人）が来たのは宗教の note のとおり明末清初なので、言語の 1453 年の値が誤り（1648 年の値を写したもの）。
  → lang_kokang の 1453 年を mon_khmer_hill／minor shan（隣の lang_wa と同じ）にし、1648 年から chinese。確信度：高。

（A は 2 件）

## B（不正確・改善すべき）

### 宗教・言語の分布

- **[B] モンゴル西部（MNG-Khovd・MNG-Uvs）のチベット仏教化の年（religion/east_asia.yaml の rel_mongolia、1586–1615 年）**
  この 2 ピースは政治の地図では 1586–1615 年もオイラト（dzungar）の地なのに、外モンゴル全体の rel_mongolia（1586 tibetan_buddhism）が効いて、ハルハと同じ 1586 年にチベット仏教になる。ジュンガリア（rel_dzungaria など）・バヤン・ウルギー（rel_bayan_olgii）は 1616 年（オイラトの帰依）で切り替えていて、オイラトの中で年がずれる。
  → ホブド・オブスを rel_bayan_olgii に入れるか、`until: 1647` の地域で 1453 other／minor tibetan_buddhism → 1616 tibetan_buddhism にする。確信度：高。

- **[B] ホルチン（CHN-Tongliao）とフルンボイル・興安のチベット仏教化の年（rel_inner_mongolia、1580 年）**
  通遼（CHN-Tongliao、ホルチン部の本拠）は rel_im_ordos_horqin（1648 年から）なので 1647 年までは rel_inner_mongolia の 1580 年（tibetan_buddhism が main）が効く。一方、同じホルチン部の白城・松原（rel_jilin_west）は 1630 年（「ホルチン部は後金と早くから同盟し、チベット仏教を受け入れた」）。同じ部族で 50 年ずれる。フルンボイル・興安（ダウール・エヴェンキ・バルガ）も 1580 年になる。
  → 東部（通遼・興安・フルンボイル）は rel_jilin_west と同じ 1630 年にそろえる（`until: 1647` の地域）。確信度：中。

- **[B] サンボアンガ半島（rel_zamboanga・lang_zamboanga、1453–1647 年）の宗教と言語の食い違い**
  宗教は 1453 年から sunni（minor other）、言語は philippine_other（スバノン人など）が main で moro が minor。住民の多数がスバノン人（在来の信仰）なら宗教は other／minor sunni のはず。1648 年以降の既存データも同じ食い違いがあるので、1648 年以降と合わせて見直す候補。確信度：中。

- **[B] ゴアの全域がカトリック（rel_goa、1570 年〜）**
  IND/Goa は北ゴア・南ゴアの 2 ピースで、1570 年から両方が catholic（minor hindu）になる。改宗が進んだのは旧征服地（ティスワディ〈ゴア島〉・バルデス・サルセテ。バルデス・サルセテの獲得は 1543 年）だけで、新征服地（ペルネム・ビチョリム・サッタリ・ポンダ・サンゲム・ケペム・カナコナ。18 世紀後半の獲得）はヒンドゥー教徒が多数のまま。面積では新征服地が大半を占めるので、地図ではゴア全体が「カトリックの地」に見えすぎる。
  政治の地図でも 1510 年からゴアの全域がポルトガル領になっている（担当外だが、宗教と同じ原因）。
  → ピースを分けられないなら note に書くか、certainty・minor で弱める。分けられるなら旧征服地だけを catholic に。確信度：高（史実）／対処は要相談。

- **[B] 朝鮮の仏教（大乗）と明の民間信仰の色が近い（religion/_kinds.yaml、1453–1549 年）**
  1453–1549 年の朝鮮は mahayana（#e6a3c9）、隣の遼東・中国は chinese_folk（#e48aa8）。ΔE（CIE76）13.2 で、1648 年以降には出てこない新しい隣り合わせ。地図（ea_rel/map_1453）では、朝鮮の儒教の斜線（minor confucian）があるので見分けはつくが、塗りの色だけでは区別しにくい。ハミ（1453–1514 年の mahayana）と甘粛（chinese_folk）も同じ。
  → mahayana をもう少し紫寄り・明るめにするなど（色差 20 以上）。確信度：中（見た目）。

- **[B] ケーララの聖トマス派の扱いが地域でずれる（rel_central_travancore・rel_pathanamthitta、1599–1647 年）**
  ディアンペル会議（1599）でコッタヤム・エルナクラム・イドゥッキは hindu／minor catholic になるが、隣のパッタナムティッタは oriental のまま（1453 年からの値を 1648 年以降と同じにしている）。ディアンペル会議はケーララの聖トマス派全体をラテン化した（離反はクーナン十字架の誓い〈1653〉から）ので、1599–1647 年はパッタナムティッタも catholic のはず。
  → 1599–1647 年だけ rel_pathanamthitta を hindu／minor catholic に（`until: 1647` の小さな地域でもよい）。確信度：中。

### 都市（data/cities.yaml）

- **[B] タウングー朝の首都が 1538 年に 2 つ（taungoo と pegu）**
  taungoo の capital が burma 1510–1538、pegu が burma 1538–1598 で、1538 年に重なる。タビンシュエーティーのペグー攻略は 1538 年（遷都 1539 年）。年末の状態なら taungoo を 1537 年まで（または pegu を 1539 年から）。確信度：高。

- **[B] 首都の抜け（主な定住国家）**：caps.py で、年ごとにアジアで 15,000 km² 以上の領域を持ち首都の点がない政体を数えた。遊牧国家（北元・ハルハ・オイラト・トゥメトなど）と小さな在地の国は首都なしでよいとして、次は点がほしい。
  - グジャラート＝スルタン朝 1484–1535（チャンパーネール）：ahmedabad の note に「1484–1535 年はチャンパーネール」とあるのに、その期間の首都の点がない。
  - アフマドナガル王国 1600–1636（ジュンナール・ダウラターバード、マリク・アンバルのカドキ〈1610–、のちのアウランガーバード〉）。aurangabad（founded 1610）に capital を足すのが簡単。
  - アルグン朝 1520–1554（ブッカル／タッター）：thatta の note は「サンマ朝、ついでアルグン朝・タルハーン朝の都」とあるのに、capital は samma と tarkhan だけ。
  - ツァンパ政権 1565–1641（シガツェ）：1618 年からは中央チベットの大部分を持つ（1620 年に約 73 万 km²）のに首都がない。パクモドゥ（ネドン）も同じ。
  - パレンバン：capital が 1648 年から。政体 palembang は 1453 年からあるので、1453 年（または王国の確立した年）からに延ばせる。
  - 確信度：高（抜けていること）。C に回したもの：ラダック（レー）、グゲ（ツァパラン）、黎朝の中興（1533–1592 のタインホア）、広南阮氏の 1600–1635、カンボジアの 1505–1527・1594–1617（スレイ・サントー）、ジョホール（1587 年以降）、カトマンズ（マッラ朝の分裂前、1453–1483 はバクタプル）、フマーユーンのカーブル（1545–1555、担当 E の都市）。

- **[B] 清（後金）の都・瀋陽が地域の拡大率では見えない（shenyang の pop）**
  pop が 1600・1650 年とも 30,000 なので、首都でも minz = 5.4 − 0.7 = 4.7 になり（src/map.ts の cityFeature。首都で 4 万以上なら 3.4）、1640 年の東アジアの地図（ea_rel/map_1640、拡大率 1.8）では盛京の点が出ない。明の北京は出るので、明清の二つの都が並ぶ図にならない。
  → 1625–1643 年の盛京の人口を見直す（宮殿・八旗の駐屯で数万はいたとされる。値は要確認）か、1630・1640 年の値を足して 4 万以上に。確信度：中。

### 潮流（data/movements）

- **[B] 明の潮流が羈縻・名目の地まで光る（east_asia.yaml の yangming・ming_culture・asian_christian_missions の `polities: [ming]`）**
  明には home_iso がないので、その年の明の全領域が光る。1453–1600 年の明の nominal・indirect の地は、青海（約 70 万 km²）・黒竜江・吉林・沿海州（RUS-Primorsky_Krai）・新疆東部・チベット東部・雲南・貴州の土司など、合わせて 150 万 km² をこえる。陽明学や「明の文化（四大奇書）」、イエズス会の布教が沿海州や青海で光るのは不自然。
  → `exclude_regions` で羈縻の地域（女真・兀良哈・青海・ハミ・チベット東部など）を除くか、`adm1`（中国本土の省）で書く。確信度：高。

- **[B] インド＝イスラーム文化の人物「ビハーザード」（south_asia.yaml の mughal_culture、people）**
  ビフザード（ビハーザード）はヘラート・タブリーズの画家で、インドには来ていない（ムガル絵画への影響は弟子筋を通じて）。ムガルの宮廷工房を開いたのはフマーユーンが連れてきたミール・サイイド・アリーとアブドゥッサマド。
  → people を「ミール・サイイド・アリー」「アブドゥッサマド」などに替える（ビフザードは text で「イランの細密画」の代表として触れる程度に）。確信度：高。

- **[B] 東南アジアのイスラーム化で、マラッカの勢いが 1453 年から下がり続ける（sea_islamization の spread `{polities: [malacca]}`）**
  curve が `[[1453, 1.0], [1511, 0.0]]` で、間は線形補間なので 1480 年に 0.5、1500 年に 0.2 になる。マラッカがイスラームの交易と布教の中心として最も栄えたのは 15 世紀後半〜1511 年。「始まり／最盛期／衰退」を光り方で見せる方針と逆の見え方になる。
  → `[[1453, 0.9], [1500, 1.0], [1510, 1.0], [1511, 0.0]]` のように。確信度：高。

## C（好みや細部）

- [C] 内モンゴル（rel_inner_mongolia）1580 年、外モンゴル（rel_mongolia）1586 年に tibetan_buddhism が main。アルタン＝ハンの帰依（1578）・エルデニ・ゾー（1585–86）から数年で住民の多数とするのは早め。main への切り替えを 1600 年前後にし、それまでは minor にする案もある。
- [C] 長崎（rel_nagasaki_pre）だけが minor catholic。天草（熊本）・豊後（大分）にもキリシタンが多かった。ピースが県単位なので note で補う程度でよい。
- [C] フィリピン（rel_philippines）1580 年の minor catholic が、まだスペインの支配の及ばないカガヤン（1581 年に征服）にも入る。
- [C] バタヴィア（ジャカルタ）：言語は 1620 年に malay／minor chinese になるが、宗教は sunni のまま（華人・マルダイケル〈キリスト教徒〉・オランダ人が住民の多く）。1648 年以降の既存データも同じなので、1648 年以降と合わせて見直す候補。言語の 1620 年は政治（1619 年にオランダ領）と 1 年ずれる。
- [C] ボンベイ・バセイン（1534–1661 のポルトガル領）に、のちの「イースト・インディアン」になるカトリックの minor がない。
- [C] バンカ・ブリトゥン（rel_bangka、1648 年から）は 1647 年まで rel_indonesia の 1453 sunni が効く。1453 年のバンカのイスラーム化は早め。
- [C] 西シベリア南部（rel_sib_steppe）のノヴォシビルスク州も 1453 年から sunni。バラバ・タタールのイスラーム化は 18 世紀以後とされる（1648 年以降と同じ値なので既存データの問題）。
- [C] 澎湖（rel_taiwan_islands・lang_taiwan_islands）が 1453 年から漢人・chinese_folk。明は 14 世紀末に澎湖の住民を移しており（海禁）、15 世紀半ばは人が少なかったとされる。
- [C] トゥルファン（rel_turfan_pre）1453 年に sunni が main。ムスリムが多数になった時期は 15 世紀後半とする見方もある（要確認）。
- [C] ベンガル東部の 1610 年の sunni（rel_bangladesh）：イートンの説では東部デルタのイスラーム化の中心は 17〜18 世紀。1648 年の値が sunni なので、1610 年の切り替えはつながりとしては妥当。note の「イートンの説」の書き方はこのままでよい。
- [C] 言語の lang_yunnan_yi の名前は「大理・楚雄・紅河・普洱・臨滄」だが、紅河・普洱・臨滄はより小さい lang_yunnan_south が効くので、1550 年に漢語に変わるのは大理・楚雄だけ。右パネルの「言語分布の変化」（1550 年）に紅河などまで変わったように出る。
- [C] 都市の細部：瀋陽の names が「to: 1624 瀋陽／to: 1656 盛京」で、1625–1633 年も盛京になる（改称は 1634 年。note どおりなら to: 1633）。グワーリオルの note「1517 年にローディー朝が攻め取った」はイブラーヒーム・ローディーの 1518 年とする説が多い。アユタヤの王は 1463–88 年はピッサヌロークにいた（トライローカナート王）。スール朝の都（sur 1540–1554 がアーグラ。イスラーム・シャーはグワーリオルにいた）。
- [C] 潮流：アジアへの布教の PHL の spread が 1724 年に 0（雍正帝の禁教に合わせた全体の終わり）。フィリピンでは修道会の布教がその後も続くので、PHL だけ 1724 年以後も残す案。シク教の 1500–1647 年の spread（&punjab）がムルターン・デーラ・ガーズィー・ハーンまで光る（初期のシク教はマージャ・ドアーバ中心）。ゲルク派の広まりにオイラト（1616 年〜、政体 dzungar）が入っていない。
- [C] 色：ダヤク（dayak、#9fcf7a）がオーストロネシア系なのにオーストロアジア系の緑（khmer・vietnamese）に近く、凡例の語族の色（青緑）と合わない（1648 年以降の既存の色）。

- 南京の人口（1450 年 20 万・1500 年 15 万・1600 年 30 万）：明代の南京は副都として 1600 年前後に数十万〜100 万とする推計もある。
- 大坂の 1600 年 20 万：推計の幅が大きい。
- カルギル（rel_kargil）の 1550 年の shia：プリグのシーア派化は 16〜17 世紀と幅がある。
- ハミの 1515 年の sunni：王家・住民のイスラーム化の完了は 16 世紀前半とされ、年は目安として妥当。

## 問題がなかった観点

- **宗教と言語の年の整合**：チャンパー北部（1471・1550・1600）、フーイエン（1611・1640）、ハイデラバード（1591）、シッキム（1642）、イリ（1580 のオイラト進出）、台南（1630）、チュメニ（1590）が宗教・言語で同じ年。政治の年とも合う（ヴィジャヤ攻略 1471、フーイエン 1611 の阮氏の確かな支配、シッキム王国 1642、ロシアのチュメニ 1586）。
- **1647→1648 の段差**：アジアの全ピースで、宗教・言語の main／minor が変わるのはコーカンの宗教だけ（明末清初の漢人の移住として意図どおり。ただし言語は A-2）。until の地域の終わりもすべて 1648 年の値につながっている。
- **東南アジア島嶼部のイスラーム化**：ジャワ（デマク 1527 → 1600）、スンダ（1527 → バンテンのパクアン攻略 1579）、バンジャル（1526）、テルナテ（1490）、ゴワ・タロ（1605 → 1612）、ロンボク（1545 → 1620）、ビマ（1620 年代）、ミナンカバウ（1560）、ランプン（1550）、パタニ（1500）、ブランバンガン（1640 minor）、バリはヒンドゥーのまま、の年と範囲は通説どおり。アンボン（1570 カトリック → 1605 改革派）、ソロル・ララントゥカ（1570・1620）も妥当。
- **フィリピンのカトリック化**（1580 minor・1600 main・1630、北ミンダナオ 1620・1640、パラワン・ミンドロ minor、コルディリェラは other のまま）は、レガスピの征服・16 世紀末の受洗者数と合う（ミンダナオのムスリム地域の 1453 年は A-1）。
- **朝鮮の儒教化**（1453 mahayana／minor confucian → 1550 confucian／minor mahayana → 1610 confucian）と潮流（朝鮮の朱子学、1560 が頂点）は整合している。
- **日本のキリシタン**：長崎の minor catholic を 1570–1637 年とし、島原・天草一揆の後に消す扱いは、住民の多数派で塗る原則と合う。全国は shinbutsu のまま（note でザビエル・禁教・寺請制度を説明）。
- **モンゴルのチベット仏教化**：内モンゴル 1580、ハルハ 1586、オイラト（ジュンガリア）1616、ホルチン（白城・松原）1630、熱河 1620 という順序は通説どおり（年のずれは B の 2 件）。
- **ベンガルのイスラーム化**（東ベンガル・マルダ・ムルシダーバード・キシャンガンジ・バラク渓谷が 1610 年に sunni main）は 1648 年の値につながる。
- **シク教**：1648 年より前は住民の中で少数のため塗らず、潮流（1500–1647 は 0.05〜0.4）で見せる扱いは妥当。グル・ナーナク（カルタールプル 1520 年代）、黄金寺院（1604）の記述も正しい。
- **首都（年末の状態）**：北京（明 –1643、清 1644–）、南明（南京 1644・福州 1645・肇慶 1646・桂林 1647）、大順（西安 1643–44）、大西（成都 1644–45）、後金（ヘトゥアラ 1603–18・遼陽 1621–24・瀋陽 1625–）、京都・安土・大坂・江戸、ムガル帝国（アーグラ・ファテープル・シークリー 1571–84・ラホール 1585–97・アーグラ 1598–）、ヴィジャヤナガル（ハンピ –1564・ペヌコンダ・チャンドラギリ・ヴェールール）、ビーダル・ゴールコンダ・ハイデラバード、マジャパヒト・デマク・パジャン・マタラム（コタゲデ・クルタ・プレレド）、マラッカ（–1510）、ルアンパバーン → ヴィエンチャン（1560）、ロンヴェーク（1528–93）・ウドン（1618–）は史実どおり。重なりは 1538 年のタウングー朝だけ（B）。
- **founded**：ハイデラバード（1591）・ファテープル・シークリー（1571）・安土（1576）・アムリトサル（1577）・長崎（1571）・マカオ（1557）・台南（1624）・フフホト（1572）・ヘトゥアラ（1603）・トボリスク（1587）・トムスク（1604）・クラスノヤルスク（1628）・チェンナイ（1639）など、点が出る年は合っている（1453 年の地図にハイデラバードは出ず、ゴールコンダが出る）。founded より前の年に capital がある都市はない。
- **都市の人口**：北京（1500 年 67 万・1600 年 70 万・1650 年 47 万）、アーグラ（1600 年 50 万）、ヴィジャヤナガル（1500 年 50 万）、ガウル（1500 年 20 万）、江戸（1600 年 6 万 → 1650 年 43 万）などは通説（チャンドラーの推計など）と合う。
- **潮流の期間・強さ**：陽明学（1520〜1600、日本は中江藤樹の 1630 年代〜）、東山文化（1480 の頂点）・桃山文化（1580–1615）、明の文化（1600 の頂点、南明は 1662 まで）、インド＝イスラーム文化（タージ＝マハル 1632 の頂点）、アジアの海の交易（1511–1610 の頂点、日本は 1641 で終わり）、バクティ（ベンガル 1530 年代のチャイタニヤ、マハーラーシュトラ 1600 のエークナート）の山の位置は通説どおり。参照する adm1（JPN/Kumamoto・JPN/Oita など）はすべて実在する。
- **色**：新しい政体の色の調整（整合の 6）とは別に、宗教・言語の色で 1453–1647 年に新しく隣り合う組を見た。言語のチャム語とベトナム語・クメール語、モン語とビルマ語は十分に離れている。宗教で近いのは朝鮮（mahayana）と中国（chinese_folk）だけ（B）。
