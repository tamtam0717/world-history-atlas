あなたは歴史地図プロジェクト（/home/user/world-history-atlas）のデータを、作成に関わっていない立場で検証するレビュー担当です。データは読むだけで、**変更してはいけません**（data/, src/, tools/ は編集しない。git の commit もしない）。成果物はレビュー結果のファイル1つと、最後の報告です。

## 前提
- このサイトは年代別のヨーロッパ地図で、現代の行政区画（ピース）を年ごとの所属で塗り分けて描く。データ形式は docs/data-format.md を読むこと。
- データは data/polities, data/regions, data/events の YAML。`npm run data` で public/data/atlas.json ができる。
- 対象期間は 1648–1815。地図の「Y年」は Y年の年末時点の状態を表す。

## 検証の方法
1. 地図を見る：`node tools/snapshot.mjs <年...> --zoom <経度>,<緯度>,<倍率> --out .cache/snapshots/review_<担当名>` で PNG を書き出し、Read ツールで見る。`--polity <ID>` で国を選んだ状態（右パネルに君主・情勢が出る）も見られる。
   主な年：1648, 1660, 1680, 1700, 1715, 1740, 1763, 1772, 1789, 1795, 1800, 1803, 1806, 1807, 1810, 1812, 1815。
2. YAML を読み、国境の変化の年・理由、君主の在位年、情勢の記述、出来事の年と内容を、あなたの知識と照らし合わせる。
3. 照合用に `/home/user/venv/bin/python tools/compare_hb.py <年> --iso <国コード>` も使える（照合先は粗いので参考程度）。
4. 特に見てほしい観点：
   - 教科書や一般的な歴史地図と比べて、明らかにおかしい国境・塗り・所属年（例：まだ割譲されていない地域が先に塗られている、条約の年が違う）
   - 君主の名前・在位年の誤り、抜け
   - 事実の誤り、日本の高校世界史の表記から外れた名前
   - 見た目の問題（ラベルの名前がおかしい、隣国と色が同じで区別できない、など）

## 成果物
`docs/review/<ファイル名>` に Markdown で書く。各指摘は次の形にする：
- **[重要度] 対象**（ファイル名と ID、年）：何がおかしいか → 正しいと思う内容（根拠：条約名・通説など）。確信度（高・中・低）。
  - 重要度：A＝地図や事実が明らかに誤り、B＝不正確・改善すべき、C＝好みや細部
確信度の低いものは「要確認」として分けて書く。問題がなかった観点も短く書く（例：「ポーランド分割の3段階は正しく描かれている」）。
