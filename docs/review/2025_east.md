# レビュー（1914–2025）：ロシア・ソ連と後継国、ハンガリー・ルーマニア・バルカン、トルコ、中東・北アフリカ（担当 east）

- 対象：data/regions/north_east.yaml・ottoman.yaml（1914 年以後の項目）、data/polities/north_east.yaml・ottoman.yaml・habsburg.yaml（ハンガリー）、data/events/north_east.yaml・ottoman.yaml、data/events/europe.yaml の担当地域に関わる項目、data/religion/north_east.yaml・ottoman.yaml（1914 年以後）。北アフリカは west.yaml（A 担当）の範囲なので、目立つ点だけ見た。
- 方法：
  - `npm run data` で作った atlas.json から、ピースごとの所属（owner / overlord / certainty / 効いている地域と label）を年ごとに集計した。対象は EST・LVA・LTU・BLR・UKR・MDA・RUS・GEO・ARM・AZE・KAZ・UZB・TKM・HUN・ROU・BGR・SRB・XKX・MNE・MKD・ALB・GRC・BIH・TUR・CYP・SYR・LBN・ISR・ガザ・西岸・JOR・IRQ・KWT・SAU・ARE・QAT・BHR・IRN・AFG・EGY・LBY・TUN・DZA・MAR。年は 1914 年から 2025 年までの約 50 の年。
  - 1914 年以後の regions の cause の文を全部読み、条約・日付を確かめた。政体の names・rulers・periods（1900 年以後）を通読した。
  - 出来事に付く政体の印（チップ）の名前を全出来事について計算して、時代に合わない名前を探した。
  - `node tools/snapshot.mjs`（?range=476-2030）：東欧（1914–2025 の主な年 28）、バルカン（1915・1918・1919・1920・1941・1943・1944・1945・1992）、中東（1914・1917・1918・1919・1920・1922・1925・1932・1948）、カフカス・中央アジア（1914・1918・1919・1920・1921・1922・1924）、ロシア（1918・1919・1920・1922・1941・1942）。画像は `.cache/snapshots/review_2025_east/`。
- 合意済みの方針（保護国・委任統治は宗主国の色＋副ラベル、枢軸国の併合は occupied、ソ連のバルト三国・ポーランド東部は斜線なし、クリミア 2014・2022 年以後は occupied、ナジュドの帯、アフガニスタンの独自色）と、ピースの都合で描けないナゴルノ・カラバフ・ニコシアは指摘していない。
- 件数：A 2件、B 6件、C 14件、要確認 5件

## 重要度 A

- **[A] ヒヴァ・ハン国とブハラ・アミール国が 1918–1919 年にソヴィエト・ロシアの色になっている**（regions/ottoman.yaml `khorezm`（ホラズム・ダショグズ）、`lebap`（ブハラ領のアム川中流））。
  - 問題：どちらも 1873 年／1868 年から `owner: russia`（保護国。1914 年の地図では「ヒヴァ ロシアの保護下」「ブハラ ロシアの保護下」と正しく出る）で、次の項目が 1920 年の `khorezm_uz`・`khorezm_tm`（ホラズム人民ソヴィエト共和国）と `lebap`（ブハラ人民ソヴィエト共和国）になっている。このため、1918・1919 年の地図では、ヒヴァ・ブハラが副ラベルも保護国の枠もない「ロシア・ソヴィエト共和国」（russia の 1917–1921 年の名前）の普通の塗りになる（caucasus/map_1918・map_1919 で確認）。
  - 史実：十月革命の後、両国はソヴィエト政権から事実上独立した。ブハラはコレソフの攻撃（1918 年 3 月）を退け、キズィル・テペの和約でソヴィエト側に独立を認めさせた。ヒヴァでは 1918 年初めにロシア軍が引き揚げ、トルクメンのジュナイド・ハンが実権を握った（khiva の rulers の note にも書いてある）。両国がソヴィエト政権の手に落ちたのは 1920 年（ヒヴァは 2 月、ブハラは 9 月）。
  - 直し方：`khorezm` と `lebap` に `{from: 1918, owner: khiva}`／`{from: 1918, owner: bukhara}` を足す（ヒヴァは実権がジュナイド・ハンにあったので uncertain でもよい）。polities の khiva・bukhara の names（ヒヴァ・ハン国／ブハラ・アミール国が 1919 年まで）はすでにこの形になっている。
  - 確信度：高。
- **[A] 出来事の政体の印に、時代の違う国名が出る（セルビア公国・ロシア帝国など）**（polities の names の抜け）。
  - `serbia`：names は「セルビア王国（1882–1918）」「セルビア・モンテネグロ（2003–2005）」「セルビア共和国（2006–）」だけで、その間は標準の name「セルビア公国」になる。このため、「ユーゴスラヴィア紛争の始まり」（1991）、「ボスニア紛争」（1992）、「コソヴォ紛争とNATOの空爆」（1999）、「ミロシェヴィチ政権の崩壊」（2000）の印が「セルビア公国」になる（east/map_1991、balkans/map_1992 で確認）。→ `{from: 1919, to: 2002, name: セルビア共和国（ユーゴスラヴィアの構成共和国）, short: セルビア, kind: 構成共和国}` などを足す（1945 年までは地図に出ないので、1945–2002 だけでもよい）。
  - `montenegro`：同じ理由で「コソヴォ紛争」（1999）の印が「モンテネグロ（主教公国）」になる。→ `{from: 1945, to: 2005, name: モンテネグロ共和国（ユーゴスラヴィアの構成共和国）}` を足す。
  - `russia`：names の「ロシア・ソヴィエト共和国」が `to: 1921` なので、1922 年の「ラパロ条約」（4 月）と「ソヴィエト社会主義共和国連邦の成立」（12 月）の印が「ロシア帝国」になる。→ `to: 1922` にする（ソ連の成立後のロシア共和国を出したいなら 1990 年まで延ばす）。
  - 確信度：高（計算で確かめた。直すのは names を足すだけ）。

## 要確認（確信度が低いもの）

- **ベッサラビア・北ブコヴィナの 1941–1944 年（romania、certain）**：方針「枢軸国の併合で戦後無効になったものは occupied」の機械的な拾い出し（1937・1948 年の両方と持ち主が違う）には、1937 年がルーマニア領だったため入らない。ルーマニアの立場では領土の回復だが、パリ講和条約（1947）でソ連領と確定したので、ソ連の 1940 年の併合を certain で描く以上、1941–1944 年は occupied（副ラベル「ベッサラビア（ルーマニアが再併合）」）にするほうが方針に沿うかもしれない。多くの教科書の地図（1942 年の枢軸国の最大版図）はルーマニア領として塗るので、今のままでもよい。まとめ役の判断を。
- **1919 年末のハンガリー東部**：ルーマニア軍は 1919 年 8 月から 1920 年 3 月まで、ティサ川以東（デブレツェン・セゲド周辺）を占領していた。いまの地図では、ルーマニア領になるクリシャナだけが occupied で、ハンガリー本土は certain。数か月の占領は描かない原則どおりともいえるが、年末の時点では占領中だった。
- **1918 年末のヴィリニュス地方**：`vilnius_region_1`・`_4` は「ドイツ軍（撤退中）」、`vilnius_region_2` は russia、`vilnius_region_5` は lithuania と、隣り合うピースで扱いが分かれる。年末の実態（ドイツ軍が撤退中で、リトアニア政府はヴィリニュスにいた。赤軍の入城は 1919 年 1 月）にはどれも近いが、そろえてもよい。
- **2025 年のポクロウシク**（`pokrovsk`）：cause に「要確認」とあるとおり、年末の前線しだい。2026 年の時点で見直す。
- **1918 年のクリミア（white_movement）**：11 月以後はクリミア地方政府（ソロモン・クリム）で、義勇軍の影響下ではあるが、白軍そのものではない。white_movement・uncertain の描き方で大きな問題はない。

## 問題がなかった観点

- **第一次世界大戦の占領の段階**：オーバー・オスト（1915）、リガ（1917 年 9 月）・ムーンスンド諸島（10 月）、セルビア・モンテネグロ・アルバニアの分割占領（1915–1916）、ワラキア（1916）・ブライラ（1917）、ロシア軍のエルズルム・トラブゾン（1916）、メソポタミア（バスラ 1914 → クート → バグダード 1917 → モースル 1918）、パレスチナ（1917 年末にイェルサレムまで、1918 年に全域）、アカバ（1917）、メディナの降伏（1919）。年末の状態として正しい。
- **ロシア内戦**：1918・1919・1920 年末の白軍・赤軍・各民族政府の範囲（コルチャーク政府の崩壊、ヴランゲリのクリミア撤退、エストニア勤労者コミューン・ラトヴィア・ソヴィエト共和国、ザカスピ臨時政府、北カフカス山岳共和国、極東共和国 1920–1922、北サハリンの保障占領 1920–1925、トゥヴァ 1921・1944）が筋の通った形で描かれている。
- **ソ連の成立と内部の境界**：ザカフカース連邦（1922–1936）、白ロシア共和国の拡大（1924・1926）、モルダヴィア自治共和国（1924）、中央アジアの民族・共和国境界画定（1924）、カレリア＝フィン共和国（1940–1956）、ペツェリ・アブレネのロシア共和国への移管（1944–1945）、クリミアの移管（1954）。副ラベルで構成共和国が読める。
- **バルト三国・ポーランド東部・ベッサラビア**：独立（1918–1920）、中部リトアニアとヴィリニュスの帰属（1920・1922・1939・1940）、メーメル（1920・1923・1939・1945）、ソ連の併合（1939・1940）、独ソ戦の年末の前線（1941–1944）、クールラント包囲陣、ザカルパッチャ（1944・1945）。
- **ソ連解体後**：沿ドニエストル（1991、ベンデル 1992）、チェチェン（1991・1995・1996・1999・2000）、アブハジア（1992・1993）、クリミア（2014）、ドネツク・ルハンシク（2014）、2022–2025 年の占領地の広がり（ヘルソン右岸を 2022 年末に外している）。
- **バルカン**：ヌイイ条約（西トラキアの連合国管理 1919・ギリシア 1920、ストルミツァ・西部辺境地域）、トリアノン条約、南バラニャ（1921 年にハンガリーへ）、ドデカネス（1923・1943・1945・1947）、クラヨーヴァ条約（1940）、第 2 次ウィーン裁定、1941 年のユーゴスラヴィア・ギリシアの分割と 1943 年のイタリア占領地のドイツへの移行、北トランシルヴァニアのソ連軍政（1944–1945）、ユーゴスラヴィア紛争（クライナ 1991–1995、東スラヴォニア 1998、ヘルツェグ＝ボスナ 1993–1994、デイトン合意）、コソヴォ（1999・2008・2013）、セルビア・モンテネグロ（2003–2006）。
- **トルコ**：ムドロス休戦協定後の分割占領（スミルナ・アンタルヤ・キリキア・イスタンブル・東トラキア）、カルス・アルダハン・アルトヴィン（1918・1919・1920・1921）、ギリシア軍の進退（1920・1921・1922）、ハタイ（1938・1939）、モースル問題（1926）、キプロス（1914・1960・1974）。
- **中東**：委任統治の成立（1920）、トランスヨルダンとアカバ・マアーン（1921・1925）、サウード家の統一（ハーイル 1921、ジャウフ 1922、ヒジャーズ 1925、ジッダ条約 1927）、イラク（1932）・レバノン（1943）・シリア・ヨルダン（1946）の独立、イランの英ソ占領（1941–1946）とギーラーン共和国（1920–1921）、イスラエル（1948 年末のネゲヴを uncertain、1949 年に確定）、西岸・ガザ・ゴラン（1967）、アラブ連合共和国、クウェート（1961・1990・1991）、湾岸の首長国（1971・ラアス・アル＝ハイマ 1972）、イラク戦争（2003–2004）、「イスラーム国」（2014–2017）、アサド政権の崩壊（2024）。
- **君主・元首**：ロシア・ソ連・ウクライナ・ベラルーシ・モルドバ・バルト三国・カフカス 3 国・ハンガリー・ルーマニア・ブルガリア・ギリシア・アルバニア・ユーゴスラヴィア・トルコ・イラン・イラク・シリア・レバノン・イスラエル・ヨルダン・サウジアラビア・湾岸諸国・エジプトの在位年を確かめ、誤りは見つからなかった。
- **宗教（1914 年以後）**：アルメニア人の虐殺・住民交換後のアナトリア（1923 年に東方諸教会・正教の minor が消える）、強制移住（チェチェン・イングーシ・カルムイク・クリミア・タタール 1944–1957）、ウクライナ東方カトリック教会の強制合同（1946）と復活（1989）、イスラエル（1948）、北キプロス（1974）は描き分けられている。
