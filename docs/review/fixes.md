### 反映しなかった B

- **[B] 神聖ローマ帝国の外枠と「帝国イタリア」**（west_italy）：サヴォワ（`savoy_duchy`）の `overlord: hre` は残した。サヴォイア公国はアルプス以北の帝国領（上ライン・クライスの帝国台帳に載る）で、データ作成方針（agent-brief.md）でも、枠から外すのは「帝国イタリア」だけと決めている。歴史地図でも、サヴォワを帝国の枠の内側、ピエモンテを外側に描くことが多い。ピエモンテ・ニースが外側になるのは、この方針による意図どおりの描き方。
- **[B] マッサ＝カッラーラのピース**（west_italy）：所属は変えず、`tuscany_region` の note を詳しくした。ITA-Massa_Carrara（約1,140 km²）の大部分はルニジャーナ（ポントレーモリ・フィヴィッツァーノなどのトスカーナ領と、マラスピーナ家の小さな帝国封土）で、マッサ＝カッラーラ公国（マッサ・カッラーラ・モンティニョーゾ、約200 km²）はピースの2割ほどしかない。「面積の大きい側に入れる」原則に従い、トスカーナ領のままとした。
- **[B] テメシュヴァル（バナート）の 1716–1717 年の占領**（central の「オスマン領ハンガリー」の項の補足）：バナートの地域は ottoman.yaml にあり、今回は編集範囲外。ハンガリー中部（`ottoman_hungary_hu`、`bihar_hajdu`）だけを 1686 年から occupied にした。
- **[B] プファルツ・ラインヘッセンの 1814–1815 年**（central）：まとめ役の指示により今のまま（利用者に確認中）。

- **ワグラム**：本文と見出しを「ワグラム」にしたが、出典 URL（ja.wikipedia「ヴァグラムの戦い」）は記事名なのでそのまま。
- **東フリースラント・ロイス・シュヴァルツブルクの kind（「伯領→侯国」の形）**：レビューの対象外だったので、そのままにした。

## 北欧・東欧・オスマン

対象：docs/review/east.md。A・B はすべて（一部は注記で）対応した。以下は反映しなかったもの、または一部だけ反映したもの。

### B
- **ポーランド南東の細い帯（1809〜1815年）**：原因はピース `POL-powiat_hrubieszowski` のジオメトリ。CGAZ 由来のスリバーが南西へ（緯度49.5度付近まで）伸びている（ポリゴンの外接矩形が 22.64–24.18E, 49.49–51.00N）。所属データ（ザモシチ地区：1772 オーストリア、1809 ワルシャワ公国）は正しいので、データ側では直せない。**要対応（tools / ピース生成の担当）**：このピースからスリバー部分を切り落とす。
- **スウェーデン領ヴィスマル**：regions/germany_north.yaml の担当範囲のため触っていない（**要対応：担当 germany_north**。小さなカスタム・ピースか注記）。
- **バナート（central.md の B「オスマン領ハンガリー」の末尾）**：反映済み。`banat_ro`・`banat_rs`・`lugoj_caransebes` を 1716–1717 年 habsburg（occupied）、1718 年パッサロヴィッツ条約で確定とした。同じ戦争で占領された北セルビア（1717 年ベオグラード攻略）・東スレム・オルテニアは、依頼の範囲外なので 1718 年の切り替えのまま。
- **ハンガリー（ブダ・スラヴォニア）の再征服**：habsburg.yaml の担当が occupied にする前提。こちらはトランシルヴァニア（1691）、ビホル（1692）、アラド（1688、年は要確認）、バーチカ・西スレム（1687）を occupied にした。ハンガリー側と年を揃えて確認してほしい。
- **ワラキアの直轄地（ジュルジュ・トゥルヌ）、南ブコヴィナの範囲、旧モンテネグロのナヒヤ**：ピースが県・市単位で、塗り分けると過大になるため、注記で対応した（モンテネグロは1796年以降ポドゴリツァ市を「不確実」で追加）。

### C
