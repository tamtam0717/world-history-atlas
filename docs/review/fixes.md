## 1815–1914：言語・都市・潮流

対象：docs/review/1914_distributions.md の 2〜4 節。A・B はすべて反映した（下の「一部だけ反映」を除く）。C は簡単で確実なものだけ反映した。

### 反映の方針（田村さんの決定 2026-11-21）
- **東欧のユダヤ人の多い都市**：都市のピースが独立している所は、ユダヤ人が最大の集団になった時期（19世紀半ばの目安。1897年のロシア帝国国勢調査に照らす）から `main: yiddish` にした。ミンスク・キシナウ・ヴィリニュス・カウナス・ダウガフピルス・ビャウィストク・ルブリンに加え、同じ条件のシェドルツェ・シャウレイ・パネヴェジース・レーゼクネ・バルツィ・ベンデルも追加した。2番目の集団が2割に届かない所（ビャウィストク・レーゼクネ・バルツィ）は minor を付けない。
- 対象外（都市のピースがなく、周りの郡と一体）：ブレスト・グロドノ・ピンスク・ヴィテプスク・モギリョフ・ゴメリ（いずれもベラルーシの地区単位のピース）、ベルディチフ（ウクライナの地区単位）、オデッサ（市のピースがない。なお1897年はロシア語約49%・イディッシュ語約32%で、ユダヤ人は最大ではない）。
- ワルシャワ・ウッチ・ラドム・クラクフなどは、ユダヤ人が3〜4割でポーランド人が最大なので polish/yiddish のまま。ヘウムは1897年の数字に自信がないので変えなかった。

### 一部だけ反映したもの
- **lang_oran（オラン）**：ピースは現在のオラン県で、市域より広い（周りの農村を含む）。19世紀末のオラン市はヨーロッパ系が多数だが、県全体では判断できないので arabic/spanish のまま。アルジェ市（DZA-Alger）だけを lang_algiers_capital として分け、1880年から french/arabic にした。
- **lang_kars（カルス）**：1880年の項目を立てて note を書き直したが、main は turkish、minor は armenian のまま。1897年のカルス州ではアルメニア人約24%・トルコ人約22%で拮抗するが、カラパパフなどテュルク系の言葉を合わせると最大になるため。
- **lang_circassia**：minor を ukrainian にし、西部（アナパ・クルィムスク・アビンスク・セヴェルスキー・ゴリャチ・クリュチ）を lang_circassia_west（ukrainian/russian）、アディゲ人の残った地域を lang_adygea（russian/caucasian）として分けた。

### 反映しなかったもの
- **[C] lang_brussels（1900年にフランス語）**：集計方法（二言語話者の扱い）で変わるので、今の「要確認」の注記のまま。
- **[C] 言語の凡例が地図の左3分の1を覆う**：画面（src）の担当なので触っていない。**要対応（画面の担当）**：初めは閉じておく、または1列にして小さくする。
- **[C] lviv の「ルヴフ」**：1772年より前はポーランド領なので、ポーランド語の名前のままとした（1772年からレンベルク、modern はリヴィウ）。
- **[C] nafplio（1821–28年の首都なし）**：レビューのとおり許容範囲として変更なし。
- **要確認：sofia（1800年 46,000人）・tula（1800年 30,000人）**：推計の幅の中なので変更なし（どちらも note に「人口は概数・要確認」）。
- **[C] nationalism の広がり（マケドニア・アルバニア・カタルーニャ・フランデレン・バルト・ウクライナ）**：地域の選び方（政治の地域 ID）をまとめて検討する必要があるので、今回は見送り。次に潮流を見直すときの候補。
- **[C] free_trade のリスト**：説明文で保護貿易論者と断っているので、そのまま。
- **[C] ガガウズ語・フリウリ語**：すでに note で「turkish／romansh の色で塗る」と説明していたので変更なし（アルーマニア語の2か所には同じ説明を足した）。
