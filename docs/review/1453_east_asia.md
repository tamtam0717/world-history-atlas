# 独立レビュー：1453–1647 東アジア・内陸アジア（中国・満洲・台湾・モンゴル・新疆・チベット・青海・シベリア東部・日本・朝鮮・琉球）

対象：data/polities・regions・events の china.yaml・inner_asia.yaml・japan_korea.yaml（1453–1647）。
方法：`npm run data` で作った atlas.json から全ピースの 1453–1647 の所属を省・州ごとに年を追って書き出して確かめた（CHN・TWN・MNG・JPN・KOR・PRK・ロシア東部）。地図は `node tools/snapshot.mjs`（中国 1453/1500/1550/1600/1621/1644–1647、満洲・朝鮮 1600/1619/1621/1626/1636/1642、モンゴル 1453/1500/1550/1600/1636/1642、日本 1500/1592/1593/1609/1637。.cache/snapshots/review1453_ea/）。君主・情勢・出来事（約 140 件）・地域の cause/note・首都（cities.yaml）を通説と照らした。隣り合う政体の色の差（ΔE）も計算した。
合意済みの方針（冊封は独自色＋明の帯、朝鮮は 1637 年から清、明の辺境は indirect / nominal、戦国日本は uncertain、1648 年以降は原則変えない）は指摘していない。

## 重要度 A

- **[A] ハルハの君主アブタイ・サイン・ハン**（data/polities/inner_asia.yaml `khalkha` の rulers、1554–1588）：`from: 1554` はアブタイの**生年**で、在位の始まりではない（アブタイは 1554–1588 年の人。en.wikipedia「Abtai Sain Khan」も生没年として 1554–1588 と書く）。このままでは 1554 年から、生まれたばかりの子がハルハの君主として右パネルに出る。→ 在位の始まりは 1580 年前後（ハルハ左翼の首長として頭角を現し、1586 年ごろダライ・ラマ3世から「ハン」の称号を受けた）なので、`from` を 1580 年ごろにし、1550–1579 年は君主を書かないか、ゲレセンジェの子（ノーノホ・ウイジェンなど）を「ハルハ諸侯」としてまとめて書く。note の「在位年は要確認」も残す。確信度：中〜高。

## 重要度 B

- **[B] 咸鏡道北部の 1592 年**（data/regions/japan_korea.yaml `imjin_1592`、PRK-North_Hamgyong、1592）：年末の状態として「日本軍の占領」に塗っているが、note にもあるとおり、咸鏡道北部（鏡城・吉州より北）は 1592 年の秋から冬に鄭文孚の義兵が取り戻した（加藤清正の軍は吉州・端川より南に退き、翌 1593 年初めに咸鏡道から撤退）。→ PRK-North_Hamgyong を `imjin_1592` から外して 1592 年も joseon[ming] にするか、certainty: uncertain にする。確信度：中。
- **[B] 撫順・本渓の 1589 年**（data/regions/china.yaml `cn15_liaoning_benxi`、CHN-Fushun・CHN-Benxi、1589–1617）：ピース全体を 1589 年から後金にしているため、明の辺境の城の撫順（撫順所）・清河堡が 1618 年まで明のものだったことが地図に出ず、1618 年の出来事「七大恨と撫順陥落」のときに地図が何も変わらない。note で断っているが、出来事と地図が食い違って見える。→ 1589–1617 年は later_jin の certainty: uncertain にするか、1618 年に cause「撫順・清河を落とす」を持つ項目を足して「国境の変化」に出す（所有者が同じなら certainty の切り替えで）。確信度：中。
- **[B] 大順の情勢の「開封（1642）を取った」**（data/polities/china.yaml `shun` の periods 1641–1645）：李自成は開封を3度囲んだが落とせず、1642 年の第3次包囲の最中に黄河の堤が切られて町は水没した（出来事「開封の水没」の本文はそう書いている）。「取った」は誤り。→「開封を囲み（1642 年に黄河の決壊で水没）」などに。確信度：高。
- **[B] ツァン王と明の色が近い**（`tsangpa` #faabc2 と `ming` #faae9f、ΔE 19.8、1618–1641）：明の nominal のカム（チャムド・カンゼ）とツァン王（ラサ・ニンティ）が接し、どちらもサーモン系で、白い斜線の有無だけで見分けることになる。チベットが明の一部のように見えやすい。→ tsangpa の色を青紫・黄土など別の色相に変える（1648 年以降の地図には出ない政体）。確信度：高（見た目の問題）。
- **[B] 鄭成功の勢力の廈門（1646–1649）**（data/regions/china.yaml `cn15_fujian_xiamen`、CHN-Xiamen、1646–）：note にもあるとおり、廈門は 1650 年まで一族の鄭彩・鄭聯（魯王を奉じる）が押さえており、鄭成功が挙兵した（1646 年末〜1647 年初め）のは南澳・烈嶼（小金門）。1648 年以降の既存データとつなげるための単純化だが、出来事「鄭成功の挙兵」（1646）の「金門・廈門を拠点に」は言い過ぎ。→ 本文を「南澳・金門で挙兵し、一族の鄭彩・鄭聯が押さえる廈門を拠りどころに」などに。地図はこのままでよい。確信度：中。
- **[B] ハルハの君主エリイェヘイ・メルゲン・ハンの在位（1588–1635）**（inner_asia.yaml `khalkha`）：47 年の在位は長すぎる可能性が高い（子のゴンボドルジは 1594 年生まれで、1620 年代にはすでにトゥシェート・ハン家の当主として動いていたとされる）。要確認の印はあるが、1630 年代の空白や重なりを点検してほしい。確信度：低〜中。

## 重要度 C

- **[C] 1636 年の「後金→清」の国境の変化**（china.yaml・inner_asia.yaml の多くの地域、1636）：国号の変更が 18 地域以上の「国境の変化」として右パネルに並ぶ（満洲・内モンゴル）。1644 年の「明→南明」も同様に多い。色はほぼ同じ（ΔE 7.4）なので地図は自然だが、パネルが長くなる。→ 余裕があれば、所有者の付け替えだけの項目は cause を短い共通文にするか、パネル側でまとめる。
- **[C] 長城のれんが造り**（china.yaml `ming` の periods 1453–1505、出来事「万里の長城の修築」1474）：余子俊の楡林の辺牆（1474）は主に版築（土）で、今に残るれんが造りの長城は主に 16 世紀後半（嘉靖・万暦年間、戚継光の薊鎮など）。「成化年間から今に残るれんが造りの形に」は言い過ぎ。→「16 世紀後半にかけて、れんが造りに築き直した」に。
- **[C] 戦国日本の名前の区切り**（japan_korea.yaml `japan` の names）：「日本（織豊政権）」が 1573–1602 年で、1600–1602 年の君主（徳川家康）・情勢（関ヶ原）と食い違う。→ 織豊政権を 1599 年まで、1600–1602 年を「日本（徳川家康の政権）」などに。将軍がいない 1566–1567 年（義輝の死後〜義栄）も君主が空になるので note に一言あるとよい。
- **[C] 天順帝の表記**（china.yaml `ming` の rulers）：高校の教科書は「正統帝（英宗）」。「英宗（正統帝の復位、天順年間）」のほうが教科書に近い。
- **[C] トゥルファンとトルファンの混在**：出来事「トゥルファンがハミを攻め取る」（1473）の本文が「トルファンのスルターン・アリー」、`yarkent` の情勢も「トルファン・ハミ」。題名にそろえて「トゥルファン」に（または全体を「トルファン」に）。
- **[C] 大順の建国の月**（出来事「李自成が西安を落とす」1643、`shun` の rulers note）：「翌年1月」「1644年1月」は陰暦の正月（西暦では 1644 年 2 月 8 日）。「1644年の元日（旧暦）」などに。
- **[C] 後金の都の空白**（data/cities.yaml）：ヘトゥアラが 1603–1618、遼陽が 1621–1624 で、1619–1620 年（界藩城・薩爾滸城）に都がない。小さいので、ヘトゥアラを 1620 年まで延ばすので足りる。
- **[C] 丁酉倭乱の年末の倭城**（japan_korea.yaml `imjin_wajo`、1597）：1597 年末の日本軍は釜山・蔚山だけでなく、泗川（慶尚南道）・順天（全羅南道）まで南岸に倭城を連ねていた。ピースが粗いので、cause か note に「順天・泗川にも倭城」と書くだけで足りる。
- **[C] 下アムールと沿海州の扱いの差**（inner_asia.yaml `amur_primorye_pre1858` は 1453 年から所属なし、`pre1648_primorye` は ming[nominal]）：奴児干都司（アムール川下流、いまのハバロフスク地方）こそ明の拠点だったので、沿海州だけ明の nominal なのはやや不揃い。どちらかにそろえる（1430 年代の撤退後はどちらも所属なし、でもよい）。
- **[C] 鴨緑江上流の「廃四郡」**（japan_korea.yaml `korea`、PRK-Jagang）：note は世宗の四郡六鎮に触れているが、四郡は 1455–1459 年に廃された（廃四郡）。地図は 1648 年以降と同じ朝鮮のままでよいので、note に一言足す程度。
- **[C] 甘粛の酒泉**（`cn15_gansu_jiuquan`、1528–1643 ming[nominal]）：粛州（酒泉の町）は明の衛所として最後まで守られた。ピースの大半が嘉峪関の外なので nominal は理解できる（note にあり）。このままでよい。
- **[C] 永暦帝の 1647 年の広西東部**：1647 年に李成棟の清軍は梧州など広西東部にも入った（翌 1648 年に李成棟が寝返る）。年末の状態としては広西全体を南明でもよいが、梧州を不確実にする手もある。

## 要確認（確信度の低いもの）
- ダヤン＝ハンの没年（1517 説で描いている。1543 説もある）と、ボディ・アラクの即位年（1519）。どちらもデータに要確認の印あり。
- トゥルファン・ハミが「ヤルカンドのハン家の一族の支配に入る」年（1570）。マンスール・ハンの子シャー・ハン（1543–1570）の後とすれば妥当。モグーリスタン（data/polities/ottoman.yaml）の君主にシャー・ハン（1543–1570）がなく、1544–1569 年のトゥルファンの君主が出ない（担当 E の範囲だが境を接するので報告）。
- 山西の 1644 年末：太原は 1644 年 10 月に清が取ったが、山西南西部（臨汾・運城）がいつ大順から清に移ったかは確かめられなかった（清で描いている）。
- 1453 年末の兀良哈三衛の地（承徳・朝陽・阜新・白城・松原）をエセン（オイラト）の確かな支配としている。エセンが三衛を従えたのは確かだが、「確か」の塗りは強め。uncertain でもよい。

## 問題がなかった観点
- **明清交代（1616–1647）**：後金の拡大（1589 建州統一、1599–1619 のフルン四部の併合、1619 開原・鉄嶺、1621 遼瀋、1622 広寧、1633 旅順、1642 錦州、1644 寧遠＝葫蘆島）、1644 年末の三つ巴（清が北京・河北・山東・山西、大順が陝西・甘粛・寧夏・河南西部・湖北北部、大西が四川、南明が江南以南）、1645 年の江南・江西北部・湖北、1646 年の浙江東部・福建・贛州、1647 年の広東・海南・湖南（不確実）と四川（清の不確実）、南明に残る広西・貴州・雲南は、どれも年末の状態として通説どおり。1648 年の既存データ（李成棟・金声桓の寝返り）にも自然につながる。
- **内モンゴル**：エセン（1453）→ 北元の分裂 → ダヤン＝ハンの再統一（1510）→ アルタン＝ハンのトゥメト（1542、1571 年から明の帯＝順義王）・チャハルの東遷（1547）→ リンダン＝ハンの西進（1628）→ 後金への服属（ホルチン 1626、ハラチン 1628、フフホト 1632、チャハル・オルドス 1635）の順序と年が正しい。
- **青海・チベット**：亦不剌の青海入り（1510）、アルタンの青海遠征（1559）、チョクト（1632）、グシ・ハン（1637 青海、1640 カム、1642 ツァン）、ラサのリンプン派支配（1498–1517）、ツァン王の自立（1565）とウー征服（1618）、ラダックのグゲ併合（1630）が正しく描かれている。
- **新疆**：ハミの奪い合い（1473・1482・1513）、ドゥグラト（1465）→ ヤルカンド・ハン国（1514）、オイラトのジュンガル盆地への移動（1600 ごろ）とエルデニ・バートル（1635）は通説どおり。
- **台湾**：オランダの澎湖占領（1622–24）、台南（1624）、スペインの基隆（1626）・淡水（1628）、オランダの南西部平定（1636）と北部の奪取（1642）、明の澎湖の遊兵（1597）は正しい。マカオ（1557、ポルトガルの不確実）も方針どおり。
- **日本・琉球**：戦国（1467–1589 斜線）→ 1590 年の統一、和人地（道南十二館 → 蠣崎氏 → 松前藩）と蝦夷地（1593 nominal）、奄美（1466 喜界島、1609 占領、1611 薩摩の直轄）、琉球の明の帯（1643 年まで）は史実と方針に合う。将軍・天下人・琉球国王・朝鮮国王・明の皇帝・南明の皇帝の在位年は、上に挙げたもの以外は正しい。
- **朝鮮**：明の帯 → 1637 年から清の帯（丙子胡乱の降伏が西暦 1637 年 1 月であることを note で説明）、壬辰倭乱（1592 年末の占領、1593–1598 の南岸の倭城）の描き方は方針・史実に合う（咸鏡道北部を除く）。
- **出来事**（china 約 55・inner_asia 約 35・japan_korea 約 47）：年・内容に大きな誤りはなく、日本の高校世界史の表記（土木の変・北虜南倭・一条鞭法・張居正・ヌルハチ・ホンタイジ・アルタン＝ハン・応仁の乱・壬辰・丁酉倭乱など）に合っている。上の C の数件を除けば直す所は少ない。
- **首都**：北京（明 –1643、清 1644–）、盛京（1625–1643）、南明（南京 1644・福州 1645・肇慶 1646・桂林 1647）、西安（大順）・成都（大西）、京都・安土・大坂・江戸、首里、漢城、ヤルカンド、ラサ（1642–）、フフホト（1572–1626）は通説どおり。
- **色**：隣り合う組で ΔE が小さいのはツァン王と明（19.8）だけ。後金と清（7.4）は続けて見せるための意図的なもの。
