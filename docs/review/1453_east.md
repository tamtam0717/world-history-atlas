## A（明らかな誤り）

- **[A] リトアニアとスウェーデンの色が同じに見える**（data/polities/north_east.yaml の `lithuania` #e2cb8c と `sweden` #dcc583、1561–1568 年）：ΔE がわずか 2.8 で、リヴォニア騎士団の解散（1561）の後、リトアニア領のリヴォニア（ヴィゼメ・ラトガレ）とスウェーデン領のエストニアが接する所で境目が見えない（北欧ズームの 1561 年の地図で、エストニアとリヴォニアが一続きの黄色に見える）。リヴォニア戦争のいちばん大事な局面で、どちらがどちらを取ったのか分からない → 新しく足した政体ではないが、`lithuania`（1453–1568 だけ使う時期の色を names で変えられないなら、色そのもの）を、ロシア（#cfae8d、ΔE 17.7）ともスウェーデンとも離れた色にする。例：明るい黄緑・薄い橙など（ドイツ騎士団・リヴォニア騎士団・ポーランドとも 20 以上離れるもの）。確信度：高（数値と画像で確認）。
  - 整合メモ（docs/integration-notes-1453.md の 13）の ΔE の確認は「新しい政体が入る組」だけだったため、既存どうしのこの組が漏れたと思われる。
