# 独立レビュー：サハラ以南のアフリカ・オセアニアの 1453–1647

対象：data/{polities,regions,events}/ の west_africa・guinea_coast・east_africa・southern_africa・australasia・pacific（1648 年より前の部分）と、関係する cities.yaml の首都。指示書 docs/agent-brief-1453-rest.md、整合の記録 docs/integration-notes-1453-rest.md も読んだ。
方法：YAML の通読（政体の rulers・periods、地域の timeline、出来事）、atlas.json から 1647→1648 の段差の全ピース比較、`build_data.mjs --missing`（1453・1500・1550・1600・1647 でデータなしゼロ）、snapshot（.cache/snapshots/review_1453afr/：西アフリカ `--zoom -2,12,2.4` の 1453・1470・1500・1505・1530・1543・1550・1575・1591・1600・1620・1647・1648、東アフリカ `38,5,2.6`、南部・中部アフリカ `25,-15,2.2`、オセアニア `170,-15,2`、サントメ `6,1,6`）。データは変更していない。

## 重要度 A

- **[A] サントメ島が 1493–1499 年に所属なし**（guinea_coast.yaml の `st_islands`・`st_sao_tome_pre1648`、1493–1499）：サントメ島のピースの最初の所属が 1500 年（portugal）なので、1493–99 年は「誰の国でもない土地」の点描になる（1495 年の snapshot で確認。隣のビオコ島は 1474 年から portugal[nominal] で塗られている）。一方、出来事「ポルトガル人がサントメ島に入植する」（1493、アルヴァロ・デ・カミーニャ）があり、cities.yaml のサントメも founded 1485 で地図に出ている。`st_sao_tome_pre1648`（until: 1647）は、サントメ島だけを早く塗るために作ったと思われるのに、from が 1500 で `st_islands` と同じ内容になっていて役に立っていない（cause も「プリンシペ島に入植する（サントメ島は1493年）」のまま）。→ `st_sao_tome_pre1648` を 1493 年（または 1485/86 年の最初の入植の年）から portugal にし、cause を「アルヴァロ・デ・カミーニャがサントメ島に入植する」とする。確信度：高。

## 重要度 B

- **[B] ソンガイの滅亡で切り替わる年が 1591 と 1592 に分かれている**（west_africa.yaml の regions `mrt_hodh`・`bfa_oudalan`・`mli_gourma`・`mli_douentza`・`mli_segou`・`mli_san`・`mli_massina`・`mli_kaarta`・`ner_zarma`、1591）：トンディビの戦いは 1591 年 3 月で、トンブクトゥ・ガオ・ジェンネ・アガデスの地域は 1591 年に切り替わる。ところが上の地域は 1592 年に切り替わる（cause に「ソンガイ帝国の滅亡（1591）」と書いてある）。このため 1591 年の地図では、モロッコ領になったガオ・トンブクトゥの西に、ワラタ（ホッド）・セグー・サンなどが「ソンガイ」のまま残り、ホッドの上に大きな「ソンガイ」のラベルが出る（1591 年の snapshot で確認）。マシナ・ディアラにもソンガイの帯が 1591 年末まで残る。→ 年末の状態で描く決まり（docs/data-format.md）に合わせて、これらを 1591 年からにする（デンディに退いた残存勢力 `ner_songhai`・`ner_dendi` の songhai は今のままでよい）。確信度：高。

- **[B] アルマ（トンブクトゥのパシャ領）の年代と帯の食い違い**（west_africa.yaml の polity `arma`、regions `mli_niger_bend`・`mli_gao`・`mli_djenne`・`mli_timbuktu`、events「アルマが自らパシャを選ぶようになる」）：
  1. polity の periods は「1612年から（1591–1611年はモロッコ領として描く）」、出来事も 1612 年なのに、地図の arma は 1618 年から（regions の cause は「年代は要確認」）。地図の 1612–1617 年はモロッコ領のままで、情勢の文と合わない。どちらかの年にそろえる（通説では 1612 年にアルマがパシャを選ぶようになり、1618 年ごろモロッコからのパシャ派遣が絶える。地図を 1612 年にするか、情勢・出来事を「1612 年から自分たちで選び始め、1618 年ごろモロッコの任命が絶えた」と書き直す）。
  2. regions の 1618–1647 年は `overlord: morocco`（帯）だが、polity の note は「モロッコの宗主権は名目的なので、帯（overlord）は付けない」。1648 年から帯が理由なく消える（1647→1648 の段差。integration-notes の段差の一覧にない）。→ 1648 年以降の書き方に合わせて帯を外すか、帯を残すなら note を「1660 年代まで帯」として 1648 年以降も同じにする（後者は 1648 年以降の変更になるので報告扱い）。確信度：高（食い違いがあること）。

- **[B] オランダのサントメ占領（1641–48）が地図にない**（guinea_coast.yaml の `st_islands`、events「オランダがサントメを占領する」1641）：出来事では 1641 年にオランダがサントメの町と砦を占領し、1648 年に撤退したとある。同じ時のルアンダ・ベンゲラ（southern_africa.yaml の `ao_luanda`・`ao_benguela`）は 1641–47 年に netherlands[occupied] で描いているのに、サントメ島は portugal のまま。→ サントメ島（STP-Sao_Tome_Province）に 1641–47 年の netherlands[occupied]（until: 1647 の地域）を足す。確信度：中〜高（オランダは 1641 年 10 月に町を、1642 年初めに要塞も取ったとする記述が多い）。

- **[B] ハウサ諸王国の副ラベルが 1647 年までない**（guinea_coast.yaml の `ng_kano`・`ng_katsina`・`ng_zazzau`・`ng_zamfara`・`ng_sokoto`・`ng_yauri`、west_africa.yaml の `ner_gobir`・`ner_maradi`・`ner_konni` の 1453 年の項目）：hausa_states は複数の王国を一色で塗り、副ラベルで国名を出す決まり（polity の note）だが、1453 年の項目に label がないので、1453–1647 年は「ハウサ諸国」の一つの塊になり、1648 年から急にゴビル・カツィナ・ザムファラ・カノなどのラベルと境界線が出る（1647・1648 年の snapshot で確認）。カノ（ムハンマド・ルンファ）・ザザウ（アミナ）は出来事・情勢にも出てくるので、名前が地図にないのは惜しい。→ 1453 年の項目に 1648 年と同じ label（カノ・カツィナ・ダウラ・ザザウ（ザリア）・ザムファラ・ゴビル・ヤウリなど）を付ける。確信度：高。

- **[B] コンゴ王アフォンソ1世の即位年**（southern_africa.yaml の events「アフォンソ1世がコンゴ王に」1506 と polity `kongo` の rulers）：出来事は 1506 年、rulers はジョアン1世 1470–1509・アフォンソ1世 1509–1542。どちらかにそろえる（ジョアン1世の死とアフォンソの即位を 1506 年とする古い説と、1509 年とする近年の説〈Thornton〉がある。rulers が 1509 年なら、出来事も 1509 年にするか、本文に「1506年（1509年とも）」と書く）。確信度：高（食い違いがあること）。

- **[B] ルワンダ王国が 1453 年から塗られている**（east_africa.yaml の `rwa_core`、1453–1647）：rwanda_kingdom[uncertain] が 1453 年から。ニギニャ朝の王国の実際のまとまりは 17 世紀（ルガンズ・ンドリのころ。Vansina は 17 世紀なかば）とされることが多く、同じ担当のブルンジ（`bdi_core`）は「成立年ははっきりしない」として 1600 年から塗っているので、扱いがそろっていない。→ 1600 年ごろまで所属なし（note に伝承上の初期の王たち）にするか、ブルンジと同じ基準で年を決める。確信度：中。

- **[B] オヨの亡命期の都の表記**（cities.yaml の `igboho` の name「イボホ」）：情勢・地域・出来事はすべて「イグボホ」と書いているのに、都市の点だけ「イボホ」。ヨルバ語の Igboho の gb は一つの子音で、日本語では「イグボホ」が普通。→ 「イグボホ」にそろえる。確信度：高。

## 重要度 C

- **[C] モンバサの首都の終わりの年**（cities.yaml の `mombasa` の capital 1453–1588）：polity `mombasa` と地域 `ken_mombasa` は 1592 年まで mombasa。1589–92 年は町に首都の印がない。1589 年のジンバ人・ポルトガルの破壊を区切りにしたのなら、そのままでもよいが、1592 年にそろえる方が地図と合う。
- **[C] ダホメのおこりの出来事の年**（guinea_coast.yaml events「ダホメ王国のおこり」1625）：地域・首都・ダコドヌの在位は 1620 年から。本文も「伝承の年代は1620年ごろ」と書いているので、出来事も 1620 年でよい。
- **[C] アンタナナリボの都の年**（southern_africa.yaml の `mg_imerina` 1610、merina の rulers のアンドリアンジャカ 1612–1630）：地域・出来事は 1610 年、在位は 1612 年から。どちらも推定なのでよいが、1612 年に寄せるか note に「在位は1610年ごろから」と書くと読みやすい。
- **[C] ジガンショール**（west_africa.yaml の `sen_ziguinchor`）：note に「町は1645年」とあるのに、portugal の塗りは 1648 年から（1647→1648 の段差）。1645 年から portugal にしてよい（until: 1647 の地域で）。
- **[C] ルアンダの建設年**（southern_africa.yaml の polity `ndongo` の periods「1575年にポルトガルがルアンダに来ると」）：地域・出来事は 1576 年（1575 年に上陸）。情勢の文も「1575年にポルトガル人が上陸し、翌年ルアンダを建てると」とするとそろう。
- **[C] ビオコ島の年**（guinea_coast.yaml の `gq_bioko` 1474）：cause は「1472年ごろ到達」なのに from が 1474。どちらかにそろえる。
- **[C] ムタパ王国の表記**（southern_africa.yaml の polity `mutapa`）：高校世界史の教科書・用語集は「モノモタパ王国」が主。name は「ムタパ王国（モノモタパ）」で問題ないが、地図ラベル（short）は「モノモタパ」の方が教科書と結びつきやすい（1648 年以降のラベルも変わるので好みの範囲）。
- **[C] モシ諸王国とハウサ諸王国が同じ色**（#d3ca7e）：integration-notes に既出。1500 年の西アフリカの画面では両方が同時に映り、同じ色の塊が二つ並ぶ。隣り合わないので誤認は起きにくいが、次の見直しの候補として同意する。
- **[C] ハワイの出来事**：pacific.yaml の 1453–1647 年の出来事に、ハワイ島を統一したと伝わるウミ・ア・リロア（16 世紀初め）のような在地の出来事がない（us_hawaii の note にはある）。トンガ・ポンペイの出来事はあるので、1 件あると太平洋の在地社会の見え方がよくなる。
- **[C] ハライブ・トライアングル**（east_africa.yaml の `sdn_halaib`、1453 mamluk 確か）：内陸はベジャ人の遊牧地で、隣の SDN-Red_Sea（所属なし）との差が大きい。エジプト本体に合わせた扱いとして理解できるが、uncertain でもよい。

## 要確認（確信度の低いもの）

- **ゴンジャのンデウラ・ジャクパの年代**（guinea_coast.yaml の `gc_gonja` 1620「17世紀前半」）：ジャクパの活躍を 1620 年代とする説と 1670 年代とする説がある。1620 年に「確か」に切り替える根拠が弱ければ、1647 年まで uncertain のままでもよい。
- **モシの騎兵のトンブクトゥ周辺の襲撃（1477 年ごろ）**（west_africa.yaml の polity `mossi` の periods）：モシのトンブクトゥ攻撃は 14 世紀（1330 年代）の記事がよく知られ、15 世紀後半はワラタ（1480）・マシナ方面の襲撃が主。1477 年の記述の出典を確かめたい。
- **コリ・テンゲラの在位**（polity `futa_toro` の rulers 1490–1512）：1512 年はテンゲラ（父）がソンガイ軍に討たれた年とされ、コリの征服を 1512 年以降とする説もある。「年代は諸説」と書いてあるので現状で可。
- **マリ王マフムード3世（1496–1559）**：自身で「要確認」としている通り、この時期のマンサの系譜は不確実。マフムード2世・3世の在位年をそのまま出すより「歴代のマンサ（名と在位は不確実）」の1行にする方が、指示書の「誤った断定より粗いが正しい方がよい」に合う。

## 問題がなかった観点

- **ソンガイ**：ソンニ・アリ（1464–92）、アスキア・ムハンマド（1493–1528、1496–97 のメッカ巡礼）、ダーウード（1549–82）、イスハーク2世とトンディビの戦い（1591）、デンディの抵抗（–1599）の君主・年代は通説どおり。トンブクトゥ（1468）・ジェンネ（1473 ごろ）・アガデス（1500–01）・ケッビの自立（1516）・タガーザ（1556–57）・アフマド・バーバーの連行（1593、1607 年帰郷）も正しい。
- **マリ王国の縮小**：ジェンネの喪失、1545 年ごろのダーウードによる都の略奪、カーブの自立、1599 年のジェンネでの敗北が地図・情勢に一貫して出ている。
- **ジョロフ**：ダンキの戦い（1549）でカヨール・ワロ・バオル・シン・サルームが自立する流れ、アマリ・ンゴネ・ソベル・ファル、デニャンケ朝の成立は妥当。
- **カネム＝ボルヌ**：アリー・ガージーとンガザルガム（1470 年代）、イドリス・カタカルマビのカネム奪回（1507 ごろ）、イドリス・アローマ（1564/70–96、火器とトルコ人の銃兵）、ブラーラのフィトリ湖への後退、バギルミの貢納（17 世紀初め）は通説どおり。
- **ベニン**：エウアレ・オゾルア・エシギエ・オルホグブア・エヘングブダ・オフアンの伝承上の在位、1486 年ごろのポルトガルとの接触、イガラ戦争（1515–16）、ラゴス（エコ）の軍営とアシパ、1553 年のイギリス人の来航はよい。
- **オヨ・ヌペ**：ヌペによるオヨ・イレの陥落（1535 ごろ）、イグボホでの亡命、アビパの帰還（1610 ごろ）、ツォエデのヌペ建国（伝承 1531）は通説どおりで、「年代は目安」も適切。
- **黄金海岸**：エルミナ（1482 ポルトガル → 1637 オランダ）、アクシム（1515 → 1642）、シャマ（1640）、モリーのナッサウ砦（1612）、デンキラ・アクワム・アキェムの台頭の年代は妥当。
- **エチオピアとアダル**：ザラ・ヤコブからファシリデスまでの皇帝と在位はすべて通説どおり。シンブラ・クレ（1529）・アクスムの焼き討ち（1535）・クリストヴァン・ダ・ガマ（1541）・ワイナ・ダガ（1543）・ゲラウデウォスの戦死（1559）・アウサへの遷都（1577）・ハラール・アミール国（1647）・スセニョスの改宗（1622、1626 国教化）・ゴンダール（1636）。アダル軍の占領を 1529–43 年の occupied で描き、オロモの移動で南の州が順に所属なしになる描き方はわかりやすい（1543・1600 年の snapshot で確認）。
- **フンジ・アルワ・オスマン帝国**：フンジの成立とソバの陥落（1504）、スルタンの在位（アマーラ・ドゥンカス〜バーディ2世）、ハベシュ州（スアキン 1555、マッサワ 1557）、下ヌビアの守備隊（1560 ごろ）、デバルワのオスマン軍の撃退（1578）は通説どおり。北のエジプト（マムルーク朝 → 1517 オスマン帝国）とヌビアの境も自然につながっている。
- **スワヒリ海岸**：ガマのマリンディ寄港（1498）、アルメイダのキルワ・モンバサ攻撃（1505）、キルワの要塞（1505–12）、ミール・アリー・ベイ（1585・1589）、ジンバ人（1587・1589）、ジェズス要塞（1593）とマリンディのスルタンのモンバサ移封、1631 年のユースフの反乱は正しい。貢納国を portugal[nominal] で描くのは 1648 年以降と同じ書き方でそろっている。
- **コンゴ・ンドンゴ・マタンバ**：コンゴ王の系譜（ンジンガ・ア・ンクウ〜ガルシア2世）、ディオゴ・カン（1483）、ジョアン1世の洗礼（1491）、アフォンソ1世の書簡（1526）、ジャガの侵入（1568）、ンドンゴの自立（1556）、ルアンダ（1576）、マサンガノ（1583）、ベンゲラ（1617）、ンジンガ（1622 の交渉、1624 即位、1631 マタンバ）、オランダのルアンダ・ベンゲラ占領（1641–48）は通説どおり。
- **ムタパ**：ムトタ・マトペからマヴラ2世までの王名と推定年、シルヴェイラの殺害（1561）、バレトの遠征（1571–73）、1607 年の約束、1629 年の臣従（帯）、チャンガミレの反乱の後のマニカ・キテヴェ・バルエの自立、トルワ（カミ）は妥当。
- **マダガスカル・インド洋**：メリナの初期の王（アンドリアマネロ〜アンドリアンツィタカトランドリアナ）、フォール・ドーファン（1643）、モーリシャスのオランダ（1638）、モザンビーク島（1507）・ソファラ（1505）・セナ・テテ（1531）は妥当。
- **オセアニア**：1453–1647 年のオーストラリア・ニューギニア・メラネシアを所属なしにし、ヨーロッパ人の到達（ヤンスゾーン 1606、トレス 1606、ハルトフ 1616、カルステンスゾーン 1623、ニュイツ 1627、バタヴィア号 1629、タスマン 1642・1644、マゼラン 1521、サラサール 1526、サアベドラ 1528、オルティス・デ・レテス 1545、レガスピ 1565、メンダーニャ 1568・1595、キロス 1606、ル・メールとスホーテン 1616、タスマンのトンガ・フィジー 1643）を出来事だけで扱っているのは指示どおりで、年代・内容とも正しい。トンガのトゥイ・トンガ／トゥイ・ハアタカラウア（15 世紀後半）／トゥイ・カノクポル（17 世紀初め）の二重王権、マリアナの spain[nominal]（1565）→ 確か（1668・1695）もよい。
- **1647→1648 の段差**：全ピースを比べた。integration-notes に書かれたもの（ワッサ、フィトリ湖、バナディール、ジンマ、ベニシャングル、カールタ、確からしさの段差）のほかに見つかったのは、上の B のアルマの帯と C のジガンショールだけ。ルアンダ・ベンゲラの段差（オランダの占領 → ポルトガル）は 1648 年の奪回の cause があり正しい。
- **塗り漏れ**：`build_data.mjs --missing` で 1453・1500・1550・1600・1647 年にデータなしのピースはない。
- **北アフリカ・エジプトとの境**：サハラ（所属なし）とトゥアレグ・アガデス、モロッコのパシャ領（1591–）の飛び地、カワール・ティベスティ（所属なし）、ヌビアの描き方に不自然な所はなかった。
