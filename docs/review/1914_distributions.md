# 独立レビュー：宗教・言語（民族）の分布、都市、潮流（1648–1914）

レビュー担当：作成に関わっていないエージェント（2026-11-21）
対象：data/religion/、data/language/、data/cities.yaml、data/movements/（形式は docs/religion-format.md、docs/language-format.md、docs/movements-format.md）
方法：
- `npm run data` で atlas.json を作り、宗教 210 地域・言語 427 地域・都市 352・潮流 59 件の変遷を一覧にして読んだ。
- 開発サーバ（`?range=1648-1914`）を Playwright で開き、`l=religion` / `l=language` / `mv=<ID>` で 1700・1750・1880・1900 年の画面を確認した。
- データ・コードは変更していない。

重要度：A＝地図や事実が明らかに誤り、B＝不正確・改善すべき、C＝好みや細部。

## 1. 宗教の分布（data/religion/）

### いちばん大きな問題：1815年より後の変化がひとつも入っていない
`atlas.json` の宗教データで `from` が 1815 より後の項目は **0件**（言語は81件ある）。各ファイルの見出しも「1648–1815」のまま。このため、言語の地図では 1864 年・1878 年などに切り替わる地域が、宗教の地図では 1815 年の状態のまま 1914 年まで続く。2つの表示が食い違うので、地図を見比べると誤りがすぐ目につく。以下の A-2〜A-6 はこの問題の具体例。

- **[A] 全体**（data/religion/*.yaml、1816–1914）：1815年より後の宗派分布の変化がない → 少なくとも下の A-2〜A-6 と B の項目を足す。言語データ（lang_crimea_steppe 1860、lang_circassia 1864、lang_toplica 1878、lang_dobruja_* 1880 など）と年をそろえるとよい。確信度：高。

- **[A] rel_belarus・rel_belarus_west（1839年）**：1700年から1914年まで「カトリック（ユニエイトを含む）／正教会」のまま。しかし 1839年のポロツク教会会議で、ロシア帝国内のユニエイト教会は廃止され、正教会に統合された。この地域の note にも「ユニエイト教会は1839年まで存続した」と書いてある → 1839年から `main: orthodox, minor: catholic`（西部のグロドノ地方にはローマ・カトリックが多いので minor にする）。1900年の画面でベラルーシ全体がカトリックの黄色になっていて、教科書や一般の地図と大きく違う。確信度：高。
  - 関連 [B] ヘウム（ホルム）地方（rel_poland の一部）：1875年にホルム主教区のユニエイトも強制的に正教に移された → 1875年から minor: orthodox を検討。確信度：中。

- **[A] rel_crimea・rel_nogai_taurida（1783–1914）**：1783年からずっと「スンナ派が多数／正教会が少数」。しかし、併合の後とクリミア戦争の後（1856–62年）にクリミア・タタール人がオスマン帝国へ大量に移住し、ロシア人・ウクライナ人などが入植した。1897年の調査では、タヴリーダ県のクリミア部分でタタール人は約35％にすぎない。言語データ（lang_crimea_steppe）も 1860年にロシア語を多数派にしている → 1860年ごろから `main: orthodox, minor: sunni` にする（山地と南岸の rel_crimea_south はスンナ派のままでもよい）。確信度：高。

- **[A] rel_north_caucasus_muslim のうちチェルケス・アナパ（1864年）**：カフカス戦争の終わり（1864年）に、チェルケス人の大部分がオスマン帝国へ追放・移住させられ（ムハージル）、クバン川左岸と黒海沿岸にはコサック・ロシア人・ウクライナ人・アルメニア人などが入植した。言語データ（lang_circassia・lang_sochi）は 1864年に切り替えているが、宗教はスンナ派のまま → circassia・anapa を別の地域に分け、1864年から `main: orthodox, minor: sunni` にする。確信度：高。

- **[A] rel_south_serbia（トプリツァ・ヤブラニツァ・プチニャ、1878年）**：1690年から 1914年まで「スンナ派が多数」。しかし、露土戦争（1877–78）でセルビア領になったニシュ周辺では、アルバニア人のムスリムが追われ、セルビア人が入植した。言語データの lang_toplica も 1878年にアルバニア語をなくしている → トプリツァ・ヤブラニツァは 1878年から `main: orthodox`。プチニャ（プレシェヴォ周辺）はアルバニア人が残ったので、`main: orthodox, minor: sunni` か、地域を分ける。確信度：高（プレシェヴォの扱いは中）。

- **[A] rel_dobruja（北ドブルジャ、1878年以後）**：1914年まで「スンナ派が多数」。ベルリン条約（1878）でルーマニア領になったあと、ムスリム（タタール人・トルコ人）の多くが移住し、ルーマニア人の入植が進んだ。1899年ごろには、ルーマニア人・ブルガリア人・リポヴァン（ロシア人古儀式派）などのキリスト教徒が明らかに多数。言語データでも 1880年にルーマニア語が多数派になっている → 1880年（遅くとも 1890年）から `main: orthodox, minor: sunni`。確信度：高（切り替えの年は中）。

### B：不正確・改善すべき
- **[B] rel_erivan（エレヴァン・ハン国・ナヒチェヴァン、1828年以後）**：1914年までシーア派が多数。トルコマンチャーイ条約（1828）の後、ペルシアとオスマン帝国からアルメニア人が移住し、1897年のエリヴァン県ではアルメニア人が約53％。言語データ（lang_armenia）は 1830年にアルメニア語を多数派にしている → エレヴァン部分は 1830年ごろ（遅くとも 1880年）から `main: oriental, minor: shia`。ナヒチェヴァンはシーア派のままでよいので、地域を分ける。確信度：中〜高。
- **[B] rel_england_wales のウェールズ（19世紀）**：19世紀のウェールズでは、カルヴァン派メソジストなどの非国教徒が多数になった（1851年の礼拝調査で、礼拝に出た人の約8割が非国教会）。カルヴァン派メソジストは教義では改革派なので、ウェールズは 1800〜1850年ごろから `main: reformed, minor: anglican` とする案がある。確信度：中（非国教徒をどの色にするかは方針次第）。
- **[B] rel_greece_north（テッサリア、1881年）**：1881年にギリシア領になった後、ムスリムの多くが去った。言語データの lang_thessaly_plain は 1881年にトルコ語をなくしている → テッサリア部分だけ minor: sunni をなくす。確信度：中。
- **[B] アルジェリアの都市（アルジェ・オラン、1870年代以後）**：宗教は rel_maghreb / rel_oran でスンナ派のまま。19世紀末のアルジェ市・オラン市では、ヨーロッパ系の住民（カトリック）とクレミュー令で市民となったユダヤ人が多数だった → 都市のピース（DZA-Alger、オラン）だけ `main: catholic, minor: sunni`（1880年ごろから）。言語側の指摘（後述）と合わせて検討。確信度：中。
- **[B] rel_volga_tatar（タタールスタンとバシキール、1648–1914）**：全体を「スンナ派が多数」としている。現在のタタールスタンの範囲でもロシア人とチュヴァシ人（正教）が多く、1897年のカザン県は正教徒が多数。バシキールはムスリムが多い → タタールスタンとバシコルトスタンを分け、タタールスタンは「スンナ派／正教会」の拮抗（main はどちらでも、minor を必ず付ける）と note に明記。確信度：中。
- **[B] rel_abkhazia（1864・1877年）**：アブハズ人のムスリムの多くが 1864年と 1877年にオスマン帝国へ移住した（ムハージル）。スンナ派を main のまま 1914年まで続けるのは疑問 → 1877年以後は `main: orthodox, minor: sunni` を検討。確信度：中。
- **[B] rel_galicia_east（オーストリア領ガリツィア東部、1772–1914）**：「カトリック／正教会」の斜線になっているが、ガリツィアのルーシ人はほとんどがギリシア・カトリック（カトリックに数える）で、正教徒はわずか。斜線が誤解を生む → 1772年以後は minor をなくすか、ユダヤ教徒の多さを note に書く。確信度：中。

### C：細部
- [C] プロイセン合同教会（1817年）：プロイセンではルター派と改革派が合同した。色を変えるほどではないが、rel_germany_base などの note に一言あるとよい。
- [C] リヴォニア・エストニア南部では 1845–48年に農民の一部（1〜2割）が正教に改宗した。note でよい。
- [C] rel_kosovo の 1690年のムスリム多数化は早めの印象（アルバニア人の多数化は18世紀を通じて進んだ）。要確認。
- [C] rel_jabal_druze の 1711年（ドゥルーズ派の移住）は、本格化したのは19世紀（特に1860年以後）。要確認。

### 問題がなかった観点
- 1648–1815 のドイツの宗派の塗り分け（ヴェストファーレン・ラインのカトリック、ヘッセン＝カッセル・アンハルト・リッペ・ナッサウ＝ディレンブルクの改革派、フランケン・バイエルン・オーバーシュヴァーベンのカトリック、帝国都市のルター派）は、通説の「ウェストファリア条約後の宗派分布図」とよく合う。
- ナントの王令廃止（1685）、ザルツブルクの追放（1731–32）、アルスター植民、ハンガリー東部の改革派、トランシルヴァニア（ザクセン人のルター派・セーケイの改革派・ルーマニア人の正教とユニエイト）、ポーランド分割後の右岸ウクライナ・ヴォルィーニの正教化（1795–96）は妥当。
- バルカン（ボスニア・アルバニア・コソヴォ・ブルガリア北東部・西トラキア）の多数派・少数派の判断は、19世紀の民族分布図とおおむね合う。
- レバノン山地（マロン派＝カトリック、ドゥルーズ派＝その他）、イラク・ペルシア湾岸のシーア派の扱いも妥当。

## 2. 言語（民族）の分布（data/language/）

### A：明らかな誤り
- **[A] lang_minsk_city（ミンスク市、1850–1914）**：`main: russian, minor: yiddish`。しかし note には「1897年の調査でユダヤ人約51%、ロシア語話者約25%」とあり、データが自分の note と矛盾している → `main: yiddish, minor: russian`（ポーランド語・ベラルーシ語は note に書く）。確信度：高。
- **[A] lang_chisinau（キシナウ市、1648–1914）**：1914年まで `main: romanian`。note にも「1897年の調査でユダヤ人約46%、ロシア人・モルドヴァ人がそれぞれ約2割」とある → 1850年（または1880年）から `main: yiddish, minor: russian`。確信度：高。

### B：不正確・改善すべき
- **[B] 東欧の「ユダヤ人が最大の集団」の都市の方針**：上の2都市のほかにも、ヴィリニュス（lang_vilnius_city。note で1897年にイディッシュ語約40%・ポーランド語約31%）、カウナス（lang_kaunas_city。ユダヤ人約36%）、ダウガフピルス（lang_daugavpils。ユダヤ人4割以上なのに main: russian）、ビャウィストク（lang_pl_jewish_cities の一部。1897年にユダヤ人約6割）では、19世紀後半の最大の言語はイディッシュ語。いまは note に数字を書きながら main は別の言語にしている所が多い。「都市のピースでは最大の言語を main にする」と方針を決めて、そろえるとよい。確信度：高（数字）、方針は田村さんの判断。
- **[B] lang_budapest（1850年）**：1850年に main をハンガリー語に切り替えている。1851年のペストではドイツ語話者がまだ過半数で、ハンガリー語が多数になるのは1870年代（1880年の調査で約57%）→ 切り替えを1870年（または1873年の合併）にする。確信度：中〜高。
- **[B] lang_riga（1880年）**：1880年にラトヴィア語を main にしている。1881年の調査ではドイツ人約40%・ラトヴィア人約29%・ロシア人約20%で、ラトヴィア人が最大になるのは1890年代（1897年に約42%）→ 切り替えを1890年にする。なお note の「1897年に約45%・ドイツ人約23%」は、一般に引かれる値（約42%・約25%）と少し違う。確信度：中〜高。
- **[B] lang_algiers_city（アルジェ・アンナバ、1870年以後）**：1914年まで main はアラビア語。note にもあるように、アルジェ市では19世紀末にヨーロッパ系の住民が多数（1880年代で約3分の2）→ アルジェ市は 1880年ごろから `main: french, minor: arabic`（スペイン語・イタリア語・マルタ語は note に書く）。lang_oran（オラン）も 1850年以後は市内でスペイン系・フランス系が多数なので、ピースがオラン市だけを指すなら同じように切り替える。確信度：中（ピースの範囲が市域か県全体かで変わる）。
- **[B] lang_dobruja_constanta・lang_dobruja_tulcea（1880年）**：1880年にルーマニア語を main にしている。note 自身が「1880年代はまだムスリムが多い」と書いている。南部（コンスタンツァ）でルーマニア人が多数になるのは1890年代後半 → コンスタンツァは1900年、トゥルチャは1890年ごろに切り替える。確信度：中。
- **[B] lang_kars（カルス、1878年以後）**：ベルリン条約でロシア領になったあと、ムスリムの一部が移住し、アルメニア人・ロシア人・ギリシア人などが入った（note にも書いてある）。それなのに 1914年まで `turkish/armenian` のまま → 1880年から少なくとも minor を見直す（1897年のカルス州では、アルメニア人とトルコ人がほぼ拮抗）。確信度：中。
- **[B] lang_galicia（スペインのガリシア、1648–1914）**：ガリシア語を portuguese（ポルトガル語）の色で塗っている。凡例に「ポルトガル語」と出るので、見る人はガリシアでポルトガル語が話されていると誤解する → `galician`（ガリシア語、ロマンス系）を _kinds.yaml に足すか、ポルトガル語の name を「ポルトガル語・ガリシア語」にする。確信度：高（表記の問題）。
- **[B] lang_vojvodina_base（1700年）**：1700年から minor: german。しかし、ドイツ人（ドナウ・シュヴァーベン人）の入植は1720年代以後で、バナトは1718年までオスマン領だった（note にも「18世紀後半の入植」とある）→ 切り替えを1720年（または1750年）にする。確信度：高。
- **[B] lang_belarus（1800年と1880年）**：1800年の項目の note に「1863年の1月蜂起の後、ロシア化政策が強まり」とあり、1800年の地図に1863年以後の説明が出る。さらに1880年に minor: russian をなくしていて、ロシア化が進むはずの時期に逆の動きになる → 1800年の項目は「ロシア領になった」だけにし、ロシア化は1863年以後の項目に書く。1880年の minor をなくす理由も note に書くか、minor を残す。確信度：中。
- **[B] lang_circassia（1864年）**：1864年以後の main を russian にしている。クバン州の入植者は黒海コサック（ウクライナ語）が多く、1897年のクバン州ではウクライナ語約47%・ロシア語約42%。クバン川左岸の西部はウクライナ語、東部はロシア語が多い → 少なくとも minor を ukrainian にする（lang_kuban は ukrainian/russian で、隣どうしで食い違っている）。確信度：中。
- **[B] スラヴ系の色の区別**：ポーランド語・ロシア語・ウクライナ語・ベラルーシ語が近い緑で、1900年の画面では境界がほとんど見分けられない。語族ごとの色相の方針は守りつつ、明るさの差を大きくする（例：ロシア語を濃く、ベラルーシ語を明るく）とよい。確信度：高（見た目の問題）。

### C：細部・要確認
- [C] lang_brussels（1900年にフランス語を main）：1910年の調査でもオランダ語だけを話す人や二言語話者は多く、1900年に「フランス語が多数」と言えるかは集計方法による。要確認（note に「要確認」とあるとおり）。
- [C] lang_prague（1880年に minor: german をなくす）：1880年ごろのプラハのドイツ語話者は1〜2割。消すのは少し早い。
- [C] lang_macedonia_gr_south（1913年に minor: turkish をなくす）：ムスリムの大部分が去るのは1923年の住民交換。バルカン戦争での避難を重く見るなら 1913年でもよいが、note で説明を。
- [C] lang_kosice（1880年にハンガリー語）：1880年の調査ではスロヴァキア語とハンガリー語がほぼ同数。1890年の方が無難。
- [C] アルーマニア語（lang_pindus_vlach・lang_krushevo）、ガガウズ語（lang_gagauzia）、フリウリ語（lang_friuli）を、それぞれルーマニア語・トルコ語・レト・ロマンス語の色で塗っている。語族の色としては妥当だが、凡例の名前と合わないので note で説明を。
- [C] 言語の凡例は開いた状態で、地図の左3分の1ほどを覆う（PC 1400×1000）。初めは閉じておくか、2列をやめて小さくするとよい。

### 問題がなかった観点
- ボヘミアの国境地帯（ズデーテン）、上シュレジエン・マズーリ・カシューブ、ハンガリーの言語境界（スロヴァキア南部・トランシルヴァニア・セーケイ）、ヴォイヴォディナのモザイク、ルーマニア・ブルガリアの少数派、アイルランド語・ゲール語・ウェールズ語の後退（1750・1850・1880・1890年の段階）は、一般的な民族分布図とよく合う。
- 18世紀の黒海北岸（ノガイ人→ウクライナ人・ロシア人）、ヴォルガ・ドイツ人（1764–）、ブジャクのブルガリア人・ガガウズ人（1812–）の入植の年は妥当。
- テッサロニキのラディーノ語、トビリシのアルメニア語（1800–）、フィンランドのスウェーデン語沿岸とヘルシンキの切り替え（1890）も妥当。

## 3. 都市（data/cities.yaml）

人口の桁と順位は、Chandler・Bairoch や各国の国勢調査の通説的な値とおおむね合っている（パリ・ロンドン・ウィーン・ベルリン・ペテルブルク・モスクワ・イスタンブル・ナポリの1650→1914の推移、マンチェスター・リヴァプール・グラスゴー・ウッチ・オデッサの急成長、セヴァストーポリの1856年の落ち込み、メッシーナの1908年の地震）。首都の期間も、ヴェルサイユ（1682–1789）、ペテルブルク（1712–、1728–31のモスクワ）、マンハイム（1720–77）、ルートヴィヒスブルク、ブカレスト（1659–）、クラグイェヴァツ→ベオグラード（1841）、ナフプリオ→アテネ、トリノ→フィレンツェ→ローマ、ヘトマン国家の首都の移動など、よく調べられている。

### B
- **[B] novocherkassk（ノヴォチェルカッスク）**：capital が `don_cossacks 1805–1815` で終わっている。政体 don_cossacks は1834年まで続き、ノヴォチェルカッスクは1917年までドン・コサック軍（州）の中心 → `to` を政体の終わり（1834）まで延ばす。1815年までの範囲で作ったときの名残と思われる。確信度：高。
- **[B] plovdiv（フィリベ）**：東ルメリ自治州（eastern_rumelia、1878–85）の首府なのに capital がない。また、1878年以後はブルガリア側の呼び名「プロヴディフ」が一般的 → `capital: [{polity: eastern_rumelia, from: 1879, to: 1885}]`（年は政体データに合わせる）、`names: [{from: 1878, name: プロヴディフ}]`。確信度：高。
- **[B] kaffa（カッファ）**：1914年まで「カッファ」のまま。ロシア併合後の1784年に「フェオドシヤ」と改名された → `names: [{from: 1784, name: フェオドシヤ}]`。確信度：高。

## 4. 潮流（data/movements/）

59件すべての曲線・広がり・説明文を読んだ。時期と広がりは全体に自然で、事実の誤りはほとんどない（ワッハーブ派の第1次・第2次サウード王国、ニザーム・ジェディード→タンジマート→ミドハト憲法→青年トルコ革命、奴隷貿易の国ごとの廃止年、農奴解放の国ごとの年、自由貿易から保護関税への転換（ドイツ1879・フランス1892）、女性参政権（フィンランド1906・ノルウェー1913）など）。1900年の `mv=nationalism` の画面でも、広がりは自然だった。

### B
- **[B] parliamentary_politics（議会政治）の全体の curve**：1815年に 1.0 になり、1914年まで 1.0 のまま。1815–1848年はウィーン体制（vienna_system、1815年に 1.0）と絶対王政が強い時代で、全体の「空気」として議会政治を最大にするのは言いすぎ → 1815年 0.6、1832年（第1回選挙法改正）0.7、1848年 0.8、1867年 0.9、1900年 1.0 くらいに。確信度：中。
- **[B] pan_slavism の説明文**：「1848年のプラハのスラヴ人会議に始まり」とあるが、スラヴ人の連帯の思想は1820〜30年代のコラール・シャファーリクらの文化的な運動から始まっている（spread もボヘミアを1830年から始めている）→「1830年代の文化運動に始まり、1848年のプラハのスラヴ人会議で政治運動になった」など。確信度：中。

### C
- [C] absolutism のスウェーデン：1772年のグスタフ3世のクーデタで王権が回復したのに、curve は 1772年 0.1 から 1789年 0.7 へゆっくり上がる。1772年の直後に 0.6 にするとよい。
- [C] baroque_catholicism の people（ルイ14世・レオポルト1世）は「対抗宗教改革」の代表として弱い。イエズス会の人物や作品（教会建築）を挙げるとよい。
- [C] 人物の分類が高校教科書とずれるもの：continental_rationalism のパスカル、british_empiricism のホッブズ、utopian_socialism のプルードン（教科書では無政府主義）、impressionism のロダン、free_trade のリスト（保護貿易論者。説明文で断っているので可）。
- [C] nationalism の広がりに、オスマン帝国下のマケドニア（内部マケドニア革命組織、1893–）・アルバニア（プリズレン連盟、1878）や、カタルーニャ・フランデレン、バルト・ウクライナの民族運動が入っていない。範囲を広げるなら候補。
