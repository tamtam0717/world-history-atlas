# 独立レビュー：宗教・言語（民族）の分布、都市、潮流、全体の出来事（1914–2025）

レビュー担当：作成に関わっていないエージェント（2026-11-21）
対象：
- 宗教 data/religion/*.yaml（docs/religion-format.md）
- 言語 data/language/*.yaml（docs/language-format.md）
- 都市 data/cities.yaml
- 潮流 data/movements/*.yaml（docs/movements-format.md）
- 全体の出来事 data/events/europe.yaml（1914年以後の100件）

方法：
- `npm run data` で atlas.json を作った（宗教 253 地域、言語 452 地域、潮流 85 件）。1914年より後の項目がある地域を一覧にして読んだ（宗教 約90地域、言語 約200地域）。
- ピースごとに「その年の宗教／言語」を引く小さなスクリプトで、同じピースの宗教と言語の変化年・多数派を突き合わせた（例：コソヴォ北部、アルメニア、イスラエルの各地区、ヴォイヴォディナ北部、北マケドニア西部、エストニア・ラトヴィアの都市、レバノンの県）。
- 画面は tools/snapshot.mjs と同じ手順で `?range=476-2030` を開き、ハッシュに `l=religion` / `l=language` を付けて PNG を書き出して見た（1914, 1920, 1925, 1939, 1945, 1950, 1990, 2000, 2025。中東欧を中心に拡大）。tools/snapshot.mjs には表示（l）を指定するオプションがないので、同じ内容のコピーを .cache/ に置いて使った（tools/ は変更していない）。
- データ・コードは変更していない。

重要度：A＝地図や事実が明らかに誤り、B＝不正確・改善すべき、C＝好みや細部。

## 1. 宗教の分布（data/religion/）

### A：明らかな誤り
- **[A-1] rel_kosovo のうち北部4自治体（レポサヴィチ・ズヴェチャン・ズビン・ポトク・北ミトロヴィツァ）、1970–2025**：1970年から `main: sunni`（少数派なし）。しかし言語データ（lang_kosovo_serb）では、同じピースが1914–2025年ずっと「セルボ・クロアチア語が多数、アルバニア語が少数」。宗教と言語が真っ向から矛盾している。北部はイバル川の北のセルビア人地域で、1999年以後も住民の約9割がセルビア人（正教徒） → 北部4自治体を rel_kosovo から分け、`main: orthodox, minor: sunni`（2000年ごろから minor なしでもよい）。lang_kosovo_serb と同じ select を使うとよい。確信度：高。
- **[A-2] rel_mount_lebanon_druze（LBN-Mont_Liban の全体）、1648–2025、特に 1984 年以後**：地域名は「レバノン山地南部（シューフ・メトン）」だが、ピースは今のレバノン山地県の全体（メトン・バアブダ・アレイ・シューフ）。1984年から `main: other`（ドゥルーズ派）で少数派なしなので、2025年の地図では県全体がドゥルーズ派だけになる。実際には、メトン（マロン派・正教徒）とバアブダ（キリスト教徒とシーア派）はキリスト教徒が多く、ドゥルーズ派が多いのはシューフ・アレイの一部だけ。県全体でもドゥルーズ派は少数派。1983–84年の「山岳戦争」でキリスト教徒が去ったのはシューフ・アレイの村 → 県全体は `main: catholic`（マロン派）、`minor: other`（ドゥルーズ派）にするか、ピースを分けられないなら少なくとも 1984 年の `minor: catholic` の削除をやめる。地域名も「レバノン山地」に直す。確信度：高（県全体の比率は中）。
- **[A-3] ナゴルノ・カラバフ（rel_azerbaijan・lang_azerbaijan、1923–2023）**：アゼルバイジャンのピースは「AZE-Contiguous_Azerbaijan」と「ナヒチェヴァン」の2つしかない。このため、ナゴルノ・カラバフ自治州（1923–91。1989年でアルメニア人約77%）と、1994–2023年のアルメニア人勢力の支配地域が、宗教でも言語でもどの年も「シーア派／アゼルバイジャン語」で塗られる。note には 2023 年の住民の流出まで書かれているのに、地図に一度も現れない → tools/pieces_config.json でアゼルバイジャンを admin-2（ラヨン）に分け、旧自治州の範囲を `main: oriental` / `armenian`（1923–2023）、2023年に `main: shia` / `azerbaijani` に切り替える（2023年9月のアゼルバイジャン軍の攻勢で、約10万人のアルメニア人のほぼ全員がアルメニアへ去った）。ピースの追加が必要なので、作業としては国境担当と合わせて扱う。確信度：高。

### B：不正確・改善すべき
- **[B] rel_galicia_east（1946–1989）とソ連期の「伝統的な帰属」の方針の食い違い**：ロシア・ウクライナ・ベラルーシ・バルト・チェコ・東ドイツ・アルバニアでは「地図は伝統的な帰属」として無神論政策や世俗化を塗りに反映していない。ところが東ガリツィアだけは、1946年の強制合同（リヴィウ教会会議）で `main: orthodox` に変え、1990年にカトリックへ戻している。信徒の多くは地下教会として信仰を保っており、1989年に一斉に戻ったことがその証拠 → 方針に合わせるなら 1946–89 も `main: catholic, minor: orthodox` のままにして、強制合同は note に書く。ザカルパッチャ（1949）とトランシルヴァニア（1948）は、合同後も正教会にとどまった人が多いので、今のままでよい。確信度：中（方針の判断）。
- **[B] rel_erivan（アルメニア中部）・rel_armenian_highland_villages（シラク・ロリ・タヴシュ・シュニク）、1920–1990**：宗教は 1990 年まで `minor: shia` を残すが、言語（lang_armenia）は 1950 年にアゼルバイジャン語の少数派をなくしている（シラクのピースは言語が lang_armenia、宗教が rel_armenian_highland_villages で、年がずれる）。ソヴィエト・アルメニアのアゼルバイジャン人は 1926年で約9%、1959年で約6%、1989年で約2.5% と、全体ではずっと2〜3割を下回る → 宗教と言語の切り替え年をそろえる。少なくともエレバン・コタイク・アラガツォトンなどは 1950 年（または1920年）に `minor` をなくす。アゼルバイジャン人の村が多かったアララト・ヴァヨツ・ゾル・シュニクの一部だけ 1988–90 年まで残すのは可。確信度：中。
  - 逆に **[B] ナヒチェヴァン**：宗教（rel_nakhchivan）は 1930 年にアルメニア使徒教会の少数派をなくすが、言語は lang_azerbaijan（本土と共通）のまま 1990 年までアルメニア語の少数派が残る。ナヒチェヴァンのアルメニア人は 1926年で約11%、1979年で約1.4% → 言語もナヒチェヴァンだけ分けて、1930 年ごろに `minor` をなくす。確信度：高。
- **[B] ヴォイヴォディナ北部（スボティツァ・センタ・カニジャ・アダ・バチュカ・トポラなど）、1914–2025**：言語は lang_vojvodina_hungarian / lang_subotica で「ハンガリー語が多数」なのに、宗教は rel_vojvodina で「正教会が多数、カトリックが少数」。ハンガリー人とブニェヴツィ（スボティツァ）はカトリックなので、言語と矛盾する → 言語と同じ select で `main: catholic, minor: orthodox` の地域を作る。確信度：高（1914年より前からある食い違い）。

## 2. 言語（民族）の分布（data/language/）

### A：明らかな誤り
- **[A-4] lang_lublin（ルブリン市）、1920–1941**：1850 年から 1942 年まで `main: yiddish, minor: polish`。しかし戦間期のルブリンではポーランド人が多数で、1931 年の調査でユダヤ人は約3分の1（約3万9千人／約11万2千人）。ビャウィストク（1920年に polish/yiddish へ切り替え済み）と同じく、1920 年に `main: polish, minor: yiddish` にする。確信度：高。

### B：不正確・改善すべき
- **[B] イスラエルのエルサレム地区（lang_jerusalem）、1948–1966**：1948 年から `hebrew / arabic`。しかし 1948–67 年のイスラエル側（西エルサレムと回廊）ではアラブ人はアブー・ゴーシュなど数村だけで、宗教（rel_israel_jerusalem）も 1948–66 は少数派なし → 1948 年は `hebrew` のみ、1967 年から `minor: arabic`（宗教と同じ）。確信度：高。
- （ナヒチェヴァンの言語は宗教の項の B を参照。件数は宗教側に数えた）
- **[B] 「言語」か「民族」かの基準が地域で違う（方針の相談）**：ミンスク市は 1960 年から「ロシア語が多数（住民の多数はベラルーシ人）」と**使う言語**で判断しているが、ドンバス（lang_donbas）とハルキウ（lang_sloboda_ua）は「ウクライナ語が多数、ロシア語が少数」と**民族**で判断している（note 自身が「ロシア語を母語とする人が約75%」と書いている）。ベラルーシ全体（lang_belarus）も、2009年の調査では家庭でロシア語を話す人が約7割なのに `belarusian / russian` のまま → どちらかにそろえる。docs/language-format.md の基準「住民（特に農村の民衆）の多数派の言語」に従うなら、ドンバスの工業都市・ハルキウ市・オデーサ市は 1960 年ごろから `russian / ukrainian`、ベラルーシの都市部（ミンスク以外の州都）も同様。民族の分布として描くなら、ミンスクを `belarusian / russian` に戻す。「言語（民族）」という表示名の意味に関わるので、田村さんに確認したい。確信度：—（方針の相談）。
