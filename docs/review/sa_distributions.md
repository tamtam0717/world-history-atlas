# 独立レビュー：南アジア・東南アジアの宗教・言語（民族）の分布、都市、潮流（1648–2025）

対象：data/religion/south_asia.yaml・southeast_asia.yaml・secular.yaml（東南アジアの節）・_kinds.yaml、data/language/south_asia.yaml・southeast_asia.yaml・_kinds.yaml、data/cities.yaml（「南アジア・東南アジア」の節）、data/movements/south_asia.yaml、system.yaml・thought.yaml の S6 追加分（あわせて、ヨーロッパの潮流が南・東南アジアの植民地でどう光るか）。

方法：
- YAML を通読した。`npm run data` を実行し、警告がないことを確かめた。`--religion-missing 1650,1900,2025`（南・東南アジアの国に限定）の結果は 0 件。
- 地図の書き出し：`.cache/snapshots/review_sa_dist/`
  - `rel/`・`lang/`：`--zoom 95,15,1.8`（1650, 1750, 1850, 1900, 1946, 1948, 1975, 2025）
  - `rel_in/`・`lang_in/`：インドを中心に `--zoom 79,24,2.3`
  - `rel_id/`・`lang_id/`：島嶼部を中心に `--zoom 115,3,1.7`
- atlas.json から、ピースごとの宗教・言語を年ごとに取り出して照合した（例：パンジャーブの郡ごとの 1940 年の値）。
- 潮流は、atlas.json の spread を年ごとに計算し、植民地（britain・netherlands・france・spain・portugal・usa が owner のピース）で光る潮流を一覧にした。

重要度：A＝地図や事実が明らかに誤り、B＝不正確・改善すべき、C＝好みや細部。

## A（明らかな誤り）

- **[A] ヨーロッパの潮流が、南・東南アジアの植民地全体で本国と同じ強さに光る**（system.yaml・thought.yaml・religion.yaml・art.yaml の、`polities: [britain]`・`[france]`・`[netherlands]`・`[spain, portugal]` などで書いた spread。1765–1960 年ごろ）
  - 地図の spread は `ownerOf`（ピースの owner）で判定している（src/map.ts の renderMovement）。英領インド・ビルマ・マラヤは `britain`、オランダ領東インドは `netherlands`、インドシナは `france`、フィリピンは 1898 年まで `spain` が owner になっている（1900 年の時点で、インド 702・パキスタン 125・バングラデシュ 64・ビルマ 74・マレーシア 65 ピースが britain、インドネシア 421 ピースが netherlands、ベトナム・ラオス・カンボジア 118 ピースが france）。
  - このため、たとえば 1900 年には次の潮流が、英領インド全域とビルマ・マラヤで「イギリスと同じ強さ」に光る：議会政治（britain 1.0）、自由主義（0.9）、労働運動（1.0）、女性参政権運動（0.7）、メソジスト（0.3）、功利主義（0.5）、実証主義と進化論（0.9）。インドシナでは、アール・ヌーヴォー（france 1.0）、アナーキズム（0.9）、印象派（0.8）。1800–1850 年の産業革命（britain 0.9–1.0）は、むしろ綿織物業が衰えた時期のインドで最大の強さで光る。1942 年のケインズ主義・福祉国家（britain 0.6）、1950 年の実存主義（france 0.9）も同じ。
  - S6 担当の新しい潮流（south_asia.yaml）は、冒頭の注のとおり植民地時代を地域の一覧で書いていて、本国までは光らない。問題はその逆向き（本国の潮流が植民地へ漏れる）で、東アジアのレビュー（ea_distributions.md の「日本の潮流が植民地でも光る」）と同じ種類だが、範囲はずっと広い。
  - → 本国だけの政治の地域（または「本国の地域」の一覧）で書き直すか、画面側で「宗主国の潮流は、宗主国が owner のピースのうち本国の範囲だけを光らせる」ような除外のしくみ（例：spread に `home_only: true`、または `exclude_regions`）を足す。帝国主義・脱植民地化・総力戦・冷戦は、植民地が光ってよい（東アジアの修正と同じ方針）。
  - 確信度：高（地図の見た目の問題。計算で確かめた）。

A は上の1件のみ。分布のデータそのものに、教科書と食い違う明らかな誤りは見つからなかった。

## C（細部・好み）
