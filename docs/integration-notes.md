# 担当間の整合チェック用メモ（1648–1815 試作）

各データ担当の報告から、担当の境界で確認が必要な点を集める。全担当の完了後にまとめて確認する。

- BS：ジーゲン・ドルトムントに `nassau_orange` を使用。ヴェストファーレン公領 1803–1814 hesse_darmstadt。アイヒスフェルト・エアフルト 1802 まで mainz。ライン同盟の overlord は 1813 年の地図から外した → BS の終わりの年と合わせる

- 表せないもの：ヴィスマール（郡がメクレンブルク扱い）、グライフスヴァルト・ヴォルガスト（1720 からプロイセン色になる）、多くの帝国都市

## BS（南ドイツ）から
- 1815 年のライン左岸中部（プファルツ・ラインヘッセン）は habsburg uncertain（オーストリア・バイエルン共同管理）。1816 年にバイエルン・ヘッセンへ。違和感があれば 1815 から先取りする案も
- ザールブリュッケン・ザールルイは 1815 までフランス、ランダウ 1680–1815 フランス。ザールルイの 1648–1680 はロレーヌと同じ年で切り替え（A と整合）。ハーナウ＝リヒテンベルク 1736 ヘッセン＝ダルムシュタット
- ビットブルク：1684 仏占領、1697 スペイン、1714 オーストリア、1795 占領、1797 フランス → C のルクセンブルク本体と整合
- BN：ヘッセン＝カッセル本領 1807 westphalia_kingdom、ディレンブルク 1806 berg。飛び地（シュマルカルデン・リンテルン、エアフルト・アイヒスフェルト）
- D：パッサウ・アイヒシュテット・ベルヒテスガーデン 1803–1805 salzburg、ベルヒテスガーデン 1805 オーストリア・1810 バイエルン
- ツヴァイブリュッケン 1697–1718 owner sweden
- 色：bavaria と france が近い。hesse_darmstadt・frankfurt_gd・聖界領の紫系どうしが近い
- 地域ファイルは tools/gen_regions_germany_south.py（作業用スクリプト）で生成したもの

## 整合の結果

各項目の確認結果。「年末時点の状態」「正式な割譲の年で切り替える」という決まりに従い、判断が分かれるものは高校世界史の地図での見え方に合わせた。担当の境界で隣り合うピースの所属を全年で比べるスクリプト（ピースの隣接は pieces.topo.json の共有辺から求めた）で、一覧にない食い違いも探した。

### 一覧の項目

- **トランシルヴァニア 1687–1698（D・E）**：D の案に統一。`ottoman.yaml` の `transylvania_ro` から 1687 年の項目（overlord habsburg・uncertain）を削除した。1698 年まで「トランシルヴァニア公国＋オスマンの宗主権」、1699 年（カルロヴィッツ条約）からハプスブルク領。ブラージュ条約・レオポルト勅書は地域の note に書いた。
- **パルティウム・ビホル（D・E）**：E の `bihor` にあった 1692 年の「habsburg・occupied」を削除し、ハンガリー側（D の `bihar_hajdu`・`ottoman_hungary_hu`）と同じく 1699 年で切り替えるようにした。
- **サトゥ・マーレ（D・E）**：E の `satu_mare` は 1649 年にハプスブルクへ返還としていたが、D の `szabolcs_szatmar` は 1660 年（ラーコーツィ・ジェルジ2世の死）としていた。D に合わせて 1660 年（uncertain）に直し、さらに D と同じく 1682–1684 年をテケリ（thokoly、overlord ottoman、uncertain）にした。
- **ラグーザの overlord（D・E）**：E の政体の扱い（オスマン帝国に貢納）とワラキア・モルダヴィアの例に合わせ、`habsburg.yaml` の `ragusa_hr` 1648 年に `overlord: ottoman` を付けた。オーストリア領になる年は 1815 → 1814 に直した（ダルマツィア・コトル湾の 1814 年と合わせる。1814 年1月にオーストリア軍が占領、パリ条約）。ラグーザ廃止のイベントは D の1件だけで、重複はなかった。
- **ゴリツィア・トリエステ・トレント（C・D）**：年はすでに一致していた。C の `gorizia_trieste` の 1809 年（イリリア州）に `overlord: france` が抜けていたので付けた（D のスロベニア側・ケルンテンと同じ）。トレント 1810 年イタリア王国、南チロル（ボルツァーノのピース）はバイエルンのまま、東チロル 1810 年イリリアという分かれ方は史実どおりなので残した。
- **ピエモンテとサヴォワ（A・C）**：食い違いなし。サヴォワ 1792・ニース 1793 年併合、ピエモンテ 1798 年占領・1802 年併合、1814 年返還（シャンベリ・アヌシーは 1815 年）は、それぞれ史実の年で、境界の段差は実際の違い。直していない。
- **ルクセンブルクとビットブルク（BS・C）**：
  - 1684–1696 年：C の `luxembourg` は france（確か）、BS の `bitburg` は france（占領）で食い違っていた。レユニオン期の獲得地は、ザール地方（BS）と同じく「france・occupied・overlord hre」に統一した（ライスワイク条約で返還されたため、帝国の外枠も残す）。
  - 1795 年：C は france（確か）、BS は 1795 年占領・1797 年確定だった。C（森林県への併合、1795）に合わせ、`bitburg` の 1797 年の項目を削除し、1795 年から確かな france にした。
  - 1814 年：BS の `bitburg` ほかライン左岸の「prussia・uncertain」を、C・BN と同じ「prussia・occupied」にした（下記）。
- **ライン左岸のフランス化の年（A・BN・BS・C）**：BN は「1794 年占領（overlord hre を残す）→1801 年確定」、BS は「1797 年占領（overlord なし）→1801 年確定」で、ケルン領ボンとアールヴァイラーなどの間に 3 年の段差があった。BN の方式に統一し、`germany_south.yaml` の 12 地域（トリーア、ザールブリュッケン、ツヴァイブリュッケン、メルツィヒ、ビルケンフェルト、プファルツ左岸、フンスリュック、アルツァイ、ヴォルムス、シュパイアー、ピルマゼンス、アールヴァイラー）の 1797 年の項目を 1794 年（france・occupied・overlord hre）に移した。マインツ市（`mainz_left`）は 1797 年 12 月の開城まで要塞が持ちこたえたので、1797 年のままにした。C 側のプロイセン領（`gennep`、`upper_guelders_prussian`）もクレーヴェと同じ「1794 年占領→1801 年確定」にした。オーストリア領ネーデルラント・リエージュ・オランダ領リンブルフなど（C）の 1795 年併合はそのまま（ムーズ＝アンフェリウール県などへの併合は 1795 年で、1801 年まで待ったドイツ側と実際に違う）。
- **1814 年のライン左岸**：BS の「中部ライン総督府」の 6 地域を uncertain → occupied にし、BN・C（連合国の暫定統治＝占領）と同じ表示にした。
- **スウェーデン領ポンメルン（BN・F）**：食い違いなし（1648、1679 年のオーダー右岸の一部、1720 年ペーネ川以南とシュテッティン、1806 年 overlord なし、1815 年プロイセン）。
- **ホティンとモルドバ北部（E・F）**：直していない。ホティン（UKR、F）は 1713 年からオスマン直轄、ブリチェニなどモルドバ北部（E）は 1812 年までモルダヴィア。ホティンのラヤの範囲が現モルドバ北部にどこまで及んだかははっきりしないが、どちらもオスマンの枠の中なので地図の見え方への影響は小さい。1812 年のロシア併合は両方そろっている。イェディサン・トランスニストリア（1792）、ブジャク（1812）もそろっている。
- **ザカルパッチャとスロバキア東部（D・F）**：F の `zakarpattia` に 1682–1684 年のテケリ（thokoly、overlord ottoman、uncertain）を追加し、D の上部ハンガリー東部・ボルショドなどとつなげた（ムカチェヴォ城がテケリの拠点）。ラーコーツィ家の所領（〜1711）は私領なので、ハプスブルク領のまま。
- **スピシュの質入れ都市（D・F）**：1772 年でそろっている。
- **ライン同盟の overlord が外れる年（BN・BS）**：全担当で 1813 年の地図から外れている（1812 年まで rhine_confederation、1813・1814 年はなし）。食い違いなし。
- **インフィアテル（D・BS）**：BS はバイエルン本領を 1704–1713 年「habsburg・occupied」（スペイン継承戦争の占領）としていたが、D の `innviertel` はバイエルンのままだった。D 側に同じ項目を追加した。1779・1810・1813・1815 年の扱いは一致していた。
- **ユーリヒ公国の飛び地（BN・C）**：C の `julich_nl`（シッタルト・スステレン）が 1648 年から palatinate、1777 年以降も palatinate だった。BN の `julich_left` に合わせ、1648 palatinate_neuburg → 1685 palatinate → 1777 bavaria にした。
- **ベルヒテスガーデン・パッサウ・アイヒシュテット・ザルツブルク（BS・D）**：1803 年 salzburg、1805 年、1810 年でそろっている。
- **1815 年のドイツ連邦の枠**：BS の左岸プファルツ・ラインヘッセン（オーストリア・バイエルン共同管理、1816 年に分配）が 1815 年に枠の外になり、連邦の外枠に穴があいていた。7 地域に 1815 年の項目（habsburg・overlord german_confederation・uncertain）を加えた。ランダウ（1815）とイーゼンブルク（1815、陪臣化）にも german_confederation を付けた。
- **ザールルイ・ザール地方とロレーヌ（A・BS）**：ロレーヌ公国（A）は 1670–1696 年のフランス占領中も overlord hre を残しているのに、隣のザールブリュッケン・ツヴァイブリュッケン・ザールルイ（BS）は 1680 年から枠なしだったため、ロレーヌが帝国の枠の飛び地になっていた。BS のレユニオン 4 地域の 1680 年の項目に overlord hre を付け、ザールルイは 1697 年（ライスワイク条約でフランスに割譲）から枠なしのフランス領とした。
- **コトル湾**：E と D で一致（1813 年はモンテネグロの占領）。
- **ボスニア北辺（ポサヴィナ）1718–1739**：HRV 側スラヴォニアと一致。
- **ジョージア諸国と北カフカース（E・F）**：大きな食い違いなし。ダゲスタン（F）は 1813 年（グリスタン条約）までペルシア（名目）、アゼルバイジャンの諸ハン国（E）は 1805 年からロシアで、1805–1812 年に段差がある。ハン国ごとの服属条約（1805 年のクレクチャイ条約など）を根拠にした E の判断を残した。
- **A のその他**：コルシカ 1768、アヴィニョン 1791、モナコ、モンベリアール（1793 年まで wurttemberg）、アイスランド、北アフリカの overlord ottoman は、ほかの担当と矛盾なし。
- **DZA-Tamanghasset の名前**：ピースの名前付け（tools/build_pieces）の問題で、データ側は A が位置から正しくオランとして扱っている。tools/ は変更していない。
- **北シュレースヴィヒ（BN・F）**：DNK 側は denmark のみ、DEU 側はゴットルプ家領が 1713 年まで holstein_gottorp。ゴットルプ家の持ち分は散在していてピースで表せないため、そのまま。
- **色**：変更していない。

  - 1778「バイエルン継承戦争」（BS）と 1779「テシェン条約」（D）は、開戦と講和で別の出来事として残した。
- **残した段差**（境界の調査で見つかったが、史実どおりのもの）：ダンケルク（1658–1662 イングランド領）、ティオンヴィル（1659 フランス）とルクセンブルク、マコー・セゲド（1699）とバナト（1718）、ブジャクとイェディサン（1792–1811）、ヴェネツィア本土（帝国外）とオーストリア諸邦（帝国内）、サヴォワ（帝国内）とピエモンテ（このプロジェクトでは帝国外）、オーストリア領シュレジエンと上部ハンガリー、旧ヴェネツィア領イストリアの 1815 年（ドイツ連邦の外）、1794 年のドイツ側の左岸（占領）とオランダ領リンブルフ（1795 年に併合）。
