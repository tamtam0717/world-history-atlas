# 範囲の拡大（1648→1453）：ヨーロッパ・中東のデータ作成担当への共通の指示

全世界の 1648–2025 がそろった（レビュー済み）。次は **1453 年（コンスタンティノープル陥落・百年戦争の終わり）までさかのぼる**。最終目標の 476 年に向けた最初の段階で、まずヨーロッパ・中東から（アジア・アメリカ・アフリカ・オセアニアは次の段階）。
担当範囲（現代の国コード）と担当ファイルはこれまでと同じ（docs/polity-ids.md の表：A・BN・BS・C・D・E・F）。**既存のファイルに追記する**（地域の timeline の先頭に 1453 年からの項目を足し、必要な地域・政体・出来事を足す）。

## 最初に読むもの
1. CLAUDE.md（「画面づくりの原則」「進捗」）
2. docs/data-format.md、docs/agent-brief.md（手順・検証・してはいけないこと。すべてそのまま当てはまる）
3. docs/polity-ids.md（下の「1453–1647 の主な政体 ID」も）
4. 自分の担当の既存ファイル（data/polities・regions・events の担当分）。今の地域は 1648 年の形で分けてあるので、1453–1647 に形が違う所は、地域を分ける（小さい地域が優先される決まりを使って、1648 年より前だけ別の所属にする）か、既存の地域の timeline に 1648 年より前の項目を足す。**1648 年以降の所属を変えないこと**（atlas.json の 1648–2025 の所属が変わっていないことを、作業の前後で比べて確かめる）。

## 作るもの
- 担当範囲のすべてのピースに 1453–1647 の所属を与える。確認：`node tools/build_data.mjs --missing 1453,1480,1500,1520,1530,1550,1570,1590,1610,1620,1635,1647 --iso <担当の国コード>`（ゼロにする）。
- 画面の表示範囲（data/meta.yaml）はまとめ役が全担当の完了後に 1453 へ広げる。snapshot.mjs は範囲外の年も表示できる。
- 主な国境の変化を年末時点の決まりで入れる。自分が定義する主な政体の 1453–1647 の**君主を全員**（在位年・出典つき）、情勢（periods）を2〜6件。担当地域の出来事を 30〜60 件。

## 描き方の方針（これまでと同じ考え方）
- 「Y 年の年末の状態」。
- 神聖ローマ帝国（hre）：1453 年から overlord の枠。領邦は主要なもの 20〜30 に絞り、残りは other_hre。ボヘミア王冠領（ボヘミア・モラヴィア・シュレジエン・ラウジッツ）は帝国の一部として描く。
- **同君連合**（カスティリャとアラゴン 1479–、ポーランドとリトアニア 1386–1569、カルマル連合 –1523、スペインとポルトガル 1580–1640、ハプスブルク家の諸領など）：それぞれの国の色を残し、note に書く。統合した年（1516 年のスペイン王国の成立をどう扱うか、1569 年のルブリン合同）から1つの政体にしてよい。判断は note に書き、担当どうしでそろえる。
- 長く続いた占領・戦乱の支配は描く（三十年戦争のスウェーデン軍・帝国軍の何年も続いた占領、八十年戦争の前線、イタリア戦争の主な占領、ハンガリーの三分割など）。短い遠征は描かない。
- 名目的な支配・あいまいな境（ハンガリー南部の辺境、ロシア南部の草原、クリミア＝ハン国の宗主権、ドナウ二公国のオスマンへの貢納など）は certainty: nominal / uncertain、overlord と note で。
- 表記は日本の高校世界史の教科書に合わせる（メフメト2世、スレイマン1世、カール5世、フェリペ2世、エリザベス1世、イヴァン4世、ルター、カルヴァン、ユグノー戦争、オランダ独立戦争 など）。

## 担当ごとの主な変化（例。これに限らない）
- **A**：百年戦争の終わり（1453、カレーは 1558 年まで）、ブルゴーニュの解体（1477）、レコンキスタの完了（1492）、ナバラ併合（1512）、イタリア戦争、ユグノー戦争、ブルターニュ併合、スコットランドとの同君連合（1603）、アイルランドの征服（テューダー朝）、北アフリカ（スペインの拠点、オスマン帝国のアルジェ・チュニス・トリポリ、モロッコ）。
- **BN・BS**：神聖ローマ帝国の諸邦、宗教改革（シュマルカルデン戦争、アウクスブルクの和議）、ドイツ農民戦争、三十年戦争（スウェーデン軍の占領 1631–48 など）、ドイツ騎士団国家のプロイセン公国化（1525）。
- **C**：イタリアの諸国とイタリア戦争（ミラノ・ナポリの帰属の変化、1559 カトー＝カンブレジ条約）、スイスの独立（1499／1648）、ブルゴーニュ領ネーデルラント → ハプスブルク → オランダ独立戦争（1568–、1581 独立宣言、前線の変化）。
- **D**：ハンガリー（マーチャーシュ1世のボヘミア・オーストリアへの進出 1469–90、モハーチの戦い 1526 と三分割、1541 ブダ陥落）、ボヘミア（1526 ハプスブルク、1618 反乱・1620 白山の戦い）、第一次ウィーン包囲（1529）。
- **E**：オスマン帝国の拡大（バルカン、アナトリアの諸侯国、1514 チャルディラン、1516–17 マムルーク朝の征服、1534 バグダード、1571 キプロス、1639 カスレ・シーリーン条約）、サファヴィー朝の成立（1501）、黒海・コーカサス。
- **F**：モスクワ大公国の統一（ノヴゴロド 1478、トヴェリ 1485、プスコフ 1510、リャザン 1521）、カザン・アストラハン併合（1552・56）、シベリア進出の始まり、リヴォニア戦争（1558–83）、ポーランド＝リトアニア（ルブリン合同 1569）、動乱時代（1598–1613、ポーランドのモスクワ占領）、スウェーデンの独立（1523）とバルト進出、カルマル連合。
