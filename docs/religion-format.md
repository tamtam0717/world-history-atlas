# 宗教の分布データの形式

田村さんと決めた方針（2026-11-20）：
- 宗教から作る（言語・民族は後で同じ仕組みで作る）
- 分け方は教科書程度（下の表）
- 描き方は「多数派の色で塗り、混在している地域は2色目の斜線を重ねる」

## 宗教の種類（data/religion/_kinds.yaml）

| id | 名前 | 色の系統 |
|---|---|---|
| catholic | カトリック | 黄 |
| lutheran | ルター派 | 青 |
| reformed | カルヴァン派（改革派） | 紫 |
| anglican | イギリス国教会 | 赤 |
| orthodox | 正教会 | 茶 |
| oriental | 東方諸教会（アルメニア使徒教会・コプト教会など） | 橙 |
| sunni | イスラーム（スンナ派） | 緑 |
| shia | イスラーム（シーア派） | 濃い緑 |
| other | その他（シャーマニズムなど） | 灰 |

- 東方典礼カトリック（ユニエイト）はカトリックに含め、note に書く。
- ユダヤ教（jewish）は原則として塗りには使わない（都市や地域の note に書く）。例外として、1948 年以後のイスラエルのように多数派になる地域では塗る。

## 地域ごとの変遷（data/religion/*.yaml）

政治の地域（data/regions）と同じ書き方。select の書き方も同じで、`regions:` には政治の地域 ID も使える。

```yaml
- id: rel_bohemia
  name: ボヘミア
  select:
    regions: [bohemia]          # 政治の地域を流用してよい
  timeline:
    - from: 1648
      main: catholic            # 多数派
      note: 白山の戦い（1620）後の再カトリック化がほぼ完了
    - from: 1781
      main: catholic
      minor: lutheran           # 混在している場合の2番目（斜線で描く）
      note: ヨーゼフ2世の寛容令で、プロテスタントが公認される
      source: "https://ja.wikipedia.org/wiki/寛容令"
```

- **main**：その地域の多数派（民衆の信仰）。支配者の宗派ではなく住民の多数派で判断する（例：ハンガリー東部の改革派、オスマン帝国下のバルカンの正教徒）。
- **minor**：無視できない規模（目安として住民の2〜3割以上）の少数派がいる場合だけ書く。1つだけ。
- 年の決まり・重なりの決まり（いちばん小さい地域が優先）は政治の地域と同じ。
- 宗教の分布はゆっくり変わるので、項目は「大きな変化」があったときだけ足す（例：1685 ナントの王令廃止、1731–32 ザルツブルクのプロテスタント追放、オスマン領からキリスト教徒の地域への移行）。

## 世俗化（secular）

田村さんの決定（2026-11-21）：世俗化した地域ほど、伝統的な宗派の色を**薄く**する（色の種類はそのまま）。文字を読まなくても「信仰が弱まった」とわかるようにするため。

- timeline の項目に `secular: 0〜1` を書ける（宗教のみ）。無宗教・宗教離れ（教会を離れた・信仰を実践しない人）の割合の**目安**。0.5 なら住民の半分程度。統計の数字をそのまま写すのではなく、丸めた目安でよい。
- 地図では、main の色を地の色に寄せて塗る（0 で今までと同じ、1 でほぼ地の色。0.2〜0.4 の違いも見えるよう、はじめに大きく効く曲線。src/map.ts の `secularFade`）。少数派の斜線も同じだけ薄くなる。
- 国をクリックしたときのカードには「宗教離れ 約6割」と帯で出る。

### 書き方は2通り

1. **世俗化だけの地域**（ふつうはこちら）：`data/religion/secular.yaml` に、main を書かず secular だけの項目を並べた地域を作る。多数派の判定には使われず、世俗化の割合だけが重なる。国単位（`iso:`）で書けるので、宗派の細かい地域の分け方に関係なく塗れる。
   ```yaml
   - id: sec_czech
     name: チェコ
     select:
       iso: [CZE]
     timeline:
       - from: 1950
         secular: 0.4
         note: 共産党政権が修道院を解散
       - from: 1960
         secular: 0.6
   ```
2. ふつうの宗教の地域の項目に `secular:` を足す（その地域だけ値を変えたいとき）。

### 重なりの決まり

- 多数派（main）とは別に決まる：その年の記述に secular を書いている「いちばん小さい地域」の値が効く。小さい地域の項目に secular がなければ、外側の大きい地域の値が効く。
- `secular: 0` と書けば、外側の値を打ち消せる（例：両大戦間はポーランド領だったウクライナ西部を、ソ連のウクライナ全体の値から外す）。
- 値は次の項目の年まで続く。宗教が復活したときは、項目を足して値を下げる（例：ソ連解体の 1991）。

## 東アジア（2026-11-21、G4 担当）

東アジアの宗教は重層的で、一人の人が祖先祭祀・仏教・道教・神社の祭りに同時に関わるのがふつう。ヨーロッパのように「どの宗派に属するか」で一つに決められないので、次の方針で塗る。

| id | 名前 | 使う地域 |
|---|---|---|
| chinese_folk | 儒教・仏教・道教（中国の民間信仰） | 漢人の地域（中国本土・台湾・香港・満洲の漢人移住地）。祖先祭祀（儒教）・仏教・道教・民間の神々の信仰が混ざった「三教」を1つとして扱う |
| shinbutsu | 神道・仏教（日本） | 日本（和人の地域）。江戸時代の神仏習合と寺請制度。1868 年の神仏分離令の後も、住民の多くは神社と寺の両方に関わるので、1つのまま塗る（分離は note に書く） |
| confucian | 儒教（朝鮮） | 朝鮮。朝鮮王朝の国教の朱子学（祖先祭祀）に、巫俗（シャーマニズム）と仏教が重なる。韓国では 1980 年代まで |
| mahayana | 仏教（大乗） | 中国・日本以外で、仏教が独立した宗派として多数を占める所（韓国の慶尚道など。のちに東南アジアでも使う） |
| tibetan_buddhism | チベット仏教 | チベット・青海・モンゴル・内モンゴル（モンゴル人の地域）・ブリヤート・トゥヴァ・カルムイク |
| theravada | 上座部仏教 | 雲南のタイ族（シーサンパンナ・徳宏）。のちに東南アジアでも使う |
| other | その他 | シャーマニズム・アニミズム（満洲・シベリアの先住民、アイヌ、台湾原住民、琉球の祖先祭祀・ノロの信仰など） |

- **色の系統**：仏教圏（chinese_folk・shinbutsu・mahayana・tibetan_buddhism・theravada）は赤〜桃色でそろえ、仏教が共通の土台であることを見せる。朝鮮の儒教は墨色（青灰）。
- **イスラーム**：回族（中国語を話すムスリム）・ウイグル人・カザフ人などは sunni。寧夏・甘粛の臨夏・青海の西寧では minor に入れる。
- **キリスト教**：韓国のプロテスタントは長老派（カルヴァン派の系統）が最大なので `reformed` で塗る（note でプロテスタント全体と書く）。中国・日本・台湾のキリスト教徒は少数（数％）なので note に書く。
- **共産主義政権と世俗化**（data/religion/secular.yaml）：中国は 1949 年以後に上げ、文化大革命（1966–76）で最も高くし、改革開放で下げる。北朝鮮は 1950 年代から非常に高い。モンゴルは 1937–39 年のラマ僧の粛清で高くなり、1990 年の民主化で下がる。ソ連のシベリアはヨーロッパ・ロシアと同じ値。
- **日本・韓国の世俗化**：日本は戦後、「信仰を持っていない」と答える人が多数になる（ただし初詣・葬式などの行事は続く）ので、目安として 0.3〜0.55。韓国は無宗教が半数前後（2015 年の国勢調査で 56%）。
- **目安**

| 地域 | 年と secular |
|---|---|
| 中国 | 1949 0.2、1958 0.4、1966–76 0.7、1978 0.55、2000〜 0.5 |
| チベット・新疆 | 1959／1958 0.2、1966–76 0.6、1980 0.25、新疆は 2017 年から 0.4 |
| 北朝鮮 | 1946 0.3、1958 0.8 |
| 日本 | 1950 0.3、1975 0.45、2000 0.55 |
| 韓国 | 1960 0.35、1985 0.45、2015 0.55 |
| 台湾 | 1980 0.1、2000 0.15 |
| 香港 | 1970 0.35、2000 0.5 |
| モンゴル | 1930 0.3、1938 0.75、1990 0.4、2000 0.35 |

## 南北アメリカ（2026-11-21、A6 担当。data/religion/americas.yaml）

| id | 名前 | 使う地域 |
|---|---|---|
| evangelical | 福音派（バプテスト・メソジストなど。ペンテコステ派を含む） | アメリカ合衆国南部・中西部（第 2 次大覚醒〈1790–1840〉以後）、アフリカ系アメリカ人の教会、カナダのメソジスト、20 世紀後半のブラジル・中米・チリの福音派（minor）、モラヴィア兄弟団の伝道地（ミスキート海岸・スリナム・米領ヴァージン諸島） |
| lds | モルモン教（末日聖徒イエス・キリスト教会） | ユタ（1847–）、アイダホ（南東部が中心。ピースは州全体） |

- 宗派の分け方：会衆派（ピューリタン）・長老派・オランダ改革派・クエーカー（塗る色がないので）は reformed、イギリス国教会（独立後の監督派）は anglican、
  ドイツ系・北欧系は lutheran、メノナイトは evangelical。カナダ合同教会（1925）は evangelical のまま note に書く。
- 先住民の伝統的な信仰は other。植民地・伝道所（ミッション）が住民の多数を改宗させた時期からキリスト教の色にする
  （フロリダ・ニューメキシコ・カリフォルニアの伝道所、パラグアイのイエズス会のグアラニーの伝道村、アマゾンのゴム・ブームなど）。
- **奴隷とされたアフリカ人が住民の多数だったプロテスタントの植民地**（英領・オランダ領・デンマーク領の砂糖の島、ガイアナ・スリナム、ベリーズ、サウスカロライナ・ジョージアのロウカントリー）は、「住民の多数派」の原則どおり、奴隷が多数になった年から main: other（アフリカの伝統的な信仰）・minor: 宗主国の宗派とし、モラヴィア派・メソジスト・バプテストの伝道で奴隷の多くがキリスト教徒になった年（おおむね 1820〜30 年代、スリナムは 1850 年）から宗主国の宗派（またはメソジスト・バプテストが中心なら evangelical）を main にする。奴隷にも洗礼を義務づけたカトリックの植民地（ブラジル・キューバ・サン＝ドマング・フランス領アンティル・キュラソーなど）は catholic のまま。
- アフリカ系の習合的な信仰（ヴードゥー・サンテリア・カンドンブレ・ウンバンダ・ウィンティ）とラスタファリは塗らず note に書く（多くの人がカトリック・プロテスタントと重ねて信じるため）。
  スリナムのマルーンの地は other（ウィンティ）。
- 移民の宗教：トリニダード中南部・ガイアナの海岸・スリナムの農村はインドからの年季契約の労働者のヒンドゥー教（hindu）、
  スリナムのコメウェイネはジャワ系のイスラーム（sunni）、ハワイ（1900–60）は日系人の仏教（shinbutsu）、ニューヨーク市のユダヤ人（1900–）は jewish の minor。
- 世俗化（secular.yaml）：アメリカ合衆国（南部は低く、ニューイングランド・西海岸は高い）、カナダ（ブリティッシュコロンビアは高い、ケベックは「静かな革命」の 1960 年代から）、
  ウルグアイ（1919 年の政教分離から）、キューバ（1959 年の革命から。1976–92 年が最も高い）、チリ・アルゼンチン・ブラジル・メキシコ（2000 年代から）。
- 無人の小さな島（ウルグアイ川の中州イスラ・ブラジレラなど）にも近くの地域の値を入れている。サウスジョージア島（捕鯨基地 1904–66 の後は観測基地だけ）はデータなし。
  アメリカ合衆国の太平洋の領土（グアム・北マリアナ・米領サモア）はオセアニアの担当に残す。

## アフリカ（2026-11-23、F5 担当。data/religion/africa.yaml）

北アフリカ（マグリブ・エジプト）は west.yaml のまま（スンナ派、エジプトはコプトが1割前後）。サハラ以南とインド洋の島々を africa.yaml に書いた。

| id | 名前 | 使う地域 |
|---|---|---|
| african_initiated | アフリカ独立教会（シオン派・使徒派など） | 南アフリカの黒人の地域（1970〜。1940〜69 年は minor）、ジンバブエ・エスワティニ・モザンビーク中南部（1970〜90 年代〜）。キンバング教会（下コンゴ）・レジオ・マリア（ケニアのルオ人）などは minor |

- **伝統的な信仰は other**。キリスト教・イスラームが住民の多数派になった年の目安で切り替えた（統計のない時期は推計。note に「比率は要確認」）。
  - イスラーム：サヘルの町と王侯・商人は早くからムスリムだったが、農村の多数がムスリムになったのは西アフリカのジハード（フータ・ジャロン 1725、フータ・トロ 1776、ソコト 1804、マシナ 1818、ウマル・タル 1852）や 19 世紀のスーフィー教団（セネガルのムリッド教団など）の後とした。東アフリカは沿岸のスワヒリの町が古くからムスリムで、内陸は隊商交易とともに（ヤオ人・タボラ・ウジジなど 1880 年前後）。
  - キリスト教：古くからのものはエチオピア・エリトリア高原（oriental）、コンゴ王国（1648 年は catholic・minor other。1780 年に逆転）、カーボベルデ・サントメ・ルアンダ（catholic）、ケープ植民地（reformed）。
    その他はおおむね 1920〜60 年代（伝道会と学校の普及）に多数派になる。ルワンダ・ブルンジは 1930 年代の集団改宗の後の 1950 年（1930 年から minor）、ブガンダは 1900 年、イメリナは 1870 年（女王の改宗）。
  - 宗派の色は伝道会の系統で：メソジスト・バプテスト・ペンテコステ派・アドベンチスト・SIM や AIM などの福音派は evangelical、長老派・会衆派（ロンドン伝道協会・アメリカン・ボード）・オランダ改革派・パリ福音伝道会は reformed、
    ルター派の伝道会（ライン・フィンランド・ベルリン・ライプツィヒ・メカネ・イエス教会）は lutheran、CMS・UMCA・スーダン聖公会は anglican。プロテスタントが複数の教派に分かれる所は、最大の伝道会の色（目安）。
- 奴隷貿易の積出地やプランテーションの島（モーリシャス・レユニオン・セーシェル）は住民の多数派で。モーリシャスは 1860 年からインド系のヒンドゥー教（hindu）。ダーバンにはインド系のヒンドゥー教徒の minor。
- 無人島だった時期は値を入れない（レユニオン 1665 前、セーシェル 1770 前、ロドリゲス 1800 前、アセンション・トリスタン 1816 前、チャゴス 1783 前、フランス領南方・南極地域は全期間）。チャゴスは 1967–73 年の住民の強制退去の後も、退去前の住民の値のまま（note）。
- 世俗化（secular）はアフリカでは使っていない（信仰を持たない人の割合が全体に低いため）。
- 言語（data/language/africa.yaml）と同じ地域の分け方で、大きな変化（ジハード・入植・移民など）はなるべく同じ年に切り替えている（元は scratchpad の生成スクリプトで両方を書き出した。今は YAML を直接直す）。改宗と民族の移動のように、意味のある違いで年がずれる所もある。

## オセアニア（2026-11-23、O3 担当。data/religion/oceania.yaml）
- 先住の信仰（祖先・精霊・マナとタプ、アボリジニのドリーミング）は other。宣教で住民の多数がキリスト教徒になった年から宗派の色にする（目安：タヒチ 1815、ニュージーランドのマオリ 1835〜50、トンガ 1835、サモア 1840、フィジー東部・沿岸 1855・内陸 1875、ミクロネシア 1870〜1900、パプア南岸・ニューブリテン 1910、ソロモン・ヴァヌアツ 1900〜50、ニューギニア高地 1965〜75）。
- 宗派の色は伝道会の系統で：LMS・ABCFM（会衆派）・長老派・パリ福音伝道会は reformed、メソジスト・SSEM・アドベンチスト・福音派の伝道会は evangelical、CMS・メラネシア伝道会は anglican、ノイエンデッテルスアウなどのルター派は lutheran、マリスト会・ピクプス会・聖心会・神言会は catholic。合同教会（オーストラリア 1977、パプアニューギニア 1968）はもとの最大の教派の色のまま。
- 入植者：オーストラリアは anglican（minor catholic）で、カトリックが上回った年（ヴィクトリア 1970、南オーストラリア 1980、ほかは 1990）に入れ替える。タスマニアは anglican のまま。ニュージーランドは anglican（minor reformed）、オタゴ・サウスランドは reformed（長老派）。マオリの預言者の宗教（パイ・マリーレ・リンガトゥ・ラタナ）、カーゴ・カルト、ジョン・フラム運動、パラオのモデクゲイは note。
- フィジーのインド系（1879–1916 の年季契約移民）はヒンドゥー教（hindu）。バ州 1921・マクアタ州 1940 から main、ほかの砂糖地帯は minor。日本の南洋諸島（コロールなど 1930–45）は shinbutsu。クリスマス島は chinese_folk（minor sunni）、ココス諸島は sunni。
- 世俗化：sec_australia（1970 0.12 → 2021 0.45）、sec_new_zealand（1970 0.12 → 2018 0.5）。先住民が多数のノーザンテリトリー東部・南オーストラリア最西部は secular: 0。太平洋の島々には入れない。
- 無人島（南極・ハード島・マッコーリー島・ケルマデック・亜南極諸島・クリッパートン・アメリカ領有小離島・南ライン諸島）は値を入れない。人が住みはじめた島はその年から（ノーフォーク 1788、ピトケアン 1790、ココス 1827、クリスマス島 1888、ライン諸島 1890、フェニックス諸島 1938）。

## 1453–1647（2026-11-24、分布担当）
- 各地域の timeline の先頭に 1453 年からの項目を足した（1648 年以後の値は変えていない。atlas.json の 1648–2025 の main・minor・secular と、効いている地域を作業前と比べて確認）。
  変化がない地域は 1648 年と同じ値を 1453 年から入れている。
- **until（この年まで有効）**：1648 年の形で分けた地域では表せない 1648 年より前の区分けは、`until: 1647` を書いた地域で示す
  （例：ドイツの諸邦の宗教改革の時期、オーバープファルツ、ボヘミア・モラヴィア、グラナダ、ウクライナ・ロシア南部の草原）。
  until の翌年からはその地域は使われず、外側の地域の記述が効く。宗教・言語の両方で使える（tools/build_data.mjs の buildDistribution）。
  ```yaml
  - id: rel_upper_palatinate_pre
    name: オーバープファルツ（1453–1647）
    select:
      regions: [upper_palatinate]
    until: 1647
    timeline:
      - from: 1453
        main: catholic
      - from: 1556
        main: lutheran
  ```
- 宗教の種類に **hussite（フス派。ウトラキスト・兄弟団）** を足した。フス戦争後のボヘミア・モラヴィアで住民の多数を占めた（1453–1623）。
  白山の戦い（1620）後の再カトリック化で 1624 年から catholic（minor hussite）。モラヴィアの兄弟団・ルター派・再洗礼派もこの色でまとめた。
- 宗教改革の広がり（目安）：ルター派はエルネスト系ザクセン・ニュルンベルク・リューネブルク・ハンザ都市などが 1521–28 年、アルベルト系ザクセン・ブランデンブルク・
  ポンメルン・ヴュルテンベルクが 1525–39 年、メクレンブルク・ブラウンシュヴァイクが 1549–68 年。北欧 1527–40 年、プロイセン公国 1525 年、リヴォニア 1525–60 年。
  カルヴァン派はスイス 1523–36、プファルツ 1563、ネーデルラント 1566–1600、スコットランド 1560、ハンガリー東部 1565、トランシルヴァニアのハンガリー人 1560。
  イングランドは 1534 anglican（minor catholic）→ 1553 メアリ1世の catholic → 1559 統一法 → 1600 anglican。
  対抗宗教改革：南ネーデルラント 1585、フランケンの司教領・ヴェストファーレン 1600–10、内オーストリア 1600、ボヘミア 1624、上・下オーストリア 1625、オーバープファルツ 1628、ハンガリー西部・スロヴァキア 1630。
- 住民の多数派の原則どおり、強制改宗の後もひそかに信仰を保ったグラナダのモリスコは 1571 年（アルプハラスの反乱後の強制移住）まで sunni、
  バレンシア・アラゴンのモリスコは minor sunni で、追放（1609–10）で消える。ユダヤ教徒の追放（1492・1497）は note。
- サファヴィー朝のシーア派化：イランは 1453 sunni（minor shia）→ 1510 shia（minor sunni）→ 1600 shia。オスマン帝国のバルカンのイスラーム化は、
  ボスニア 1500 minor → 1560 main、アルバニア 1530 minor → 1600 main、ブルガリア北東部・ロドピ 1530–50 年など。

- **アジア（2026-11-25、Z8 担当）**：東アジア・内陸アジア・南アジア・東南アジアの地域にも 1453 年からの項目を足した。1648 年の値が外側の地域と同じ小さな地域は
  項目を足さず、1647 年までは外側の地域の記述が効く（例：韓国の各道は rel_korea）。主な変化：朝鮮の儒教化（1453 mahayana／minor confucian → 1550 → 1610 confucian）、
  モンゴルへのチベット仏教の再伝播（1453 other → 内モンゴル 1580・外モンゴル 1586・オイラト 1616）、ハミ・トゥルファンのイスラーム化、
  長崎のキリシタン（rel_nagasaki_pre、1570–1637 minor catholic）、ベンガル東部のイスラーム化（1610 sunni）、ゴアのカトリック化（1510・1570）、
  聖トマス派（1599 年のディアンペル会議までは oriental）、東南アジア島嶼部のイスラーム化（until の地域：ジャワ・スンダ・スマトラ南部・ミナンカバウ・ランプン・
  南カリマンタン・スラウェシ・北マルク・ヌサ・トゥンガラなど）、アンボン・ソロルのカトリック→改革派、フィリピンのカトリック化（1580・1600・1630）、
  チャンパー北部のベトナム化（rel_champa_north_pre、1471–1600）。

## atlas.json への出力（tools/build_data.mjs）

```
religion: {
  kinds: [{ id, name, color }],
  regions: [{ id, name, timeline }],   // 世俗化だけの地域は含めない（値は pieceTimelines の 5 番目に入る）
  pieceTimelines: [[開始年, main の index, minor の index（なければ -1）, 地域 index, secular（0 より大きいときだけ）], ...]  // ピースごと
}
```

## 確認のしかた

- `npm run data` で検証される。main / minor が `_kinds.yaml` にない ID、timeline が年の昇順でない、未定義の地域を参照している、などは警告になる。
- ファイル名が `_` で始まるもの（`_kinds.yaml`）は地域として読まない。
- secular が 0〜1 の数値でない、main のない項目と main のある項目が同じ地域に混ざっている、なども警告になる。
- 地図の画像で確かめる：`node tools/snapshot.mjs 1914 1960 2025 --layer religion`
- 宗教データのないピースを数える：`node tools/build_data.mjs --religion-missing 1650,1750,1800`（`--iso DEU,AUT` で国を絞れる）。
- 同じ ID の地域が宗教にも政治にもあるときは、`regions:` では宗教の地域が優先される。
