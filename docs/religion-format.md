# 宗教の分布データの形式

田村さんと決めた方針（2026-11-20）：
- 宗教から作る（言語・民族は後で同じ仕組みで作る）
- 分け方は教科書程度（下の表）
- 描き方は「多数派の色で塗り、混在している地域は2色目の斜線を重ねる」

## 宗教の種類（data/religion/_kinds.yaml）

| id | 名前 | 色の系統 |
|---|---|---|
| catholic | カトリック | 黄 |
| lutheran | ルター派 | 青 |
| reformed | カルヴァン派（改革派） | 紫 |
| anglican | イギリス国教会 | 赤 |
| orthodox | 正教会 | 茶 |
| oriental | 東方諸教会（アルメニア使徒教会・コプト教会など） | 橙 |
| sunni | イスラーム（スンナ派） | 緑 |
| shia | イスラーム（シーア派） | 濃い緑 |
| other | その他（シャーマニズムなど） | 灰 |

- 東方典礼カトリック（ユニエイト）はカトリックに含め、note に書く。
- ユダヤ教（jewish）は原則として塗りには使わない（都市や地域の note に書く）。例外として、1948 年以後のイスラエルのように多数派になる地域では塗る。

## 地域ごとの変遷（data/religion/*.yaml）

政治の地域（data/regions）と同じ書き方。select の書き方も同じで、`regions:` には政治の地域 ID も使える。

```yaml
- id: rel_bohemia
  name: ボヘミア
  select:
    regions: [bohemia]          # 政治の地域を流用してよい
  timeline:
    - from: 1648
      main: catholic            # 多数派
      note: 白山の戦い（1620）後の再カトリック化がほぼ完了
    - from: 1781
      main: catholic
      minor: lutheran           # 混在している場合の2番目（斜線で描く）
      note: ヨーゼフ2世の寛容令で、プロテスタントが公認される
      source: "https://ja.wikipedia.org/wiki/寛容令"
```

- **main**：その地域の多数派（民衆の信仰）。支配者の宗派ではなく住民の多数派で判断する（例：ハンガリー東部の改革派、オスマン帝国下のバルカンの正教徒）。
- **minor**：無視できない規模（目安として住民の2〜3割以上）の少数派がいる場合だけ書く。1つだけ。
- 年の決まり・重なりの決まり（いちばん小さい地域が優先）は政治の地域と同じ。
- 宗教の分布はゆっくり変わるので、項目は「大きな変化」があったときだけ足す（例：1685 ナントの王令廃止、1731–32 ザルツブルクのプロテスタント追放、オスマン領からキリスト教徒の地域への移行）。

## 世俗化（secular）

田村さんの決定（2026-11-21）：世俗化した地域ほど、伝統的な宗派の色を**薄く**する（色の種類はそのまま）。文字を読まなくても「信仰が弱まった」とわかるようにするため。

- timeline の項目に `secular: 0〜1` を書ける（宗教のみ）。無宗教・宗教離れ（教会を離れた・信仰を実践しない人）の割合の**目安**。0.5 なら住民の半分程度。統計の数字をそのまま写すのではなく、丸めた目安でよい。
- 地図では、main の色を地の色に寄せて塗る（0 で今までと同じ、1 でほぼ地の色。0.2〜0.4 の違いも見えるよう、はじめに大きく効く曲線。src/map.ts の `secularFade`）。少数派の斜線も同じだけ薄くなる。
- 国をクリックしたときのカードには「宗教離れ 約6割」と帯で出る。

### 書き方は2通り

1. **世俗化だけの地域**（ふつうはこちら）：`data/religion/secular.yaml` に、main を書かず secular だけの項目を並べた地域を作る。多数派の判定には使われず、世俗化の割合だけが重なる。国単位（`iso:`）で書けるので、宗派の細かい地域の分け方に関係なく塗れる。
   ```yaml
   - id: sec_czech
     name: チェコ
     select:
       iso: [CZE]
     timeline:
       - from: 1950
         secular: 0.4
         note: 共産党政権が修道院を解散
       - from: 1960
         secular: 0.6
   ```
2. ふつうの宗教の地域の項目に `secular:` を足す（その地域だけ値を変えたいとき）。

### 重なりの決まり

- 多数派（main）とは別に決まる：その年の記述に secular を書いている「いちばん小さい地域」の値が効く。小さい地域の項目に secular がなければ、外側の大きい地域の値が効く。
- `secular: 0` と書けば、外側の値を打ち消せる（例：両大戦間はポーランド領だったウクライナ西部を、ソ連のウクライナ全体の値から外す）。
- 値は次の項目の年まで続く。宗教が復活したときは、項目を足して値を下げる（例：ソ連解体の 1991）。

## atlas.json への出力（tools/build_data.mjs）

```
religion: {
  kinds: [{ id, name, color }],
  regions: [{ id, name, timeline }],   // 世俗化だけの地域は含めない（値は pieceTimelines の 5 番目に入る）
  pieceTimelines: [[開始年, main の index, minor の index（なければ -1）, 地域 index, secular（0 より大きいときだけ）], ...]  // ピースごと
}
```

## 確認のしかた

- `npm run data` で検証される。main / minor が `_kinds.yaml` にない ID、timeline が年の昇順でない、未定義の地域を参照している、などは警告になる。
- ファイル名が `_` で始まるもの（`_kinds.yaml`）は地域として読まない。
- secular が 0〜1 の数値でない、main のない項目と main のある項目が同じ地域に混ざっている、なども警告になる。
- 地図の画像で確かめる：`node tools/snapshot.mjs 1914 1960 2025 --layer religion`
- 宗教データのないピースを数える：`node tools/build_data.mjs --religion-missing 1650,1750,1800`（`--iso DEU,AUT` で国を絞れる）。
- 同じ ID の地域が宗教にも政治にもあるときは、`regions:` では宗教の地域が優先される。
