# オセアニア（1648–2025）：データ作成担当への共通の指示

世界の最後の地域としてオセアニアを作る。年の範囲は 1648–2025。

## 最初に読むもの
1. CLAUDE.md（「画面づくりの原則」「進捗」）
2. docs/data-format.md（certainty、label、overlord、出来事の at）、docs/agent-brief.md（手順・検証・してはいけないこと）
3. docs/agent-brief-americas.md・docs/agent-brief-africa.md（実効支配・主張・先住の国家・植民地・保護領の扱い。同じ考え方）
4. 既存の政体（作り直さずに使う）：britain・france・germany（german_empire）・spain・netherlands・usa・japan・portugal など。ハワイ王国（hawaii）・グアム・北マリアナ・米領サモアは南北アメリカの担当（data/*/usa.yaml）がすでにデータを持っている。
5. ピースは data/generated/pieces.tsv（iso・adm1 列）。

## 描き方の方針（南北アメリカ・アフリカと同じ考え方）
- **実効支配は濃く、主張だけは斜線、先住の主な国家・勢力は独自の色**：
  - 1788 年のニューサウスウェールズのように、植民地の入植地と周辺の実際に治めていた所は宗主国の色（certainty なし）＋label（植民地名）。主張だけの範囲（1788 年の東経135度までの主張、内陸）は nominal（斜線）。入植・行政が及んだ年から濃く。
  - アボリジニの土地のうちどの国の主張も及ばない所は owner なし（所属なし）にして note に。
  - ハワイ王国（既存）・トンガ王国・タヒチ（ポマレ朝）・フィジー（ザコンバウの王国 1871–74 など）・サモアの王国・マオリの王位運動（キーンギタンガ、1858–）など、教科書や一般的な歴史地図に出る政体は独自の色。範囲があいまいなら uncertain。
- **植民地と保護領**：直轄の植民地は宗主国の色＋label。在地の王が残った保護領（トンガ 1900–70、ソロモンの一部など、間接統治が明確なもの）は宗主国の indirect（薄い色）＋label。委任統治（南洋諸島＝日本、ナウル、ニューギニア＝オーストラリア、西サモア＝ニュージーランド）・信託統治は統治国の色＋label。
- オーストラリア・ニュージーランドの自治・独立（1901 オーストラリア連邦、1907 ニュージーランド自治領、ウェストミンスター憲章の採択 1942/1947）は、独自の政体 `australia`・`new_zealand` を植民地時代と分けて作り、連邦・自治領の成立の年から独自の色。それ以前は britain＋label。
- 太平洋戦争の日本の占領地（1941/42–45：ニューギニア北部・ソロモン・ギルバート・ナウル・ウェークなど）は japan・occupied。南洋諸島（日本の委任統治 1919–45）は japan＋label。
- 南極（ATA）は所属なし（各国の領有主張は note に）。
- 表記は日本の高校世界史の教科書に合わせる（クック、タスマン、流刑植民地、ゴールドラッシュ、白豪主義、ワイタンギ条約、マオリ戦争 など）。

## 作るもの・確認
- 担当範囲のすべてのピースに 1648–2025 の所属を与える（意図した所属なしは note と報告に）。確認：`node tools/build_data.mjs --missing 1648,1700,1770,1788,1800,1830,1840,1860,1880,1900,1914,1920,1942,1945,1970,2025 --iso <国コード>`。
- 元首（植民地の時期は宗主国の元首を使うので不要。在地の主な王・独立後の首相など実権者）を出典の URL つきで。情勢（periods）3〜8 件、出来事 30〜60 件（高校世界史で太字になる事件はもらさない）。場所がはっきりした出来事には `at: [経度, 緯度]` を付ける。
- 地図の確認：`node tools/snapshot.mjs 1648 1770 1788 1830 1840 1860 1880 1900 1914 1920 1942 1945 1970 2025 --zoom <経度>,<緯度>,<倍率> --out .cache/snapshots/<担当名>`。
- `npm run data` が警告なしで通ること（他担当の未定義 ID による警告は報告に書く）。
- 作業用のスクリプトは、リポジトリの外の scratchpad（/tmp/claude-0/-home-user-world-history-atlas/5a7a987a-a877-559b-b3fe-1574c9cf110f/scratchpad/<担当名>/）に置く。

## 敏感な主題
先住民（アボリジニ・マオリ・太平洋の人々）への土地の収奪・暴力・同化政策（盗まれた世代など）、ブラックバーディング（労働者の強制的な徴募）、核実験（ビキニ・ムルロア）、ブーゲンヴィル紛争、ニューカレドニアの独立運動などは、事実に基づき、高校世界史・一般的な百科事典の水準の中立的な表現で書く。
