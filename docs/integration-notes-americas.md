# 南北アメリカ（1648–2025）の担当間の整合

担当：A1 アメリカ合衆国（data/*/usa.yaml、usa は data/polities/west.yaml）、A2 カナダ・アラスカ（canada.yaml）、A3 メキシコ・中米・カリブ（mexico_caribbean.yaml）、A4 南米北部・アンデス（andes.yaml）、A5 ブラジル・南米南部（south_cone.yaml）、A6 分布（data/religion・language の americas.yaml、data/cities.yaml の該当分、data/movements/americas.yaml）。指示書は docs/agent-brief-americas.md。
やり方は docs/integration-notes-south-asia.md と同じ。担当の境界で隣り合うピース（pieces.topo.json の共有辺）の所属（owner・overlord・certainty）を 1648–2025 の全年で比べ、「前後は同じなのに数年だけ食い違う」組と「同じ持ち主への切り替えの年が 1〜12 年ずれる」組を拾った。色は、隣り合う政体の組を全世界のピースで全年拾い、色差（CIE76 の ΔE）の小さい順に見た。首都は、都市の座標を含むピースの所属を首都の期間の全年で確かめた。

## 整合の結果

### 1. A1–A2（アメリカ合衆国とカナダの境）

- **アルーストック（1783–1841 usa・uncertain「イギリス領ニューブランズウィックとの係争地」、1842 ウェブスター＝アッシュバートン条約）**：A2 のニューブランズウィック（1784 年から植民地）・ケベックと段差はあるが、係争地を合衆国側の斜線で描く意図どおり。マダワスカのアカディア人をニューブランズウィックが治めたことは note にある。そのまま。
- **レッド川流域（1670–1817 britain・nominal「ルパートランド（ハドソン湾会社）」、1818 年の英米協定で usa）**：A1 のノースダコタ東部・ミネソタ北西部と A2 のマニトバはそろっていた。1812–17 年は A2 のレッド・リヴァー植民地（セルカーク）だけ濃い（入植地なので正しい）。A1 の cause の「1818年の英米条約」（9 か所）を A2 の出来事の題名「1818年の英米協定」にそろえた。
- **1760 年のカナダ**：ケベック市（1759）・モントリオール・トロワリヴィエール・セニョリー・下流は britain・occupied「カナダ（イギリスの軍政）」、奥地は nominal（同じ label）で、1763 年からケベック植民地。A1 の五大湖の砦（デトロイトなど）は 1760 年から britain・nominal（モントリオールの降伏）、シャンプレーン湖は 1759 年（タイコンデロガ・クラウン・ポイントの陥落）で、矛盾はない。そのまま。
- **オレゴン・カントリー**：A1 のワシントン・オレゴン・アイダホ・モンタナ西部は 1818–45 britain・nominal「オレゴン・カントリー（英米の共同占有）」、ウィラメット谷だけ 1843–45 usa・uncertain（臨時政府）、1846 年のオレゴン条約で usa。A2 のブリティッシュコロンビア本土は 1805 年から britain・nominal（ニューカレドニア）で、1818 年より前の A1 側は所属なし（どの国も治めていない）。そろっていた。A1 の note の「（A2 のブリティッシュコロンビアと同じ）」は画面に出るので「（ブリティッシュコロンビアと同じ）」に。
- 表記：「オレゴン協定」（A1 の出来事の題名、west.yaml のポーク大統領の note など 7 か所）と「オレゴン条約」（A1 の cause）が混在 → **「オレゴン条約」**にそろえた。

### 2. A1–A3（合衆国とメキシコの境）

- **エルパソ**：A1 は 1682 年からスペイン（イスレタ・ソコロ）、1821 メキシコ（チワワ州）、1846 usa・occupied（ドニファンの部隊、12 月）、1848 usa。A3 のチワワとの段差は 1846–47 年の占領だけで、意図どおり。
- **ガズデン購入**：メシラ谷（ドニャ・アナなど）は 1843 年からメキシコ（チワワ州の入植）、トゥーソン・ユマは 1821 年からメキシコ（ソノラ）、どれも 1854 年から usa（1853 年 12 月調印、1854 年 6 月批准）。A3 のソノラ・チワワとそろっていた。
- **ヌエセス川以南**：A1 は 1836–45 年を mexico・uncertain「テキサスとの係争地」、1846 usa・occupied、1848 usa。A3 のタマウリパス・ヌエボレオン・コアウイラは同じ期間 mexico（確か）で、係争地だけ斜線になる。意図どおり。
- **テキサス・カリフォルニア**：テキサス共和国（1836–45）の範囲は A1 の中部・東部・海岸だけで、西部（コマンチェリア）は comanche のまま。カリフォルニアは 1846 年に usa・occupied（ロサンゼルスは 1846 年 mexico・uncertain〈カリフォルニオの蜂起〉、1847 年に占領）、1848 年に割譲。A3 のバハ・カリフォルニアとそろっていた。
- **アパッチ（apache）**：A3 が定義し A1 だけが使う。A1 は 1700 年からトランス・ペコス（〜1880）・ニューメキシコ南部（メスカレロ〜1862、ヒラ川〜1871、メシラ〜1842）・アリゾナ南東部（〜1871）。A3 の政体の note が「A1 の判断」となっていたので、**地図でどこを塗るかの説明に書き直した**（メキシコ側はスペイン・メキシコの色で塗る理由も残した）。A1 のファイルの冒頭の「A3 の定義を使う」は「mexico_caribbean.yaml の定義を使う」に。
- **オースティン**：テキサス共和国の首都オースティン（1839–41）を含むトラヴィス郡が A1 のヒル・カントリー（1750–1845 comanche）にあり、首都がコマンチの色の中にあった → **トラヴィス郡・ウィリアムソン郡を「テキサス中部・沿岸（オースティンの植民地）」（us_tx_austin）に移した**（1825 メキシコ・1836 テキサス・1845 合衆国）。隣のヘイズ・バストロップ郡はもとからこの地域。

### 3. A3–A4（パナマ）

- パナマ（A3）は 1821 年 gran_colombia（11 月の独立宣言で大コロンビアに加わる）、1831 colombia、1840 イスモ自由国（panama・uncertain）、1841 colombia、1903 panama（overlord: usa、1939 まで）。A4 のチョコ（1819 gran_colombia・uncertain、1820 確か、1831 colombia）とそろっていた。パナマが 1819–20 年もスペインなのは正しい（地峡の独立は 1821 年）。
- **表記「グラン・コロンビア」（A3 の 11 か所）→ 教科書の「大コロンビア」**にそろえた。A4 の政体名は「コロンビア共和国（大コロンビア）」、short は「大コロンビア」。

### 4. A4–A5（ボリビアの境）

- **タリハ（A4）**：1807 サルタ州、1810 ブエノスアイレスの軍（uncertain）、1811 ペルー副王の軍、1825 リオ・デ・ラ・プラタ連合州（uncertain）、1826 ボリビア。A5 のオラン・チャコ（連合州・アルゼンチン）との段差は、帰属が争われた地なので意図どおり。
- **アタカマ・アントファガスタ**：A5 の沿岸部（cl_litoral）は 1825 ボリビア、1879 chile・occupied、1884 chile。プーナ・デ・アタカマは 1879 occupied・1884 chile・1899 アルゼンチン。A4 のボリビア本体（ポトシ）とそろっていた。
- **アリカ・タクナ**：A5 のアリカ・A4 のタクナとも 1880 chile・occupied、1884 chile・uncertain（アンコン条約の 10 年の管理、住民投票なし）、1929 年のリマ条約でアリカはチリ・タクナはペルー。A4 のモケグアは 1884 年にペルー。そろっていた。
- **アクレ**：A5 は 1810 年だけ「アルト・ペルー（ブエノスアイレスの軍）」（united_provinces・nominal）にしていたが、隣の A4 のパンド・ベニは 1810–24 年スペインのまま（アマゾンの奥地）で、1810 年だけ段差になっていた → **A5 のアクレの 1810・1811 年の項目を消し、1824 年までスペイン（nominal）**にした（note に理由）。1825 bolivia（nominal）、1902 uncertain（アクレ戦争）、1903 ブラジル（ペトロポリス条約）はそのまま。パンド（A4）は 1900 年からボリビアの拠点で確か、アクレ（A5）は 1902 年まで nominal で、1900–01 年だけ濃さが違うが、アクレではボリビアの支配が弱かったので残した。
- **ペルー・ボリビア連合の出来事**：A4「ペルー・ボリビア連合の成立」（1836 年 10 月）と A5「チリのペルー・ボリビア連合への宣戦」（1836 年 12 月）が同じ年の一続きの出来事 → **A4 にまとめ**（text にチリの宣戦・アルゼンチンの参戦・ユンガイでの解体、polities に chile・argentina）、A5 を削除。A4 の「ユンガイの戦い」（1839）はそのまま。
- **太平洋戦争・チャコ戦争**：太平洋戦争は A5「太平洋戦争（硝石戦争）」（1879、戦争全体）、A4「アンガモスの海戦」（1879）・「チリ軍のリマ占領」（1881）・「ボリビアとチリの休戦協定」（1884）、A5「アンコン条約」（1883）で、主題が重ならないので全部残した。チャコ戦争は A5 だけ。

### 9. 1648 年の地図の濃さ

担当ごとに 1648・1700 年の面積の内訳（ヨーロッパの国の確か／nominal／uncertain、先住民勢力、所属なし）を出し、北アメリカ・南アメリカの全体の画像で見た。

- **パラー（A5、125 万 km²）**：1648 年からポルトガルの確かな支配（濃い色）で、アマゾン川流域の大部分が濃く塗られていた（A2 はセントローレンス川沿いのセニョリーさえ 1663 年まで nominal）→ **1648–1750 は portugal・nominal**、**1751 年（グラン・パラ・マラニョン州、ポンバルの改革）から確か**にした。
- **ブエノスアイレス州のピース（A5、38 万 km²、エントレ・リオスを含む）**：1648 年から確かだったが、note のとおりサラド川より南のパンパは先住民の地 → **1648–1832 は nominal**（スペイン・連合州・アルゼンチン連合）、**1833 年（ロサスの砂漠遠征）から確か**にした。ブエノスアイレス市は別のピース（ar_buenos_aires_city）でもとから確か。
- そのままにしたもの：
  - A3 はメキシコ北部の大きな州のピース（チワワ・ソノラ・コアウイラ・ヌエボレオン、植民地期の一部）を spain・**uncertain**（黒い斜線）で塗り、A1 の隣の郡は spain・nominal（白い斜線）なので、1648–1700 年ごろ国境線で斜線の色が変わる。A3 の州は南部に鉱山・伝道所の町があり北部は先住民の地という「一部の支配」で、主張だけの A1 側（テキサス・アリゾナ）とは実際に違うので、uncertain のままにした。
  - A5 のトゥクマン・クージョ・サンタフェ（いずれも町の網があり、先住民の大勢力がない）、チリ北部の砂漠、A4 の東部平原（カサナレ・バリナス）は 1648 年から確か。
  - 先住民勢力（イロコイ・クリーク・チェロキー・チョクトー・チカソー・マプーチェ・イツァ・ミスキート）は独自の色で、所属なしは A1 の内陸（3.9 百万 km²）・A2 の極北と西部（ハドソン湾会社の 1670 年まで）にまとまり、どの担当も決まりどおりだった。

### 10. 潮流の spread の iso・adm1（A6 が tools/build_data.mjs に追加）

- `where: {iso: [...]}`・`{adm1: [...]}` を、年や所属に関係なく光る擬似の地域（"iso:MEX"・"adm1:USA/Virginia"）として movementRegions に入れ、画面は regions と同じ扱いで光らせる。src/map.ts の処理（regions のピースは所属を見ずに光らせる）とも合っていて、政治の地域 ID と名前がぶつかることもない（":" を含む）。存在しない国コード・adm1 は警告になる。docs/movements-format.md に説明がある。
- 妥当と判断した（植民地期のアメリカのように、政体で書くとヨーロッパの本国が光り、政治の地域の一覧を書くのも大変な所に向く）。exclude_regions には iso・adm1 を書けない点だけ注意（今は使っていない）。

## 直さなかったもの・自信のない点

- **パラーの 1751 年**：グラン・パラ・マラニョン州の設置と州都のベレン移転（1751）を、川沿いの支配が広がった目安にした。内陸の大部分はその後も先住民の地で、ブラジル独立後も含め「確か」はピースが大きいための近似。
- **ブエノスアイレス州の 1833 年**：ロサスの遠征で州の大半が入植の範囲に入った目安（州の南西の端は 1879 年の砂漠の征服まで先住民の地）。
- **アクレ 1900–01 年**：A4 のパンドは 1900 年から確か、A5 のアクレは 1902 年まで nominal。アクレではボリビアの税関（1899）をめぐる最初の蜂起（ガルベスのアクレ独立国、1899–1900）もあったので、1899–1901 年を uncertain にする考え方もある（未確認・そのまま）。
- **占領下の首都**：フィラデルフィア 1777・メキシコ市 1847・リマ 1881–82・アスンシオン 1869 は首都から外し、アメリカ軍が占領したハバナ・ポルトープランス・サント・ドミンゴは外さなかった。前者は政府が首都を離れた、後者は占領下でも国家（ハイチは大統領）が続いた、という区別だが、ドミニカ（1916–24）は軍政で現地の政府がなかったので、外す考え方もある。
- **色**：南北アメリカで 24 政体の色を変えた。lakota（橙）・cuba（濃い黄）・uruguay（紫）は前より濃い色になった。互いに隣り合わないことは確かめたが、田村さんの好みで調整してよい。usa とスペインの近さ（ΔE 15）は残っている。
- **言語の「その他の南米の先住民の諸語」（sa_other、`#ddd3b4`）**：アマゾンの奥地を塗る色が、データのない所の色（`#e6e2d8`、ΔE 13）に近く、1700 年の言語の地図で「データ未整備」に見えやすい。A6 の色の設計に関わるので変えていない（次に分布を触るときの候補）。
- 宗教・言語・潮流の中身（A6）は、年が政治とずれていないかと塗り漏れだけを見た。
