# 範囲の拡大（1914→2025）：データ作成担当への共通の指示

1648–1914 のデータ（レビュー済み）を **2025 年まで**延ばす。担当範囲（現代の国コード）と担当ファイルはこれまでと同じ（docs/polity-ids.md の表）。**既存のファイルに追記する**。

## 最初に読むもの
1. CLAUDE.md（「画面づくりの原則」「進捗」）
2. docs/data-format.md、docs/agent-brief.md（手順・検証・してはいけないこと。すべてそのまま当てはまる）、docs/agent-brief-1815-1914.md（前回の拡大の決まり。保護国・宗主権の扱いなどはそのまま続く）
3. docs/integration-notes-1914.md の「整合の結果」と「田村さんの決定」
4. data/events/europe.yaml（1914 年以降の分は「全体担当」が並行して書く）
5. 自分の担当の既存ファイル

## 作るもの
- 担当範囲のすべてのピースに 2025 年までの所属を与える。確認：`node tools/build_data.mjs --missing 1915,1920,1925,1939,1941,1943,1946,1950,1970,1990,1993,2000,2008,2025 --iso <担当の国コード>`（ゼロにする）。
- 地図の確認：`node tools/snapshot.mjs 1918 1923 1938 1942 1945 1949 1990 1993 2025 --zoom ... --out .cache/snapshots/<担当名>`（範囲外の年も見られる）。
- 主な国境の変化、政体の移り変わり、元首（君主・大統領・書記長など、その国で実権を持つ人。共和国は大統領と首相のどちらを書くか、その国の実態で判断し note に書く）を全員（出典の URL つき）、情勢（periods）を 3〜8 件、担当地域の出来事を 30〜60 件。

## 年の決まりと占領
- これまでどおり「Y 年の年末の状態」。
- **第二次世界大戦中の占領（1939–1945）は描く**（何年も続き、地図の理解に欠かせないため）。owner を占領した国（germany / italy / soviet_union / hungary / bulgaria など）にし、certainty: occupied。併合した所（ズデーテン、オーストリア、ポーランド西部など）は occupied を付けない。傀儡国家・保護領（ボヘミア＝モラヴィア保護領、ヴィシー政府のフランス、クロアチア独立国、スロヴァキア共和国、総督府など）は独自の政体として描いてよい（宗主権下なら overlord: germany など）。
- 第一次世界大戦中の占領（1914–1918）は、年末時点で 2 年以上続いたもの（ベルギー、セルビア、ポーランド王国、ルーマニア南部など）だけ certainty: occupied で描いてよい。担当どうしで方針をそろえること（迷ったら描く）。
- 1945–1949 のドイツ・オーストリアの占領地区：owner を占領国（usa / britain / france / soviet_union）にし、certainty: occupied、`label:`（data-format.md の副ラベル）に「ドイツ（アメリカ占領地区）」のように書く。
- 冷戦期のソ連の衛星国（ポーランド人民共和国など）は、それぞれの国として描く（overlord は付けない）。ソ連構成共和国は owner: soviet_union（1つの国として1色。共和国名は label に）。
- 植民地・委任統治領・保護国は、これまでどおり宗主国の色＋ label。独立した年に切り替える。
