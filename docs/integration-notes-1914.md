# 担当間の整合チェック用メモ（1815–1914 の延長）

## D（ハプスブルク）から
- C：トレンティーノ・南チロル・トリエステ・ゴリツィア（ITA）のドイツ連邦の枠を 1866 で外す。ロンバルディア 1859・ヴェネト 1866 の割譲
- E：ボスニア 1878 占領（owner habsburg、宗主権 ottoman のまま？）・1908 併合の年。トランシルヴァニア・バナート・ヴォイヴォディナ（1849–1860 セルビア県とテメシュ・バナート、1867 ハンガリーへ統合）
- F：アウシュヴィッツ・ザトル公領（1815–1866 ドイツ連邦）、1846 クラクフ併合、ガリツィア、ブコヴィナ
- BS：1816 ミュンヘン条約（ルペルティウィンケル・ベルヒテスガーデンはバイエルンに残る）
- europe.yaml との重複候補：ウィーン三月革命、ケーニヒグレーツ、独墺同盟、ボスニア占領・併合、カールスバート決議
- 案：1867 以降のハンガリー王国（聖イシュトヴァーン王冠領）を、地図上で外枠（overlord 用の政体 hungary_crown など）で示すと二重帝国が見た目で伝わる → まとめ役で検討

## BS（南ドイツ）から
- 北ドイツ連邦の外枠が 1868 の画像で見えない → まとめ役で map.ts の帝国枠リストに north_german_confederation を追加済み（BN の定義も確認）
- BN：oldenburg（1815 大公国）と saxon_duchies（1826 再編）の 1815 以降の名前・情勢。北ドイツ連邦にヘッセン大公国北部が含まれる点。1866 の併合の出来事は BN が書く前提
- 重複候補：1819 コッツェブー暗殺（カールスバート決議、habsburg にも）、1848 フランクフルト国民議会（europe.yaml の 1848 年革命と）

## BN（北ドイツ）から
- F：北シュレースヴィヒ（DNK のピース）は 1864 からプロイセン領（1871 から german_empire）。今はデンマーク色のまま
- 重複候補：カールスバート決議（BS・全体）、1866 の大併合とエムス電報（BS）、ルクセンブルク危機 1867（C）
- 1864–65 の共同統治：1864 両公国 prussia（斜線）、1865 ホルシュタイン habsburg（斜線）
- 画面：1871 の「国境の変化」が大量に並ぶ → 画面担当に「同じ変化はまとめる」を依頼済み
