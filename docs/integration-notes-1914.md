## 整合の結果

各担当の確認点と、まとめ役の方針（保護国の塗り方・戦時占領・ハンガリー王冠領の外枠）を全データに当てはめた結果。担当の境界で隣り合うピースの所属（owner・overlord・certainty）を 1815–1914 の全年で比べるスクリプト（ピースの隣接は pieces.topo.json の共有辺から求めた）で、一覧にない食い違いも探した。

### まとめ役の方針の適用

- **保護国・保護領・占領下の自治国は宗主国の色で塗る**（owner を宗主国にし、overlord は外した。現地の政体名は cause・note・地域名に残した）。
  - フランス：チュニジア（`tunis_regency`・`tunisia_south_nominal`、1881–）、モロッコの仏保護領（`morocco_french_zone` ほか 7 地域、1912–。南部・アトラスは nominal、タザ・ヘニフラ 1914 は uncertain のまま）。
  - スペイン：モロッコの西保護領（`morocco_spanish_zone`・`morocco_spanish_rif`・`melilla_hinterland`・`larache`・`tarfaya_strip`、1912–）。
  - イギリス：エジプト（`egypt`・`egypt_western_desert`）は 1882–1913 を owner britain・occupied、1914– を owner britain（西部砂漠は nominal）。イオニア諸島（1815–1863）、クウェート（1899–）、バーレーン（1861–）、休戦海岸（1892–。1820–1891 は条約関係だけなので trucial_states のまま）、カラート（1876–、uncertain のまま）、アフガニスタン（1879–、ガンダマク条約）。
  - ロシア：ヒヴァ（1873–）、ブハラ（1868–）、ミングレリア（1803–1856）、グリア（1810–1828）、アブハジア（1810–1863）。
  - モナコ：フランスの保護下の時期（1648–1792、1814）を owner france、サルデーニャ王国の保護下（1815–1860）を owner savoy にした。1861 年以降は独立（フランスの保護条約は 1918 年）なので monaco のまま。
  - カタルは 1871 年からオスマン帝国の宗主権下（ハサー県）で、イギリスの保護条約は 1916 年なので、qatar・overlord ottoman のまま。
  - 変えなかったもの：オスマン帝国の宗主権下の自治国（セルビア・ルーマニア・ブルガリアの独立前、東ルメリ、サモス、クレタ自治国、レバノン山地、エジプトの 1882 年まで、キプロス 1878–1913 の owner britain・overlord ottoman）。1815 年より前だけの保護関係（カルトリ・カヘティ 1783–1800、イメレティ 1804–1809）とカザフの小ジュズ（1731–1823、overlord russia・uncertain）は、試作期間のレビュー済みデータなので触っていない。
- **戦時の一時占領は描かない**：1914 年のベルギー・ルクセンブルク・フランス北東部は、もともとどの担当も描いていなかった。E の `vlore`（1914 イタリアの占領）と `northern_epirus`（1914 ギリシア軍の再進駐）を、ほかのアルバニアと同じ「albania・uncertain」に直し、占領のことは note に書いた。バルカン戦争（1912 の occupied）、イタリア＝トルコ戦争（リビア沿岸 1911、ドデカネス 1912–）、モロッコの 1907–1911 の占領、ボスニア 1878–1907 は occupied のまま。
- **ハンガリー王冠領の外枠**：`hungary_crown`（ハンガリー王国（聖イシュトヴァーン王冠領））を `data/polities/habsburg.yaml` に定義し、次の 1867 年の項目（owner habsburg・overlord hungary_crown）を足した。
  - D：`upper_hungary` `thokoly_sk` `nove_zamky` `lubovna` `hungary_hu` `ottoman_hungary_hu` `szabolcs_szatmar` `bihar_hajdu` `thokoly_hu` `burgenland` `prekmurje` `croatia_hr` `slavonia_hr` `bilogora_moslavina` `croatia_south_hr` `rijeka_hr`。軍政国境地帯がほぼ全部を占める `lika_hr` `banija_hr` は、クロアチア＝スラヴォニアに統合された 1881 年から。
  - E：`transylvania_ro` `satu_mare` `bihor` `arad` `banat_ro` `lugoj_caransebes` `backa` `east_syrmia` `banat_rs`。
  - F：`zakarpattia`。
  - ダルマチア・イストリア（オーストリア側）とボスニア（共同統治領）には付けていない。バナート・ヴァラジュディンの軍政国境地帯（1871–1873 廃止）は、ピースが民政地域と混ざるので 1867 年から枠に入れた。
  - **画面側への依頼**：`src/map.ts` の `EMPIRE_FRAMES` に `hungary_crown` がないため、今は宗主権の細い点線で描かれる（拡大すれば見えるが、ヨーロッパ全体では目立たない）。二重帝国を見た目で伝えるなら、帝国枠と同じ扱いか、専用の線の種類にするとよい。
