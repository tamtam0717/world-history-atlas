# オセアニア（1648–2025）の担当間の整合

担当：O1 オーストラリア・ニュージーランド（data/*/australasia.yaml）、O2 太平洋の島々（pacific.yaml と data/regions/usa.yaml の us_kauai・us_manua）、O3 分布（data/religion・language の oceania.yaml、data/cities.yaml のオセアニア分、data/movements/oceania.yaml）。指示書は docs/agent-brief-oceania.md。
やり方は docs/integration-notes-africa.md と同じ。ただし島どうしは境界線を共有しないので、色と塗り方の比較では「6度（約 660 km）以内にあるピース」を隣とみなした。首都は都市の座標を含む（海上なら最も近い）ピースの所属を、首都の期間の全年で確かめた。

## 整合の結果

### 1. 出来事の重複と関係国

- **重複の解消**：
  - クックの第 1 回航海（1769）：O1「クックがニュージーランドを一周する」と O2「クックの第1回航海」→ O1 を削除し、O2 の文にポヴァティ湾上陸・6 か月の一周・トゥパイアの通訳を足した。1770 年の「クックがボタニー湾に上陸」（O1）は別の出来事として残した。
  - ブラックバーディング（1863）：O1「クイーンズランドへの南洋諸島民の徴募が始まる」と O2「ブラックバーディング（太平洋の労働者徴募）の広がり」→ O1 を削除し、O2 にクイーンズランドの約 6 万人・1906 年以降の送還を足した。潮流（白豪主義・労働移民）の events から削除した題名を外した。
  - ガリポリ（1915）：O1「アンザック軍団のガリポリ上陸（アンザック・デー）」と ottoman「ガリポリの戦い」→ O1 を削除し、ottoman の文にアンザック・デーを足し、polities に australia・new_zealand を足した。
  - パリ講和会議（1919）：O1「パリ講和会議でオーストラリア・ニュージーランドが委任統治を得る」は europe「パリ講和会議」と O2「太平洋の委任統治」（1920）に重なる → O1 を削除し、europe の文に人種差別撤廃提案とヒューズ首相・自治領の委任統治を足し、polities に japan・australia・new_zealand を足した。潮流（白豪主義）の events は「パリ講和会議」に付け替えた。
  - ウェストミンスター憲章（1931）：O1 と west の同名の出来事 → O1 を削除し、west の文に両国の採択の年（1942・1947）を足し、polities に canada・australia・new_zealand・south_africa を足した。
  - ラロトンガ条約とレインボー・ウォーリア号事件（1985）：別の出来事なので両方残し、O2 のラロトンガ条約の文から事件の説明を外して「ニュージーランドの項」とした。
  - RAMSI（2003）・ファレピリ連合（2023）は O2 にだけあり、重複はなかった。
  - 太平洋戦争：真珠湾（europe「太平洋戦争とアメリカの参戦」）・ミッドウェー（japan_korea）・ガダルカナル・珊瑚海・ラバウル・ココダ・タラワ（O2）は重複なし。日本の第一次世界大戦参戦（japan_korea、青島と南洋諸島）と O2「日本の南洋諸島占領」は主題が違うので残した。
- **足したもの**：O2 に「サイパン島の陥落」（1944、絶対国防圏・東条内閣の総辞職。どの担当にもなかった）、O1 に「コロンボ・プラン」（1950、at はコロンボ）。
- **関係国の追加**（他地域のファイルは該当の行だけ）：
  - europe：第一次世界大戦はじまる・第二次世界大戦はじまる・太平洋戦争とアメリカの参戦・日本の降伏に australia・new_zealand
  - japan_korea：朝鮮戦争に britain・australia・new_zealand（国連軍）、サンフランシスコ平和条約に australia・new_zealand
  - mainland_sea：SEATO に australia・new_zealand（文には加盟国として書いてあった）
  - maritime_sea：シンガポールの陥落に australia（文に「イギリス・インド・オーストラリア」）、東ティモールの住民投票に australia（多国籍軍を主導）
  - ottoman：イラク戦争に australia（文にも）

  - ウェリントン：new_zealand の首都を 1865 → **1907**（自治領の成立から。1865 年からは植民地の首府と note に）。

### 3. 分布の年と政治の年

- 言語：ヨーロッパの言語（英語・フランス語・日本語など）が多数派になる年が、その地のヨーロッパ系などの政体の支配より早いピースはなかった。
- 宗教：キリスト教が多数派になる年が支配より 5 年以上早いのは、トンガ（1835）・サモア（1840）・タヒチ（1815）・クック諸島（1830）・ニウエ（1860）・ウォリス・フツナ（1842）・ツバル（1870）・キリバス（1880）・トケラウ・ロトゥマ・ピトケアン・ヴァヌアツ・フィジー沿岸（1855）で、どれも宣教師による改宗が植民地化に先行した地域。そのまま。
- 宗教・言語のデータがないのは無人島（南極・ハード島・マッコーリー島・ケルマデック・亜南極諸島・合衆国の小離島・クリッパートン・フェニックス諸島の 1938 年まで・南ライン諸島）だけで、意図どおり。

### 4. 隣り合う政体の色

6 度以内のピースの組（ピース・年の数が 5 以上）と、全世界の境界を共有する組を合わせて、O2 の政体の最も近い隣との差を ΔE 20 以上にした（australia・new_zealand・britain・france・usa・japan などは変えない）。

- 変えたもの（data/polities/pacific.yaml、8 政体）：tuvalu–kiribati（ΔE 3.9、もとは同じ植民地）、micronesia–palau（5.3）、palau–philippines（7.4）、kiribati–marshall_islands（9.6）、marshall_islands–nauru（10.9）、niue–samoa（11.0）、france–new_hebrides（14.2）、britain–tonga（16.2）、new_zealand–samoa（16.9）、fiji_kingdom–tonga（17.7）、australia–papua_new_guinea（18.7）など。
  - tonga `#e4b7a0`→`#e6b8d6`、new_hebrides `#c6c9e0`→`#e0c0f0`、papua_new_guinea `#d6b38f`→`#ccb4a3`、samoa `#b2d6a3`→`#9bcc8b`、niue `#d4e3b8`→`#d8f0c0`、kiribati `#9fc3d6`→`#7e98cc`、marshall_islands `#b3c6e6`→`#95caf0`、palau `#b9dccc`→`#d0f0c0`

### 5. 1788・1840・1900・1942・2025 年の塗り方

担当ごとに面積の内訳（確か／nominal／indirect／occupied／所属なし）を出し、地図の画像で見た。

- **1788**：ニューサウスウェールズ（ピース全体）・ノーフォーク島が濃く、東経135度までの主張（クイーンズランド・ヴィクトリア・南オーストラリア東部・タスマニア・北部準州東部）は斜線、西オーストラリア・ニュージーランド・太平洋の島々は所属なし（トンガ・タヒチは独自色、カロリン諸島はスペインの斜線）。
- **1840**：ワイタンギ条約の年で、ニュージーランドは北部（ノースランド・オークランド）が濃く、ほかは斜線。O2 の島々は所属なしか在地の王国。
- **1900**：ニューギニアは海岸が濃く内陸が斜線（英独とも）、ソロモンはマライタ・離島が斜線、トンガ・クック諸島・ニウエ・ウォリス・フツナは保護国の indirect、ニューヘブリディーズは所属なし（1906 年の共同統治から）。O1 は西オーストラリア・南オーストラリアの中央部が濃く、ナラボー（南オーストラリア西部）だけが斜線。
- **1942**：日本の占領（ニューギニア北部・ビスマルク諸島・ブーゲンヴィル・ソロモン北部・ギルバート・ナウル・ウェーク・クリスマス島）は O1・O2 とも japan・occupied、南洋諸島は japan＋label（確か）でそろっていた。
- **2025**：所属なしは南極だけ（オセアニアの中）。
- 直したもの：**サンタクルーズ諸島・レンネル島（slb_outer）**が 1898–1977 年ずっと nominal で、1970 年の地図でソロモン諸島の離島だけ斜線になっていた → **1946 年から確か**（戦後に行政が離島に及んだ時期を目安に。要確認）。

### 6. 全世界の所属なし・データ未整備

- `--missing 1648,1800,1900,2025`（iso 指定なし）：データのないピースが **111-Abyei** と **122-Koualou** の 2 つあった → 111-Abyei（アビエイ地域の大部分、約 1 万 km²）を east_africa の sdn_abyei に、122-Koualou（ベナンとの係争地、約 7 km²）を west_africa の bfa_gurma に入れた。これで全年 0。
- 2025 年の所属なしは南極・スプラトリー諸島・ビル・タウィールの 3 ピースだけ（意図どおり）。
- 1900 年の所属なし（98 ピース）は、ソマリア南部・ナイジェリア中部の山地・チャド（ゲラ・ティベスティ）・アルナーチャル・スラウェシ内陸・西サハラ・アルジェリアの深いサハラ・ニジェールのカワール・グリーンランド北東部・ニューヘブリディーズ・マヌア諸島など、各担当の報告どおりの意図した所属なし。
- 宗教・言語のデータがないのは無人島・南極（上の 3.）と、1648 年の無人だった島（セーシェル・マスカリン諸島の一部・セントヘレナ・フォークランド・ケイマン・タークス・カイコス・ピトケアン・ノーフォーク・ライン諸島など）だけ。

## 判断が分かれるもの（田村さんへの確認候補）

- **西オーストラリア（1829–）・ニューサウスウェールズ（1788–）のピース全体を濃く**：入植地は一部だけだが、O1 は「植民地の中心なのでピース全体を濃く塗る」とした（ピースが州単位で分けられない）。そのため 1861–1900 年は、濃い西オーストラリアと濃い南オーストラリア中央部の間で、ナラボー（南オーストラリア西部）だけが斜線になる。首都特別地域（1788 年から確か）も同じ理由。
- **1901 年の連邦成立で全域が確か**：内陸の砂漠も含め、連邦・自治領の成立から濃くしている。
- **slb_outer の 1946 年**：年は目安。
- **保護国の都**：ヌクアロファ・パペーテを首都のまま宗主国の色の中に置いた（前回までと同じ扱い）。
- **色**：8 政体の色を変えた。トンガ（淡い朱色→淡い赤紫）・キリバス（水色→青）は色合いが大きく変わったので、好みで調整してよい（隣との ΔE 20 を保つこと）。
- 宗教・言語・潮流の中身（O3）は、年が政治とずれていないかと首都・座標・潮流の題名だけを見た。
