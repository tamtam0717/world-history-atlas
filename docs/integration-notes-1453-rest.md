# 担当間の整合（1453–1647、南北アメリカ・サハラ以南のアフリカ・オセアニア）

指示書は docs/agent-brief-1453-rest.md。担当は W1（usa・canada）・W2（mexico_caribbean）・W3（andes・south_cone）・W4（west_africa・guinea_coast）・W5（east_africa・southern_africa）・W6（australasia・pacific）と W7（宗教・言語の americas・africa・oceania、cities.yaml、movements）。境を接するヨーロッパ側（west の北アフリカ・サハラ）も合わせて見た。

## 整合の結果

担当の境界で隣り合うピース（pieces.topo.json の共有辺）の所属（owner・overlord・certainty）を 1453–1647 の毎年で比べ、食い違いを一覧にして確かめた（作業用のスクリプトは scratchpad の integ_rest/：border.py・step.py・cs.py・posts.py・colors2.py・recolor.py・amcol.py・caps.py・cmp1648.py・dist.py）。
**1648 年以降の所属・分布は、作業前の atlas.json（atlas_before_rest1453.json）と比べて、下の 6 の例外（ケッビ 14 ピース、宗教 3・言語 3 ピース）以外は変わっていない**（全ピース・1648–2025 の毎年で照合）。

### 1. 太平洋の島（usa.yaml）
- グアム・北マリアナ・ハワイ・米領サモアは、W6 が既存の地域（`us_guam`・`us_nmi`・`us_hawaii`・`us_am_samoa`・`us_manua`）を 1453 年までさかのぼらせ、W1 が別に until: 1647 の `pre1648_hawaii`・`pre1648_samoa`・`pre1648_marianas` を足していた。所属はどちらも同じ（グアム・北マリアナは 1453 所属なし → 1565 spain[nominal]、ハワイ・サモアは所属なし）で、`pre1648_marianas` は小さい `us_guam`・`us_nmi` に負けて効いていなかった（副ラベルも「ラドロネス諸島」と「マリアナ諸島」で食い違い）。→ W1 の 3 地域を消し、W1 の note（ハワイは島ごとの首長、サモアのマタイ）を W6 の地域に移した。グアム・北マリアナは 1565 年から spain[nominal]、1668・1695 年に確か（既存）でそろっている。

### 2. 境目
- **W2–W3（パナマ・ダリエン）**：チョコ（`pre_col_choco`）は 1510 castile[uncertain]（サンタ・マリア・ラ・アンティグア）→ 1516 spain → 1524 所属なし、パナマ側は 1519 年（パナマ市）から。→ グナ・ヤラ（`guna_yala`、アクラ 1515・バルボアの太平洋到達 1513 の海岸）に 1510 castile[uncertain]・1516 spain[uncertain]「カスティーリャ・デル・オロ（ダリエン）」を足した。パナマのダリエン州・エンベラ（`panama_frontier`、ボカス・デル・トロと同じ地域）は分けずに 1519 年からのまま。
- **プロヴィデンス島**（1630 britain → 1641 spain[nominal]）、**ABC 諸島**（1527 spain、キュラソー 1634・アルバとボネール 1636 netherlands）は、ベネズエラのコロ（1527）とそろっている。
- **W1–W2（フロリダ・バハマ）**：バハマは 1453 taino（ルカヤ人）→ 1513 所属なし（ルカヤ人の連れ去り）、フロリダは 1564 フォート・カロリーヌ・1565 セントオーガスティン。1513 年のポンセ・デ・レオンの出来事（usa）とも合う。メキシコ北部とテキサス・アリゾナ（スペインの nominal の始まりが 1577・1598 年）、ソノラ（1617 年から）の差は史実の範囲として残した。
- **W1 内（カナダ・メイン）**：アカディア・セントローレンス（france[nominal]）とメイン・ヴァーモントの所属なしの差は史実どおり。
- **W4–W5（チャド・ダルフール）**：トゥンジュルはダルフール（W5）で 1453 年から、ワダイ（W4）で 1500 年から（1635 年にワダイ王国、1640 年にダルフールのケイラ朝）。トゥンジュルが西へ移ったという伝承に合うので残した。バギルミ（1522 uncertain → 1561 → 1608 ボルヌの帯）、ブラーラ（カネム → 1507 bornu、フィトリ湖は 1647 年まで bulala）、ダル・クティ（所属なし）、西ダルフール（所属なし）も一貫している。
- **W4 内（ナイジェリア・ニジェール）**：ハウサ諸国・ボルヌ・ケッビ・ダマガラムの境に食い違いはなかった。
- **アフリカと北アフリカ（west）**：アルジェリアのサハラ（所属なし）とトゥアレグ・アガデス、フェザーン（tripoli/ottoman[nominal]）とティベスティ・カワール（所属なし）、エジプト（mamluk → ottoman）とヌビア（所属なし・アルワ）は史実の範囲。
- **castile → spain**：アメリカのすべてのピースで 1515 年まで castile、1516 年から spain（例外なし。scratchpad の cs.py）。
- **アフリカのポルトガル・オランダの拠点**：要塞・島（エルミナ、アクシムなど黄金海岸の砦、サントメ・アンノボン、カーボ・ヴェルデ、カシェウ、ルアンダ・ベンゲラ、ソファラ・モザンビーク島・イニャンバネ・テテ、モンバサ 1593–）は確か、スワヒリ海岸の貢納国（ザンジバル・ペンバ・マリンディ・タンガの海岸）は portugal[nominal]（1648 年以降の既存データ「スワヒリ海岸（ポルトガルの勢力圏）」と同じ書き方）、キルワ（1505–12）とムタパ（1629–）・ンドンゴ（プンゴ・アンドンゴ）は宗主の帯、オランダはゴレ（1617）・エルミナ（1637）・モーリシャス（1638）・ルアンダ・ベンゲラ（1641–47、occupied）でそろっている。

### 3. 首都・都市（data/cities.yaml）
- **オヨ**：オヨ・イレの首都は 1534 年まで・1610 年から（1535–1609 年はヌペに追われた亡命期）。地図ではこの間もオヨ王国（uncertain）なので、亡命期の都 **イボホ**（新しい点、oyo 1535–1609）を足した。
- **キルワ**：首都 1453–1647 年。1505–12 年は kilwa に portugal の帯（ポルトガルの砦と傀儡のスルタン）で、首都と所属は合っている。
- **トンブクトゥ**：arma の首都を 1591 年から 1618 年からにした（1591–1617 年は地図がモロッコのパシャ領で、arma は 1618 年から）。町のピースはトゥアレグ（副ラベル「トンブクトゥの町はアルマのパシャ領」）で、1648 年以降と同じ扱い。
- **アボメー**：dahomey の首都に 1620–1647 年を足した（地図のダホメ王国は 1620 年から）。
- 1648 年より後に作られた都市（これまで 1453 年から地図に出ていた）に founded を足した（下の 6）。
- 重複していた note を直した（サント・ドミンゴ、ポトシ）。
- 残したずれ：ビルカバンバ（新インカ 1539–72。ピースが PER-Cusco の一部で、地図はスペイン。下の 8）。首都のない在地の政体（マリ・エチオピア・ムタパ・ハウサ諸国など多数）は、1648 年以降のデータと同じく点を足していない。

### 4. 色
- 1453–1647 年に隣り合う政体の組の ΔE（CIE76）を 3 年ごとに調べ、1647 年以前にだけ出る政体（1648 年以降の地図に出ない）が入る組で 20 未満のものを、その政体の色を変えて解消した。**1648 年以降の地図の色は変わらない**。
  - ブラーラ #b9c79a → #94cea2（バギルミと 9.1）、トゥンジュル #d8c59c → #e1d99c（フンジと 12.2、ブラーラと 13.3）、ソンガイ #cf8a6a → #c87a5a（マシナと 14.9。濃いテラコッタは保った）、アダル #b9cf9a → #aad5a0（ウォライタと 17.3）、ディアラ #c9d39a → #c3d9a6（マリと 18.6）。
  - 隣り合わないが同じ画面で近い組：タイノ #a6d9c3 → #7ee8e9（ユカタンのマヤと 7.2）、クスカトラン #e7aaa5 → #e39cbd（ペテンのイツァと 7.6）。
- **モシとハウサ諸国が同じ色（#d3ca7e）**：どちらも 1648 年以降からある政体で、1453–1900 年のどの年も隣り合わない（間にグルマ・ソンガイ・ボルグ）。1648 年以降の地図も変わるので変えていない（**次の見直しの候補**）。
- 解消しなかった組（どちらも 1648 年以降もある政体）：マシナとモロッコ（12.0、1591–1615）、ファンテとポルトガル（12.8）、マリとマシナ（14.8）、キルワとマニカ（17.8）、ハウサ諸国とケッビ（19.8）、イロコイとヒューロン（7.6、オンタリオ湖をはさむ）。

### 7. 塗り方のぶれ
- 南東部の先住民の連合（クリーク・チェロキー・チョクトー・チカソー、W1）が 1453 年から uncertain で塗られている。これらの連合のまとまりは 16–17 世紀（ミシシッピ文化の首長国の崩壊の後）なので、1453 年から描くのは早い可能性がある（**次の見直しの候補**。イロコイ連邦は成立年に諸説あり 1600 年まで uncertain で妥当）。
- ブラジルは 1500 年（カブラル）からバイーアが portugal[nominal]、メキシコはバハ・カリフォルニアが 1535 年（コルテス）から spain[nominal] で、どちらも「上陸・領有宣言だけの所は nominal」でそろっている。

### 8. ビルカバンバ
- 新インカ（1537–72）の拠点ビルカバンバ・ビトコスはクスコ県のラ・コンベンシオン郡にあり、ピース PER-Cusco の一部なので塗れていない（note と首都の点だけ）。**ピースを分ける価値はある**と考える（ラ・コンベンシオン郡〈約 3 万 km²〉を CGAZ ADM2 の units で分け、1648 年以降は PER-Cusco と同じ所属を写す）。ピースの作り直し（pieces.topo.json）が要るので今回はしていない。次にピースを足すときの候補。
